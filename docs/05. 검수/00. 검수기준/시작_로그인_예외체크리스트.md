# 앱 시작·로그인 예외 체크리스트

상태: 검수용 초안 / 작성일: 2026-11-04 / 코드 확인 기준: `b913093` 및 당시 작업 트리.

앱 실행 → BI/CI → 로그인 선택 → Google·게스트 인증 → 홈 또는 원래 목적지까지 확인한다. 정상 흐름을 기준으로 각 단계의 실패·중단·재시도·동시 실행을 점검한다. 이메일 입력 화면 내부와 홈 기능 내부는 범위에서 제외하며, 해당 화면으로 안전하게 이동하는지는 포함한다.

이 문서는 예외를 점검하기 위한 110개 항목이다. 체크박스는 이번 문서를 사용해 다시 검수할 때 표시한다. 이번 작성에서는 코드를 읽고 기존 증거를 대조했으며, 앱 동작 검사를 새로 실행하지 않았다. 빈 체크박스가 곧 결함을 뜻하지는 않는다. 이전 검수에서 확인한 범위는 뒤의 근거 표에 따로 적었다.

## 사용 방법

- 각 항목은 **조건 → 기대 결과** 순서다. 기본 환경에서 확인한 뒤 관련 플랫폼과 조건을 바꿔 반복한다.
- 우선순위는 P0부터 확인한다. P0는 계정·기록 오염, 잘못된 인증 성공, 시작 차단이나 무한 대기다. P1은 복구·이동·접근성 문제, P2는 표시 품질이다.
- 실제 실행 후 `통과·실패·미검증·해당 없음`을 기록한다. 통과만 체크하며, 해당 없음에는 이유를 남긴다. 웹 시험 응답의 통과와 실제 서버·기기 통과를 구분한다.
- ‘확인 기준’은 검수에서 기대하는 결과다. 기존 규격에 없는 시간 제한·계정 정책·기록 복구 정책은 이 문서만으로 확정하거나 구현된 것으로 보지 않는다.

## 1. 앱 실행과 시작 점검

- [ ] S01 · P0 · 설치 후 첫 실행에 로그인 정보가 없음 → BI/CI 후 로그인 선택으로 이동한다. 버튼 선택 전에 게스트를 발급하지 않는다.
- [ ] S02 · P1 · 시작 점검이 BI/CI 표시보다 늦게 끝남 → 브랜드를 유지하고 기다림을 안내한다. 빈 화면이나 별도 화면을 반복 표시하지 않는다.
- [ ] S03 · P0 · 공통 데이터 요청 실패·서버 오류·응답 형식 오류 → 시작 화면에 머물며 재시도를 제공한다. 홈으로 우회하지 않는다.
- [ ] S04 · P0 · 로컬 데이터 점검 실패·손상 → 오류를 구분하고 복구 방법을 제공한다. 기록을 임의 삭제하거나 가짜 데이터로 대체하지 않는다.
- [ ] S05 · P0 · 첫 실행부터 오프라인 → 필요한 확인을 생략해 성공으로 처리하지 않는다. 연결을 복구한 뒤 재시도할 수 있다.
- [ ] S06 · P1 · 기존 캐시가 있는 상태에서 오프라인 → 허용된 캐시 정책만 적용한다. 오래된 계정·정책을 최신 확인 결과로 표시하지 않는다.
- [ ] S07 · P0 · 필수 업데이트 또는 현재 기기에서 지원 버전에 도달할 수 없음 → 기존 정책에 맞춰 진입을 막고 가능한 행동을 안내한다.
- [ ] S08 · P1 · 선택 업데이트를 미룸 → 이번 실행의 정상 흐름을 이어간다. 미루기를 필수 업데이트에도 적용하지 않는다.
- [ ] S09 · P1 · 업데이트 취소·스토어 실행 실패·업데이트하지 않고 복귀 → 오류와 재시도를 제공하고 설치 버전을 다시 확인한다. 스토어를 연 것만으로 완료 처리하지 않는다.
- [ ] S10 · P0 · 점검 요청이 끝나지 않거나 앱이 배경으로 이동함 → 대기·실패·복귀 상태를 구분한다. 배경에서 목적지로 이동하거나 무한 대기를 정상으로 방치하지 않는다. 요청별 제한 시간과 탈출 경로를 확인한다.

## 2. 기존 계정과 세션 복원

- [ ] A01 · P0 · 유효한 회원 세션과 완료된 회원 설정이 있음 → 로그인 선택을 건너뛰고 홈 또는 보존된 목적지로 이동한다.
- [ ] A02 · P0 · 회원 설정이 미완료임 → 회원 설정으로 이동한다. 홈 진입으로 설정 절차를 건너뛰지 않는다.
- [ ] A03 · P1 · 기존 기기 게스트가 있음 → 로그인 선택을 표시하고, 게스트 선택 시 기존 기록을 이어간다.
- [ ] A04 · P0 · 만료·폐기된 회원 세션 → 갱신 또는 재로그인 정책을 따른다. 확인되지 않은 회원 상태로 보호된 화면에 진입하지 않는다.
- [ ] A05 · P0 · 세션은 있으나 회원 프로필 조회가 실패함 → 복원 실패와 재시도를 제공한다. 신규 회원·게스트로 임의 전환하지 않는다.
- [ ] A06 · P0 · 로컬 계정과 서버 계정의 식별자가 다름 → 현재 유효한 인증을 기준으로 확인한다. 다른 계정의 여행·개인 캐시가 보이지 않는다.
- [ ] A07 · P0 · 계정 전환 후 이전 복원 응답이 늦게 도착함 → 이전 응답이 새 계정을 덮어쓰거나 로그아웃시키지 않는다.
- [ ] A08 · P0 · 저장된 계정 정보가 일부만 있거나 손상됨 → 예외로 앱이 종료되지 않는다. 복구 가능한 정보만 사용하며 임의 회원 계정을 만들지 않는다.
- [ ] A09 · P0 · 보안 저장소·브라우저 저장소 읽기 권한 거부 또는 읽기 실패 → 오류와 재로그인 가능 여부를 확인한다. 무한 잠금이나 다른 계정 복원으로 이어지지 않는다.
- [ ] A10 · P1 · 로그인 선택을 직접 열었는데 이미 회원임 → Google 버튼을 중복 실행하지 않고 ‘이어서 시작하기’로 유효한 계정의 목적지에 이동한다.

## 3. BI/CI와 버튼 등장 연출

- [ ] M01 · P1 · 중앙 심볼에서 상단 심볼로 전환함 → 위치가 연속되고 원본 비율을 유지한다. 두 로고가 겹치거나 순간적으로 사라지지 않는다.
- [ ] M02 · P1 · 버튼 등장 순서를 확인함 → Google·게스트가 각자 최종 위치 아래에서 올라온다. 화면 전체를 밀거나 버튼을 엉뚱한 위치에서 이동시키지 않는다.
- [ ] M03 · P0 · 연출 중 터치·키보드·접근성 동작으로 버튼 선택을 시도함 → 숨겨진 버튼과 아직 준비되지 않은 인증을 실행하지 않는다. 완료 후에는 잠금이 풀린다.
- [ ] M04 · P1 · 연출 중 앱을 배경으로 보냈다가 복귀함 → 남은 연출을 이어가며 인증·시작 점검을 중복 실행하지 않는다.
- [ ] M05 · P1 · 움직임 줄이기 또는 화면 읽기가 켜져 있음 → 이동 연출을 생략하고 최종 배치와 조작 가능한 상태를 제공한다.
- [ ] M06 · P1 · 연출 도중 화면 회전·창 크기·글자 배율이 바뀜 → 최종 배치로 정리한다. 이전 좌표에 로고가 남거나 버튼이 잠기지 않는다.
- [ ] M07 · P1 · `/welcome` 직접 진입·인증 콜백·화면 재진입 → 시작 연출을 불필요하게 반복하지 않는다. 실제 새 앱 실행과 구분한다.
- [ ] M08 · P0 · 로고 배치 측정값이 0이거나 측정 콜백이 지연·누락됨 → 연출 완료와 버튼 사용 가능 상태로 복구하는지 확인한다. 중앙 로고만 남는 무한 대기를 허용하지 않는다.
- [ ] M09 · P1 · 연출 중 화면 해제·경로 변경·OS의 앱 종료 후 재실행 → 이전 애니메이션 콜백이 새 화면에 영향을 주지 않는다. 재실행 시 현재 시작 조건으로 판단한다.
- [ ] M10 · P2 · 느린 기기·프레임 저하·반복 전경 전환 → 로고 잔상·중복·투명 버튼이 남지 않는다. 연출 품질 저하가 로그인 불가로 이어지지 않는다.

## 4. Google 버튼의 이용 가능 상태

- [ ] P01 · P1 · 이용 가능 여부를 조회 중임 → Google 중복 실행을 막고 확인 상태를 알린다. 게스트는 별도 준비 상태에 따라 사용할 수 있다.
- [ ] P02 · P1 · Google 사용 불가 응답 → 버튼을 잠그고 다시 확인·게스트 선택을 제공한다. 사용할 수 있는 것처럼 인증을 시작하지 않는다.
- [ ] P03 · P1 · 조회 실패·10초 제한 시간 초과·잘못된 응답 → 사용 가능으로 간주하지 않는다. 이해할 수 있는 안내와 다시 확인 버튼을 표시한다.
- [ ] P04 · P1 · 다시 확인을 연속으로 누름 → 요청이 중복되지 않고 완료 후 버튼 상태가 최신 결과를 따른다.
- [ ] P05 · P1 · 사용 가능 상태에서 서버가 Google을 중단함 → 실제 인증 시작 실패를 처리한다. 오래된 조회 결과만으로 성공을 표시하지 않는다.
- [ ] P06 · P1 · 실패 후 연결 또는 서버가 복구됨 → 다시 확인으로 Google 버튼을 사용할 수 있다. 이전 오류가 성공 상태에 남지 않는다.
- [ ] P07 · P0 · Google 확인 중 게스트를 누르거나 두 버튼을 같은 순간 누름 → 계정 생성·인증·이동 중 하나만 실행한다.
- [ ] P08 · P1 · Google 인증 처리 중임 → G와 기본 문구를 유지하고 진행 안내를 제공한다. G를 다른 아이콘으로 교체하지 않는다.
- [ ] P09 · P2 · 사용 불가·로딩·키보드 초점·눌림 상태 → 공통 화면 문구와 Google 버튼 규격을 유지한다. 색만으로 상태를 전달하지 않는다.
- [ ] P10 · P1 · 회원 복원 완료·계정 변경과 이용 가능 조회가 동시에 끝남 → 현재 계정과 준비 상태로 버튼을 잠근다. 늦은 조회가 인증 잠금을 풀지 않는다.

## 5. Google 인증 시작과 외부 화면

- [ ] G01 · P0 · 복귀 목적 저장·난수 생성·해시 계산·검증자 저장 실패 → 브라우저를 열거나 로그인 성공으로 처리하지 않는다. 다시 시도할 수 있다.
- [ ] G02 · P0 · 인증 준비 요청 실패·15초 제한 시간 초과·사용 불가 응답 → 안내 후 잠금을 해제한다. 기존 게스트·회원 기록을 손상시키지 않는다.
- [ ] G03 · P0 · 준비 응답에 인증 URL이 없거나 형식이 잘못됨 → 외부 화면을 열지 않는다. 잘못된 주소·허용되지 않은 서버 응답의 검증 범위를 확인한다.
- [ ] G04 · P1 · 시스템 인증 브라우저 실행 실패·사용할 브라우저 없음·기기 제한 → 로그인 화면에 남아 재시도나 다른 방법을 선택할 수 있다.
- [ ] G05 · P1 · Google 계정 선택창에서 취소·뒤로가기·닫기 → 로그인 성공이나 홈 이동으로 처리하지 않는다. 처리 중 상태를 해제한다.
- [ ] G06 · P1 · 계정을 고른 뒤 동의 거절·인증 서비스 오류 → 실패를 알리고 재시도할 수 있다. 기기 기록을 보존한다.
- [ ] G07 · P1 · Google 화면에서 오래 대기·네트워크 변경·연결 끊김 → 앱 복귀 시 실제 완료 여부를 확인한다. 인증 완료를 추측하지 않는다.
- [ ] G08 · P0 · 외부 인증 중 OS가 앱을 종료함 → 복귀 가능한 인증과 만료된 인증을 구분한다. 임시 정보가 없으면 안전하게 다시 로그인하도록 한다.
- [ ] G09 · P0 · 인증 도중 Google 계정을 바꾸거나 재시도함 → 이번 시도의 검증자·복귀 목적·계정만 사용한다. 이전 시도의 결과가 섞이지 않는다.
- [ ] G10 · P1 · 웹에서 새로고침·뒤로가기·탭 복제·저장소 차단 → 동일 탭 인증이 유지되는 범위와 만료 처리를 확인한다. 다른 탭의 인증을 잘못 완료하지 않는다.

## 6. 인증 콜백과 세션 확정

- [ ] C01 · P0 · 정상 콜백 수신 → 기기에 보관한 검증자와 서버 교환을 완료하고 세션 저장 후에만 다음 화면으로 이동한다.
- [ ] C02 · P0 · 복귀 스킴·호스트·경로가 다르거나 코드가 없음 → 콜백을 거절한다. 외부 입력만으로 로그인 상태가 바뀌지 않는다.
- [ ] C03 · P0 · 만료·재사용·변조된 코드 또는 잘못된 검증자 → 인증을 거절하고 다시 로그인할 수 있게 한다.
- [ ] C04 · P0 · 검증자가 삭제됐거나 다른 기기·탭에서 콜백을 엶 → 기존 세션으로 실패를 덮지 않고 재로그인을 안내한다.
- [ ] C05 · P0 · 시스템 브라우저 완료와 라우터가 같은 콜백을 동시에 전달함 → 세션 교환·목적지 이동을 중복 실행하지 않는다.
- [ ] C06 · P0 · 교환 요청 실패·15초 제한 시간 초과·응답 형식 오류 → 성공으로 처리하지 않는다. 실패 후 재시도 또는 새 인증의 복구 경로를 확인한다.

발견 사항과 검증 요청을 구분했다. 위 쟁점은 이번 작업에서 재현·수정한 버그 목록이 아니다. 기록 복구·이관 정책처럼 기존 기준만으로 결과를 정할 수 없는 항목은 정책 미정으로 남기고, 사용자 기록을 임의로 삭제하거나 옮기는 동작을 추가하지 않는다.

## 실행 조합과 기록 양식

기본 조합은 웹 Chrome·Android 설치본·iOS 설치본이다. 각 환경에서 신규 사용자·기존 게스트·설정 미완료 회원·기존 회원을 나누고 정상망·오프라인·느린 응답·도중 연결 끊김을 조합한다. 320·390·430 너비, 글자 100%·200%, 한·영·일, 움직임 줄이기·화면 읽기는 해당 UI 항목에 적용한다. 모든 조합을 기계적으로 곱하지 말고 항목의 실패 경계가 달라지는 조합을 선정해 이유를 기록한다.

| 항목 ID | 버전·빌드         | 환경·기기             | 계정·사전 조건      | 조작 순서                      | 기대 결과                                 | 실제 결과    | 판정   | 증거·결함 ID |
| ------- | ----------------- | --------------------- | ------------------- | ------------------------------ | ----------------------------------------- | ------------ | ------ | ------------ |
| 예: G05 | 커밋·앱 버전 기입 | OS·기기·브라우저 기입 | 검수 계정, 비로그인 | Google 선택 → 계정 선택창 취소 | 로그인 선택 유지, 잠금 해제, 홈 이동 없음 | 실행 후 기입 | 미검증 | 실행 후 기입 |

검수 증거는 `outputs/startup-login-exceptions/` 아래에 두고 보고서에는 재현 조건과 결과를 남긴다. 개인 정보가 있는 원본 캡처·토큰은 공유하지 않는다. 저장·계정 변경 항목은 즉시 표시뿐 아니라 앱 재실행·화면 재진입·서버 재조회까지 확인한다.
