갱신일: 2026-10-20
대상: 화면별 상세기능정의서 v3 / R00~R13 후속 실제 설치본 인수
최신 사용자 확정: 사용자가 직접 빌드한 뒤 Google Play 내부 테스트에서 게스트·Google 로그인을 검수한다. 개발 측은 구현·사전 검사까지 담당한다. 아래 과거 버전8·서버 키 미등록 기록은 당시 이력이며 최신 빌드 입력과 서버 상태는 내부테스트_빌드전인계.txt·SECURITY_P0_FOLLOWUP.txt를 우선한다. 실제 Google 인증·실기기 검수는 아직 통과 처리하지 않았다.
상태: 지도·검색 코드 보완 검증. Places 서버 키 등록·Play 지도 키 제한 확인과 병행 화면 작업의 통합 검증은 대기. 최종 기기 테스트는 Google Play 내부 테스트 설치본으로 진행한다.
사용자 범위 확정(2026-10-15): 이번 작업은 빌드 생성 전까지이며 실제 기기 검수는 이후 단계다.
빌드 인계 기준: docs/06. 출시/00. v11/내부테스트_빌드전인계.txt.

1. 현재 증거

outputs/r14-device-preflight.json: adb 조회 성공, 연결 기기0대, physicalAcceptance=not-run.
로컬 ver.text: versionName0.1.0, versionCode8. 같은 번호만으로 이번 수정본임을 판정하지 않는다.
이번 R13은 흰 배경 중앙 로고 대체를 사용한다. tripprint_bi.mp4는 미제작이며 임의 영상을 넣지 않았다.
사용자 확인: 기기·설치본·검수 계정 준비됨, Google Play 내부 테스터 등록 완료. USB 연결은 사용하지 않는다.
이번 소스·서명·빌드와 실제 Play 설치본의 대응 및 휴대폰 실행 결과는 아직 확인하지 못했다.
비밀번호·토큰을 문서나 대화에 남기지 않는다.
기존 2026-10-12 후보·예전 APK·예전 웹 배포를 이번 R00~R13 결과로 취급하지 않는다.
브라우저 fixture·Android Hermes 번들·네이티브 모듈 컴파일은 실제 Play/Google/지도/OS 검수를 대신하지 않는다.

2. 실행 전 준비

- Play 내부/비공개 테스트 채널에서 이번 소스로 새 설치본을 만든다. expo-video·흰 기본 스플래시는 네이티브 재빌드가 필요하다.
- release ID, 빌드 소스 스냅샷/변경 목록, versionName/Code, 서명 SHA-256, APK/AAB 해시, Play 채널·배포 버전을 서로 연결한다.
- 실제 Play 설치자로 설치한다. 로컬 설치만으로 즉시 업데이트·단계 배포를 판정하지 않는다.
- 계정: 소유자, 편집 가능 동행자, 보기 전용/권한 해제 대상, 신규 회원(생일 없음), 기존 회원(과거 닉네임), 게스트.
- 여행: 진행·완료·보관, 여러 DAY와 연결 일정/비용/영수증, 국가·도시 변경, 기간 축소 대상. 승인된 검수 자료만 사용한다.
- 기기: 위치 서비스/정확한 위치/알림/카메라/사진 권한을 OS에서 조작할 수 있는 Android 실기기. OS·모델·API 수준 기록.
- 접근성: 큰 글꼴·TalkBack·동작 줄이기·백그라운드 왕복. iOS 출시 대상이라면 VoiceOver·설정 복귀는 iOS 기기에서 별도 수행한다.
- R08 운영값은 활성화 전에 별도 확정한다: 최소/권장 versionCode, 배포 가능한 Play 버전, 채널·단계 배포 범위, 정책 유효 시간과 운영 책임자.
- 검수용 시작 정책과 위치/미디어 자료는 일반 사용자 데이터와 구분한다. 현재 미확정 R08 필수 정책은 비활성 상태를 유지한다.

3. 선택 가능한 읽기 전용 USB 사전 점검

사용자 선택에 따라 이번 인수에서는 USB를 사용하지 않는다. 아래 도구는 추후 USB 검수가 필요할 때만 사용한다.
프로젝트 루트에서 실행:
node scripts/qa/android-device-preflight.mjs

여러 기기 또는 명시 SDK 경로:
node scripts/qa/android-device-preflight.mjs --adb "C:/Users/Jichang/AppData/Local/Android/Sdk/platform-tools/adb.exe" --serial 승인한기기일련번호

파일 해시도 기록하려면 위 명령에 --artifact "검수용 APK 또는 AAB 절대경로"를 추가한다.
도구는 설치/삭제/로그 수집/권한 변경/로그인을 하지 않는다. 결과는 outputs/r14-device-preflight.json.
종료0: 기기에서 Play 설치자·현재 versionCode를 확인해 수동 인수를 시작할 수 있음. 실제 인수 통과나 이번 소스 일치를 뜻하지 않는다.
종료2: adb·USB 승인·기기 선택·현재 Play 설치본 준비가 필요함. 출력 reason을 확인한다.
artifact.playAssociation은 항상 unverified다. Play Console 릴리스와 파일의 대응은 QA가 별도로 확인한다.
