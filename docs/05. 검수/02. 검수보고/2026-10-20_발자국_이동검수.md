# 발자국 검색창 삭제와 GNB 다섯 메뉴 복원

검수일: 2026-10-20. 최신 사용자 요청에 따라 발자국의 상단 검색창 행을 삭제하고 로그인 여부와 관계없이 하단 메뉴 다섯 개를 표시했다.

## 변경

- `PublicFootprintsScreen.tsx`에서 `hideSearchBar`를 전달해 독립 검색 입력·검색 실행·조건 아이콘 행을 표시하지 않는다. 조건 칩과 공유 안내는 유지하고 조건 선택 시트의 검색 입력은 보존했다. 기존 `/community` 검색창에는 적용하지 않는다.
- `GlobalNavigation.tsx`의 로그인 상태별 메뉴 제외 조건을 제거했다. 홈·내 여행·여행 만들기·발자국·MY 순서와 기존 이동 동작, 인증 경계, 일정 편집 이탈 확인, 안전 영역, 상세·작성 화면에서 숨기는 규칙은 유지했다.
- 발자국 탭 진입 파일이 개인 기록 화면을 가리키고 있어 공개 일정 목록 `PublicFootprintsScreen`으로 복원했다. 개인 기록은 기존 `/my-footprints`에서 유지한다.
- 화면 전용 표시 옵션을 `communityFeedTypes.ts`에 추가했다. DB 테이블·도메인 객체·API 계약은 변경하지 않았다.

## 참조와 대조

`docs/02. 디자인/00. 공통규격/디자인시스템.md`, `design-tokens.json`, `헤더GNB_규격.md`, `발자국목록_화면규격.md`, `docs/02. 디자인/01. 화면설계/홈온보딩_화면규격.md`와 첨부 GNB 이미지 `codex-clipboard-09b4c7e3-1df1-4387-8490-c4ccb705aa06.png`를 참조했다. 최신 지시를 DESIGN.md와 발자국 규격에 기록했다.

실제 앱의 로컬 브라우저 캡처에서 검색창 행 삭제와 다섯 메뉴 표시를 확인했다. 너비320·390·430에서 메뉴가 화면 안에 있고 발자국 선택 표시가 유지된다. 제목·표지·카드 배치와 글꼴·브랜드·아이콘은 이번 두 가지 요청 범위에서 추가 변경하지 않았다. 첨부와 아이콘 모양·공통 글자 크기까지 완전히 같다는 판정은 하지 않는다.

## 검증

화면 회귀 최종 실행은7/7 통과했다. 너비320·390·430의 기본 화면과390·430의 글자200% 화면을 열어 검색창 삭제·다섯 메뉴·텍스트 줄바꿈을 확인했다. 큰 글자에서는 ‘여행 만들기’가 두 줄로 늘어나며 메뉴를 숨기거나 글자를 축소하지 않는다.

최종 실행 결과는 `outputs/footprints-navigation-20261020/results.json`과 `outputs/footprints-navigation-browser-passed.log`에 기록한다. 기본 화면·조건 선택 시트의 검색/기간/유형 요청·공유/신고의 로그인 경계·사진 없음·더보기/차단 취소·320 기본 글자·390/430의200% 글자·긴 제목·조회 오류와 재시도·빈 목록을 확인한다. 비로그인 내 여행 클릭은 `/login?next=plans`, MY 클릭은 기존 `/login`으로 이동하며 이 검수로 개인 화면을 공개하지 않았다.

이전 실행에서 MY의 기대 주소를 `/login?next=my`로 잘못 지정한 검사 실패가 있었다. 현행 인증 복귀 계약을 확인해 검사만 바로잡았으며 제품의 인증 규칙을 변경하지 않았다. 검수 서버 연결 실패 기록과 첫 실행 로그는 보존한다.

`npm run check` 최종 실행이 통과했다. 디자인 대비·코드 경계·엄격 타입·ESLint·Prettier를 포함하며 기록은 `outputs/footprints-navigation-check-final.log`다. `git diff --check`도 통과했다. 이전 검사 `outputs/footprints-navigation-check.log`는 별도로 보존했다.

캡처는 공개 응답을 격리한 실제 앱 렌더링이다. 북큐슈 제목과 제공받은 썸네일을 검수 자료로 사용했으며 실제 DB를 새로 변경하거나 원격 웹에 반영한 결과가 아니다.

이번 작업에서 원격 배포·DB 쓰기·Android/iOS 빌드·커밋·푸시는 실행하지 않았다. 설치된 앱과 배포 웹에는 후속 빌드·배포가 필요하다.
