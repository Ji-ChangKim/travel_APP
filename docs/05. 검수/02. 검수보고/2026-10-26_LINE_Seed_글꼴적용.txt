LINE Seed 적용 검수 — 2026-10-26 시작

승인 범위
사용자 요청에 따라 앱 일반 UI 글꼴을 LINE Seed로 변경했다. 색상 재정의안은 적용하지 않았으며 기존 색·크기·행간·여백·터치 영역을 유지한다. 로고 Poppins와 Ionicons는 보존한다.

적용 내용
- 한국어: LINE Seed KR, 영어: LINE Seed Sans, 일본어: LINE Seed JP.
- 공식 배포처 https://seed.line.me/index_en.html 에서 받은 TTF Regular/Bold 6개를 assets/fonts/line-seed에 포함. OFL.txt와 출처·원본 경로·크기·SHA-256 manifest를 함께 기록.
- Regular 역할은 400 파일, 기존 Semibold(600)와 Bold(700) 역할은 실제 Bold 파일에 연결. 제공되지 않는 Semibold 파일을 임의 생성하지 않았다.
- AppFontProvider에서 세 언어를 준비하고 AppText·DesignInput·웹 날짜 입력이 언어 선택을 구독한다. 영문/일문 입력 원문은 번역하거나 바꾸지 않는다.
- 웹 혼합 언어는 같은 계열의 대체 글꼴을 순서대로 사용. 네이티브에서 주 글꼴에 없는 혼합 문자는 OS 대체를 사용하므로 별도 실기기 확인이 필요하다.
- 기존 Pretendard 자산은 이전 시안 참조 때문에 보존한다. 현재 홈 HTML 목업은 LINE Seed KR로 변경했다. 과거 정적 헤더 보드는 변경 전 이력이다.
