최종 전체 검사에서는 실제 대기 안내가 57초였고 58.349초 뒤 세션 조회가 200으로 복구됐습니다. 이어서 같은 여행으로 돌아가 DB와 같은 일정을 확인했습니다. 경로·상태·시각·대기 헤더만 남긴 증거는 `outputs/planning-v11/reauthentication-responses.json`입니다.
