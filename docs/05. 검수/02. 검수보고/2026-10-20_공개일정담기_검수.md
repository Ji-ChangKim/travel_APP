# 발자국 일정 담기

사용자 요청에 따라 공개 일정에서 내 여행 저장과 기존 편집기까지 연결한다. 발자국 카드·공개 단건 상세·내 여행 빈 화면의 실제 추천에서 같은 담기 시트를 사용한다. 디자인 기준은 디자인시스템.md·design-tokens.json·헤더GNB_규격.md·발자국목록_화면규격.md·MY_TRIPS_SPEC.md다. 공통 ActionSheet·날짜 선택·48 이상 버튼을 재사용하며 원본 보기와 GNB5개를 유지한다.

## 저장 계약

`POST /api/v1/community/:postId/import`는 인증 세션·공개 ID·출발일·선택 제목·시간대·기본 통화·Idempotency-Key를 받는다. 작성자와 본인 소유권은 세션에서 결정하고 여행 내용은 서버의 현재 공개 행에서만 읽는다. 공개하지 않은 원본 여행을 조회하지 않는다. D1 batch에서 공개 행과 차단 여부를 다시 확인하며 새 여행·owner 멤버·요청 결과를 원자 저장한다. 실패하면 일부 여행을 남기지 않는다. 같은 키의 다른 입력은409, 철회·차단·없는 게시물은404, 입력 오류는422다. D1 미설정 환경은503으로 거부하며 레거시 RPC 구현을 가장하지 않는다.

날짜는 공개 출발일과 실제 일정 날짜의 간격으로 이동한다. 새 여행과 DAY·일정·멤버는 새 UUID다. 공개 DAY 소개·장소 유형·제목·시각·순서·주소·Google Place ID·공개 설명을 보존한다. 본인 역할은owner, 상태는PLANNED, 공개 연결은null이며 동행자는 본인 한 명이다. 원본 항공권 상세·사진·비용·영수증·개인 메모·초대는 복사하지 않는다. 새 여행 편집과 원본 철회는 서로 영향을 주지 않는다.

기기 게스트는 같은 순수 모델로 현재 공개 원본을 읽은 뒤 계정별 기기 문서에만 확정한다. 기기 쓰기 큐·잠금·기존 요청 기록을 사용한다. 회원인 것처럼 원격 저장 성공을 표시하지 않는다. 로그인 전 담기는 기존 인증 복귀 규칙으로 공개 상세 UUID를 보존한다.

## 실제 staging 확인

API 버전 `a664a9a4-1d4b-4b04-b17f-f546b5666391`, 최종 웹 `https://458f1086.tripprint-staging.pages.dev`를 기존 staging 별칭에 반영했다. 이용 주소는 `https://tripprint-staging.pages.dev/footprints`다. 기존 환경 변수·비밀을 유지했으며 DB 마이그레이션은 없다.

실제 브라우저2/2는 `live-final.log`, `live-results.json`, `staging-evidence.json`에 남겼다. 응답 대체 없이 공개 카드의 담기·GNB5개·로그인 후 해당 공개 상세 복귀를 확인했다. 기존 가이드 하루 계정으로 실제 북큐슈 공개 일정의 출발일을12-10으로 선택하면 도착일12-13을 표시하고 확정 행동이 활성화된다. 새 API에는 존재하지 않는 달력 날짜를 보내422로 저장 전 거절되는 것만 확인했다. 전후 공개 게시물과 현재 계정의 여행 목록·버전이 같았으며 실제 DB에는 검수 사본을 만들지 않았다. 회원 DB의 정상 담기·편집 성공은 앞의 로컬 Worker·D1 통합에서 검증한 결과이며 원격 DB 저장 검수로 바꾸어 기록하지 않는다.

## 배포 검수에서 수정한 주소 혼입

첫 웹 배포 검수에서 실제 목록이 조회되지 않았다. 브라우저의 실패 요청 경로를 확인한 결과 상위 환경과 Metro 변환 캐시의 로컬 검수 주소127.0.0.1:8810이 들어 있었다. 해당 번들은 최종 결과에서 제외했다. `.env.release`의 공개 설정을 명시적으로 우선 적용하고 로컬 dotenv를 끈 뒤 `--clear`로 재생성했다. 최종 산출물 검사에는 포트와 관계없이localhost·127 대역·IPv6 루프백 HTTP 주소를 거절하는 회귀 검사를 추가했다. 최종 번들의 주소·비밀·검수 자료 제외를 확인한 후 웹만 다시 배포했고, 실제 조회와 담기 화면2/2로 복구를 확인했다. 초기 진단과 실패 로그는 최종 기록과 구분해 보존했다.

원자 저장 방식의 기준은 [Cloudflare D1 batch 계약](https://developers.cloudflare.com/d1/worker-api/d1-database/#batch)이며 외부 서비스 원문을 명령으로 실행하지 않았다.
