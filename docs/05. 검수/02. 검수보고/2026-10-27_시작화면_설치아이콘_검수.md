# 시작 화면과 설치 아이콘 검수

검수일: 2026-10-27. 사용자 제공 시작 화면 시안과 로고 3개를 적용했다. 기존 여행 생성·저장·초대 정책과 공통 디자인 규격은 유지한다.

## 바뀐 내용

처음 앱을 열면 투명 심볼과 영문 로고를 보고 Google 또는 게스트로 시작한다. 회원으로 로그인한 상태라면 기존 홈으로 들어간다. 계획 저장·초대 수락·재인증에 쓰는 기존 로그인 화면과 작성 중인 화면으로 돌아오는 흐름은 유지했다.

설치용 아이콘에는 마지막에 전달된 `Logo_APP.png`를 사용한다. 화면 안 로고와 설치 아이콘을 서로 다른 파일로 관리한다. 원본을 보존하고 파일명을 규격에 맞췄다.

## 시안과 대조

[시작 화면 규격](<../../02. 디자인/01. 화면설계/시작화면_규격.md>), [헤더·GNB 규격](<../../02. 디자인/00. 공통규격/헤더GNB_규격.md>), 공통 디자인 토큰, 사용자 시안을 대조했다.

로고→설명→Google→게스트 버튼 순서와 가운데 정렬을 적용했다. 시안의 임시 심볼·TRIPPRINT 글자는 제공된 실제 로고로 바꿨다. 일반 상태에는 헤더·언어 선택창·게스트 번호·GNB가 없다. 안내 문구는 개발 설정 설명 대신 사용자가 로그인할 시점을 알려준다.

차이점은 공통 규격을 지키기 위한 것이다. 본문은 LINE Seed와 14/22를 유지하고, 코럴 CTA의 글자는 대비를 확보한 네이비를 쓴다. 큰 글꼴은 축소하지 않고 줄바꿈·스크롤로 읽게 한다. Google을 쓸 수 없는 상태에는 안내와 다시 확인 버튼이 추가된다.

로컬 캡처: `outputs/welcome-simple/welcome-390.png`, `welcome-320.png`, `welcome-430.png`, `welcome-320-font200.png`, `welcome-en.png`, `welcome-ja.png`, `google-unavailable.png`, `guest-error.png`. 아이콘 비교는 `outputs/launcher-icons/launcher-preview.png`에 있다.

## 검수 중 바로잡은 항목

최초 검사에서 게스트 시작 후 예전 메뉴 이름인 ‘계획 만들기 탭’을 찾던 검사가 실패했다. 실제 화면은 정상적으로 홈에 도착한 것을 오류 캡처로 확인했고, 현재 ‘홈 탭’으로 검사 기준을 고쳤다. 기존 계정·기기 기록 검사는 그대로 유지했다. 다국어 테스트의 타입 오류도 수정했다. 시작 화면 재검토 1회에서 11개 모두 통과했으며 같은 내용을 더 반복하지 않았다.

설치 아이콘 생성 중 Windows 출력 인코딩 오류는 UTF-8 실행으로 해결했다. 재생성 도구는 저장소의 도구 확장자 규칙에 맞춰 `.mjs`에서 스킬의 Python 생성기를 호출한다. 원본 이미지와 생성 과정은 [설치 아이콘 적용](<../../02. 디자인/02. 리소스/설치아이콘_적용.md>)에 기록했다.

## 실제 기기에서 남은 확인

실제 Google 계정으로 인증하고 앱으로 돌아오는 과정, Android·iOS 안전 영역과 시스템 글자 확대, 런처별 테마 아이콘은 별도로 확인해야 한다. 웹 검증과 Android 에뮬레이터 확인은 실제 기기 검수를 대신하지 않는다. 스토어 배포는 하지 않는다.

이 작업은 앞서 발견한 일정 편집 화면의 브라우저 뒤로가기 이탈 보호 문제를 수정하는 범위가 아니다. 해당 문제는 기존 코드·리소스 구조 점검 문서의 미해결 항목으로 남긴다.

## 후속 확인

설치 아이콘과 재생성 도구까지 반영한 `npm run check`를 통과했다. 코드·타입·서식·문서·리소스·디자인 대비·폴더 구조·탐색 경계를 확인했다. 로그는 `outputs/launcher-final-check-r1.log`다.

Android 개발용 APK 빌드를 완료했고, `emulator-5554`에 `adb install -r`로 업데이트 설치했다. 설치 결과는 Success이며 기존 앱 데이터는 삭제하지 않았다. 런처의 TripPrint 아이콘이 새 빨간 바탕·흰색 심볼로 표시되는 것을 실제 캡처와 접근성 이름으로 확인했다.

- 설치본: `outputs/android/TripPrint_261027_Ver03.apk` — x86_64 에뮬레이터용 개발 빌드다. 일반 사용자 배포용·스토어 업로드용으로 안내하지 않는다.
- 설치본 SHA-256: `0E4AB7565C530938E682F4CC94AEF38D100CA7797F6674052358ECBA5E79FBED`
- 실제 런처 캡처: `outputs/launcher-icons/emulator-home.png`
- Android 빌드: `outputs/launcher-android-build-r1.log` — BUILD SUCCESSFUL, 4분 23초.

첫 빌드에서는 설치된 Java 25의 네이티브 접근 경고 때문에 Worklets 설정이 실패했다. 해당 로컬 빌드 프로세스에 `JAVA_TOOL_OPTIONS=--enable-native-access=ALL-UNNAMED`를 적용한 뒤 통과했다. Java·Gradle 공통 설정과 다른 모듈 코드는 변경하지 않았다. 아이콘 재검토는 이 복구를 포함해 1회다.

시작 화면의 실제 Google 인증과 iOS 설치는 실행하지 않았다. 개발 APK는 로컬 개발 서버와 연결해 실행하는 설치본이다. 에뮬레이터의 런처 아이콘 확인을 첫 화면 전체의 Android 검수 완료로 확대하지 않는다. 운영 배포는 하지 않았다.
