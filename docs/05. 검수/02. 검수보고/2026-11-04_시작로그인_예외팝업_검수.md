# 시작·로그인 예외 분류와 중앙 팝업 검수

상태: 로컬 웹 검수 통과·설치본 미검증 / 검수일: 2026-11-04 / 대상: `4e175e5` 이후 이번 변경 작업 트리. 다른 작업의 폴더 이동과 기존 변경을 보존하며 현재 경로를 사용한다.

## 요청과 결과 범위

[110개 예외 체크리스트](<../00. 검수기준/시작_로그인_예외체크리스트.md>)를 코드 처리 77개·화면 안 상태 안내 7개·중앙 팝업 26개로 분류했다. ID 110개가 빠짐없이 한 번씩 분류됐음을 확인했다. 이 숫자는 표시 기준의 분류이며, 각 조건의 실서버·실기기 검증 완료 개수가 아니다.

기존 자동 복원·검증·요청 잠금·목적지 정책을 유지했다. 연출 위치 측정이 1,200ms 내 끝나지 않으면 최종 로그인 배치로 복구한다. 자동 처리 실패 중 사용자의 재시도나 선택이 필요한 상태만 중앙 팝업으로 연결했다. Google 이용 가능 여부는 버튼 주변 안내를 유지하고, 사용자가 외부 인증을 취소한 경우 새 오류 팝업을 띄우지 않는다.

Google Play 버튼은 ‘클릭 시 이동’ 로그와 행동 코드만 남긴다. 외부 이동·즉시 업데이트·설치 성공·필수 업데이트 통과를 실행하지 않는다. 필수 업데이트는 클릭 후에도 팝업을 유지하며 선택 업데이트의 현재 버전 사용만 별도로 동작한다.

## 미검증과 후속 조건

Android·iOS 설치본의 실제 안전 영역·시스템 뒤로가기·화면 읽기, 실제 Google 계정 인증 성공과 서버의 기록 저장·이관은 미검증이다. OS 설정·서버 응답을 모사한 웹 검사로 이를 대신 판정하지 않는다.

Google Play 이동·설치·업데이트 취소·스토어 복귀는 사용자 지시에 따라 이번에는 실행하지 않는다. 출시 단계에서 실제 이동을 다시 연결하고 별도 검증해야 한다. 로그가 찍혔다고 업데이트나 설치가 가능하다고 보고하지 않는다.

실제 서버나 정책이 필요한 기록 손상·복구·이관·부분 저장과 모든 경합 순서는 해당 체크리스트의 미검증 항목으로 남긴다. 새 정책을 임의 확정하거나 사용자 기록을 지우는 동작은 추가하지 않았다. 배포·설치는 하지 않았다.
