## 화면 변경

- 발자국 탭 `/footprints` 전체를 기존 공개 피드 기능으로 연결했다. 검색·유형·기간·페이지·공개 상세·신고·차단을 공유한다. 로그인 전에도 공개 목록을 읽을 수 있다.
- 홈의 더보기·둘러보기는 발자국으로 이동한다. 새 북큐슈 일정을 제품 코드에 하드코딩하지 않았다.
- 기존 개인 원본과 완료 판정은 유지했다. 개인 보관함은 `/my-footprints`로 분리하고 내 여행·다이어리에서 연결했다. 로그인 보호와 인증 후 복귀 주소도 분리했다.
- 공개 발자국에서는 넓은 화면에서도 하단 메뉴를 숨기지 않는다. 기존 `/community` 주소도 같은 공개 목록으로 읽고 발자국 메뉴를 선택 표시한다.
- 기존 개인 보관함·다이어리·완료 여행의 DB 원본을 공개하거나 완료 상태로 바꾸지 않았다. 병행 작업의 기존 수정도 보존했다.

참조 규격은 `docs/02. 디자인/00. 공통규격/디자인시스템.md`, `design-tokens.json`, `헤더GNB_규격.md`, `발자국목록_화면규격.md`, `docs/02. 디자인/01. 화면설계/홈온보딩_화면규격.md`다. 화면 제목26/36·왼쪽 정렬·좌우20, 기존 공개 카드와 필터·터치 규격을 유지했다. 320/200%에서 글자가 줄바꿈하며 끝까지 스크롤된다. 390·430·900에서도 같은 제목과 공개 자료를 읽었다.

## 검증과 한계

- 최종 `npm run check` 통과. 디자인 대비69/69·코드 경계 위반0건·엄격 타입·ESLint·Prettier를 새 소스로 확인했다. `git diff --check`도 통과했다.
- 로컬 저장 스키마·변환 모델: 여행 입력과 명령28개 통과. 4DAY·23항목·2개 대체 항목·비공개 메모 제외·예상비용 비공개 확인. 최대 JSON 요청1907바이트.
- 인증 복귀 단위 검사: 11/11 통과. 공개 발자국과 개인 보관함의 접근·복귀 분리를 포함한다.
- 화면 회귀: 7/7 통과. 320/200%, 390·430·900의 공개 카드·첨부 표지·DAY4·오류 재시도·홈 이동·개인 보관함 로그인 보호를 확인했다. HTTP 대체 응답을 사용하는 회귀 검사다.
- 실제 서비스 데이터 화면: 별도2/2 통과. 로컬 앱의 공개 요청을 실제 승인 서버로 전달해 390·900의 실제 게시자·제목·표지·DAY4를 읽었다. 응답 데이터를 새로 만들지 않았다. 화면 이동 후 취소되는 부가 장소 사진 요청은 검수 종료 시 정리했다.
- 실제 DB 원문 대조: 비인증 별도 조회 통과. `outputs/kyushu-plan-20261020/live-verification.json`에 근거를 남겼다. 등록 요청 객체만으로 성공을 판정하지 않았다.

새 발자국 화면 코드는 로컬 앱에서 검수했다. 현재 설치본·배포된 웹에는 화면 변경을 반영하는 새 빌드·배포가 필요하다. DB와 공개 게시물은 이미 반영됐다. Android 실기기·AAB·원격 웹 배포·Git 커밋·푸시는 이번에 실행하지 않았다. Google 장소 사진의 개별 성공이나 미래 영업·운행·예약 전체를 인수한 결과는 아니다.

계정 인증 정보는 사용자가 승인한 Git 제외 폴더 `docs/98. keys/guide-haru-publisher/`에만 저장했다. 내부 식별용 이메일은 수신·복구 주소가 아니며, 비밀번호·세션 토큰을 보고서·로그·명령 인수에 남기지 않았다. 실제 회원 ID는 기존 UUID 계약을 따르며 요청한 관리번호1을 회원 PK로 가장하지 않았다.

인증 파일의 Git 제외·미추적 상태를 확인했고 공개 자료·앱 코드·DB 설명과 보고서322개 파일에서 생성 비밀번호가 검출되지 않았다. 공개 상세 웹 주소도200 응답을 확인했다.
