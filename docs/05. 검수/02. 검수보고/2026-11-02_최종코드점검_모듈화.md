# 최종 코드 점검과 모듈화 · 2026-11-02

## 요청과 범위

함수가 맡는 일을 확인하고, 다른 책임이 섞인 긴 코드와 UI를 나눴다. 한글 주석은 기능의 목적, 인증 순서, 호환성, 실패 처리처럼 코드만으로 알기 어려운 이유를 설명하도록 정리했다. 주석에 이모티콘을 사용하지 않았다.

기존 미커밋 변경을 보존한 작업트리에서 진행했다. 앱·API·공유 패키지의 제품 TypeScript 코드를 자동으로 조사하고 긴 함수와 이번 변경 구간을 수동 검토했다. 모든 함수의 동작을 사람이 전수 검증했다는 의미는 아니다. 운영 배포·운영 데이터 변경·DB 및 API 계약 변경·브랜드 변경은 하지 않았다.

익명 콜백은 함수 길이 표의 수에 포함하지 않았다. 파일이 늘어난 이유는 기능을 추가해서가 아니라 기존 책임을 나눴기 때문이다. 긴 스타일·스키마·콘텐츠 파일은 실행 책임이 섞인 함수와 구분했다.

잔여 긴 함수 30개를 처음 검토한 뒤, HTTP 처리와 UI가 섞인 `PlacePhoto`를 추가로 분리했다. 나머지 29개는 같은 입력 화면 조립, 컨트롤러 연결, 지도 수명, 순수 명령 변환 등의 책임으로 판단했다. 시작 화면 두 곳의 업데이트 실행 중복은 후속 개선 후보로 남겼다. 선택 업데이트와 필수 업데이트의 허용 조건이 달라 이번 작업에서 합치지 않았다.

조사 목록은 로컬 `outputs/final-code-audit/before.json`, `after.json`에 있다. 최종 제품 소스의 파일별 해시는 `source-fingerprint.json`에 기록한다.
