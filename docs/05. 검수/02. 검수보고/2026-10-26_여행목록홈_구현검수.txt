변경
PlanningStartScreen: 여행 목록 중심 홈. 서버 여행·계정별 기기 초안 조회, 정상·빈 상태·오류·재시도, 전체보기.
homeTravelModel: 출발일·현지 날짜 기반 분류 및 D-day 정렬. 가장 가까운 1건과 나머지 최대 3건을 분리한다.
HomeTravelCard/homeTravelStyles: 대형 표지·가로 목록·작성 중 카드, 사진 없으면 #FF00FF, 실제 사진은 기존 권한 확인 경로 사용.
HaruDailyTip: 검수한 상시 팁 6개, 홈 재진입 때 직전과 다른 문구, KR/EN/JP.
HomeHeader: travel-home 유형에서 브랜드는 비활성, 프로필만 조작 가능.
navigationModel/GlobalNavigation/탭 구성/화면 정책: 홈·만들기·커뮤니티 3개, 기존 헤더·터치·글꼴·안전 영역·이탈 보호 재사용.
useWorkspaceNavigationState: 친구 초대에서 동행 화면 직접 진입. 실제 초대 생성이나 전송은 하지 않는다.
HomeDraftResume: 전체보기에서 초안 관리와 이동 전 시트 닫기. 지난 초안도 복원·삭제할 수 있다.
messages.json: 새 고정 문구의 EN/JP 추가.
DB_객체사전: 화면 파생 객체 HomeTravel을 기록. 새 테이블·컬럼·API 변경 없음.
화면 규격 문서: 사용자의 3개 메뉴·새 홈 기준이 이전 계획 만들기 단독 첫 화면보다 우선함을 기록.

검증
단위 검사 7개 통과: 출발일 기반 분류·오늘/과거/동률·잘못된 날짜·언어 키·변수 보존.
공통 헤더/GNB/접근성/복귀 검사 21개 통과: 320/390/430px, 글자 100/200%, 인증 대기·오류·복구, 3개 메뉴와 이탈 보호.
최종 로컬 브라우저 검사 3개 통과: 신규 여행 생성→DAY2 일정 저장, 여행 6건에서 상단1/목록3/전체개수5, 날짜 없는 초안 복원·삭제, 친구 초대 화면과 프로필 이동, 여행 0건·조회 실패·재시도.
목업 렌더링 캡처: outputs/travel-home-mock.png.
앱 캡처: outputs/travel-home/390.png, lower.png, 320.png, 430.png, 320-large.png, empty.png, error.png.
로그: outputs/travel-home-unit.log, travel-home-headers.log, travel-home-final-flow.log, travel-home-final-check.log.
HTTP 응답은 검수용으로 격리했다. 운영 데이터의 저장·초대 전송·배포는 수행하지 않았다.

검토 결과와 남은 차이
시안의 구조를 따르고 브랜드 자산은 기존 TripPrint를 사용했다. 카드 버튼의 모서리·글꼴·터치 규격은 공통 DesignButton을 유지했다.
마젠타 위 제목은 대비 확보를 위해 진한 배경을 추가했다. 큰 글꼴에서는 헤더와 버튼·행이 늘어나며 잘림을 피한다.
항공권·숙소 예약 완료는 검증 근거가 없어 항공편 등록·숙소 일정 등록으로 바꿨다. 임의 예산·가족여행·렌터카 태그는 추가하지 않았다.
날짜 없는 계획은 현재 기기 초안이다. 날짜 미정 상태의 서버 저장·DAY 일정 작성은 후속 데이터 계약 검토가 필요하다.
서버 여행 ID와 초안 멱등 키는 다르다. 기존 저장 성공 후 초안 삭제가 실패하면 내용이 중복 표시될 수 있으며 전체보기에서 초안을 정리할 수 있다. 영구 연결 매핑은 후속 보완 대상이다.
시즌별 팁·최근 7개 노출 이력·원격 콘텐츠 운영은 전략만 문서화했다. 현재 구현은 상시 팁·직전 문구 반복 방지다.
실기기의 안전 영역·폰트·키보드·앱 종료 후 기기 저장 복원·실제 Google 로그인은 별도 검증 대상이다.
구형 홈 배너를 전제로 한 전체 브라우저 테스트 집합은 실행하지 않았으며, 이번 검수 통과는 위 선택 범위에 한정한다.
