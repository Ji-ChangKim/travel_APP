# 발자국 HTML 시안 적용 결과

기준일: 2026-10-20. 첨부한 HTML을 발자국 공개 일정 목록에 적용했다. 이 문서는 로컬 앱의 구현·검수 결과이며 원격 웹 배포나 Android 설치본 반영 결과가 아니다.

## 적용한 화면

- 공식 TripPrint 브랜드 상단바와 계정 이동, 실제 검색 입력·검색 실행·조건 버튼을 배치했다.
- 가로 조건 칩과 하단 선택 시트에서 기존 서버의 검색·기간·공개 유형을 선택한다. 공유 안내는 실제 내 여행 선택 흐름으로 이어진다.
- 사진208, 카드 반경16, 본문 여백16, 화면 좌우20, 카드 사이16, 제목18/26·굵기700을 적용했다. 표지는 실제 공개 사진이며 사진이 없거나 조회에 실패하면 구분해 안내한다.
- 나라·도시, 전체 날짜로 계산한 박·일, 공개 유형, 실제 시작 연월을 배지로 표시한다. 계획과 다녀온 기록의 연월 문구를 구분했다.
- 작성자와 ‘동선 보기’를 같은 카드 하단에 둔다. 동선 보기는 기존 공개 일정 상세로 이동한다. 신고·차단은 카드 더보기로 옮기고 입력·확인·취소·인증 경계를 유지했다.
- 발자국은 PublicFootprintsScreen으로 연결했다. 공통 헤더 작업과 분리해 이 화면에만 브랜드 헤더를 전달한다. 기존 개인 기록은 /my-footprints에 보존한다.

## 검증

- `npm run check` 통과. 엄격 타입·ESLint·Prettier와 디자인 대비·코드 경계 검사를 포함한다.
- 공개 계획 모델6/6 통과. 당일·윤년·연도 경계의 박·일, 읽기 전용 요약의 원본 보존을 확인했다.
- 브라우저12/12 통과. 320·390·430·900, 글자100%·200%, 긴 제목·사진 없음·조회 실패 재시도·홈 진입·검색·기간·유형·공유·신고·차단 취소·개인 보관함 인증을 확인했다.
- 실제 DB 데이터 검수1/1 통과. 새 로컬 앱에서 기존 staging 서버의 공개 GET 응답을 그대로 읽어 북큐슈 제목·가이드 하루·3박4일·2026년12월 계획·실제 표지208 높이와519픽셀 원본·DAY1 상세 로딩을 확인했다. 이 검수에서 DB 쓰기 요청은 실행하지 않았다.
- `git diff --check` 통과. 원격 배포·DB 변경·새 계정 생성·AAB 생성·커밋·푸시를 실행하지 않았다.

결과는 `outputs/footprints-html-20261020/results.json`, `live-results.json`과 `outputs/footprints-html-check-final.log`, `footprints-html-model.log`에 남겼다. 실제 DB 화면은 `outputs/footprints-html-20261020/live-390.png`다. 브라우저 검수가 Android/iOS의 실제 OS 글꼴·보이스오버·실기기 인수를 대신하지 않는다.

별도 표시 없는 화면 파일은 `apps/mobile/src/features/workspace/` 기준이다. 날짜는 비영속 요약에만 추가했으며 테이블·컬럼·API 계약을 바꾸지 않았다. 병행 변경으로 발자국 진입 경로가 개인 보관함으로 돌아간 것을 검수에서 발견해, 최신 사용자 요청의 전용 공개 화면으로 연결을 복원했다. 다른 화면의 공통 헤더 수정은 보존했다.

설치된 앱과 배포 웹에 새 디자인을 보이게 하려면 새 빌드·배포가 필요하다. 기존에 등록한 북큐슈 공개 일정과 썸네일은 그대로 사용한다.
