2026-10-26 KR·EN·JP 언어 선택 및 UI/UX 검수
상태: 로컬 구현·웹 검수, 실기기 검수 별도
범위: 앱 언어 전환, 고정 문구와 접근성 이름, 공통 규격 대조, 핵심 사용자 흐름 회귀

1. 구현 결과
- 로그인 화면과 MY에서 한국어 · KR / English · EN / 日本語 · JP를 선택한다. 내부 코드는 ko/en/ja다.
- 선택한 언어는 이 기기에 보관하고 재실행·로그아웃 후에도 유지한다. 저장 실패 때는 이전 언어와 입력을 유지하고 재시도할 수 있다.
- 앱의 버튼·제목·안내·인증 오류·입력 오류·여행 상태·일정 유형·삭제/공개 확인·접근성 이름에 번역을 연결했다.
- 사용자 여행 제목·닉네임·메모·영수증 상호/메뉴, 저장된 장소명과 외부 콘텐츠는 원문이다. 언어 변경으로 금액·통화·날짜·시간대·권한을 변경하지 않는다.
- 화면을 통째로 다시 마운트하지 않는다. 오류 연결에 쓰는 내부 필드 이름과 번역한 표시 이름을 분리했다.
- 원격 DB, 운영 데이터, 배포 설정은 변경하지 않았다. 커밋·푸시·배포는 하지 않았다.

2. 발견 후 수정한 UI/UX 문제
- 영문·일문에서 달력의 출발일/도착일 표시를 내부 오류 연결 이름으로 비교하면 시작일 대상이 사라지는 문제: 안정적인 시작일/종료일 식별자로 분리.
- 일정 입력란과 헤더 더보기의 고정 한국어가 남던 문제: 표시 이름·접근성 이름 번역 연결. 내부 필드 이름은 유지.
- 메뉴 순번·도시 순번·동적 입력 오류·공개/삭제 안내의 한국어 잔존: 문장 템플릿과 원문 변수를 분리.
- 문구 변환 과정에서 일부 인라인 띄어쓰기가 사라진 문제: 기존 JSX 공백을 복원하고 한국어 회귀로 확인.
- 일본어 본문이 웹 기본 명조체로 표시된 문제: Pretendard를 우선 유지하고 지원하지 않는 글자는 고딕 계열과 sans-serif로 대체. 새로운 외부 글꼴 다운로드는 없다.
- 언어 선택 중 연속 클릭: 화면 상태 갱신 전에도 중복 선택을 차단한다.

공통 색·간격·크기·선택 표시·안전 영역 규칙과 헤더/GNB 배치를 유지했다. 언어 버튼과 공통 선택 시트만 추가했다.
320/390/430px에서 로그인·MY·일정·영수증을 확인한다. 영수증 200% 글자는 높이와 줄바꿈을 늘리고 작은 글씨로 축소하지 않는다.

4. 검증 근거
- npm run check: 문서·디자인 대비·구조·내비게이션 경계·TypeScript·ESLint·Prettier.
- npm run test:auth: 291개 통과. 언어 설정 복구·변수 원문 보존·영문/일문 사전의 변수 일치·명시적 번역 키 누락 검사 4개 포함.
- npm run test:headers:web: 21개 통과. 일본어 글꼴 보정 후 최종 번들에서도 같은 21개 검사 통과. 320/390/430px와 100/200% 글자, 전체 화면의 헤더·GNB·오류/복귀를 확인.
- 다국어 UI 13개: 세 언어 × 세 화면 폭 9개, 언어 저장 실패/재시도, 일본어 로그인 오류·빈 여행·로그아웃, MY 즉시 전환과 프로필 무변경, 지원하지 않는 저장값 복구 4개.
- 9개 연속 흐름은 실제 버튼으로 언어 선택 → 재조회 → 이메일 로그인 → MY → 여행 상세 → 필수 제목 누락 오류의 초점 이동 → 일정 메모 저장 → 영수증 편집·메뉴 추가 → 200% 표시까지 확인한다.
- HTTP 응답을 통제한 로컬 웹 검사다. 실제 Google 로그인, 운영 서버, 실제 OCR 또는 실제 Android/iOS를 검사한 것으로 해석하지 않는다. 사용자 원문과 저장 명령/스냅샷을 비교하며 테스트 성공을 제품의 가짜 성공 응답으로 처리하지 않는다.
- 중간 실패는 숨기지 않는다. 일정 입력 번역과 헤더 접근성 이름 누락을 재현하고 수정했다. 초기 테스트 자체의 배열 순서 가정과 빈 메뉴 가정도 실제 데이터 구조에 맞춰 수정했다.

최종 검사 로그: outputs/i18n-review/check-complete.log, localization-final.log, auth-complete.log, headers-complete.log. 일본어 실제 글꼴 확인: font-verified.log (Pretendard + Yu Gothic).
최종 캡처: outputs/i18n-review/{ko,en,ja}-{320,390,430}-{login,my,receipt-200}.png와 ja-empty-home.png.
로컬 출력은 Git·배포 대상이 아니다. 다른 환경에서는 위 검사 명령으로 다시 만들 수 있다.

5. 남은 실기기·외부 검증
- Android/iOS 설치본의 언어 저장(SecureStore), 재실행, 저장 공간 오류, 앱 종료·복귀.
- 일본어 글리프·실제 기기 글꼴·큰 글꼴, TalkBack/VoiceOver 발음과 오류 초점.
- 키보드·IME·날짜/시간 선택기·사진/카메라·공유 화면. OS 화면의 언어는 시스템 설정의 영향을 받는다.
- 실제 Google OAuth, 설치된 앱의 딥링크, 실제 공유 수신, 카메라/OCR 품질, 느린 네트워크.
- 외부 콘텐츠와 사용자 기록 자동 번역은 이번 범위가 아니다. 일부 장소·콘텐츠 이름은 원문으로 표시된다.

6. 기존 78개 프로세스와의 관계
기존 전체앱78항목 대조 보고의 판정은 이 보고로 일괄 변경하지 않는다. 13개 흐름 검사는 78개 각각의 독립 검증이 아니다.
로그인 복귀 목적 유실, 비밀번호 재설정 미구현, 공유 실패의 복사 대안 등 기존 보고의 미해결 항목은 별도 개발 계획을 유지한다.
언어 선택은 로그인/MY에 추가된 UI이며 기존 화면 번호나 공통 내비게이션을 다시 정의하지 않았다.
