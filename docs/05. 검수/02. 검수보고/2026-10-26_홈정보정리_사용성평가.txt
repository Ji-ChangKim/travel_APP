홈 정보 정리 및 사용성 평가 — 2026-10-26

범위
현재 대화에서 검토한 홈 화면을 대상으로 정리했다. 앱 전체의 기능·여행 데이터·기록을 삭제하지 않았다.
평가는 문서와 실제 화면, 자동화한 사용자 행동 시나리오를 근거로 한다. 실제 사용자 모집 실험이나 만족도 조사 결과가 아니다.

삭제한 정보
1. 추천 제목 아래 ‘계절과 도시의 매력을 담은 하루의 추천이에요.’: 제목과 의미 중복.
2. 추천 도시의 일반적인 테마 문구: 도시 선택에 필요한 구체적 근거가 부족.
3. ‘도시 이야기와 여행 팁 보기 →’: 카드 전체를 누르는 동작과 중복. 화살표와 기존 접근성 이름을 유지.
4. ‘여행자들이 공개한 여행 기록이에요.’: 공개 여행 영역의 제목·카드와 중복.
5. 내 여행 요약의 일반적인 준비 안내: 실제 날짜·상태·다음 일정·이어가기 버튼을 우선.
6. 여행 도구 안의 ‘초대 링크로 참여’: 퀵메뉴 ‘초대 참여’와 목적지 중복.
7. 임시 계획의 빈 지역 행: 입력되지 않은 나라·도시로 빈 공간을 만들지 않음.

정리한 행동 위계
작성 이어가기는 유지하고 임시 계획 삭제는 기존 quiet 보조 버튼으로 낮췄다. 삭제 확인은 유지했다.
사진 출처, 기기 내 저장 안내, 준비 정보의 지원 지역·확인 날짜, 오류와 재시도는 선택과 복구에 필요하므로 남겼다.
장소 가져오기와 네이티브 권한 도구는 접힌 여행 도구에서 접근 가능하다.
헤더·GNB·공통 색상·글꼴·간격은 수정하지 않았다.

평가
정보 위계 — 개선: 추천 사진과 도시, 퀵메뉴, 이어 쓰기가 먼저 보인다. 설명 문장으로 구역을 채우지 않는다.
행동 구분 — 개선: 카드 이동은 화살표로 표시하고 초대 중복 입구를 제거했다. 초안 삭제는 주 행동보다 낮은 비중으로 표시한다.
작업 연속성 — 부분 충족: 기기 내 임시 계획 복원과 저장된 여행 재진입을 제공한다. 최대 5개 초안을 모두 펼쳐 보여주므로 초안이 많으면 아래 콘텐츠가 밀린다. 기기 간 동기화와 미확정 항공권 입력 복원은 이번 범위에 없다.
추천 품질 — 미흡: 월별 편집 목록이며 개인 취향·예산·출발지와 통계 순위를 반영하지 않는다. 인기 순위로 표시하지 않는 현재 문구는 유지해야 한다.
준비 정보 — 부분 충족: 공식 출처와 지역 구분은 유용하지만 일본·동남아 중심이다. 선택한 여행지에 맞춘 자동 구성이 없다.
서비스 차별성 — 미흡: 영수증으로 일정·메뉴를 추가하는 핵심 기능의 진입점이 홈에서 드러나지 않는다. 설명 배너를 다시 늘리기보다 여행 중·여행 후 상황에서 실제 영수증 추가 행동을 제공하는 후속 설계가 필요하다.
공개 여행 — 부분 충족: 실제 공개 기록만 사용하고 더보기의 기록 필터를 유지한다. 기록이 적을 때 탐색할 콘텐츠가 부족하다. 예시 여행으로 채우지 않는다.

세 사용자 관점의 동선 검토
- 처음 여행을 계획하는 사람: 여행지 카드·검색·새 여행 만들기로 시작 가능. 추천 근거와 개인화는 부족.
- 친구에게 일정을 받은 사람: 퀵메뉴 초대 참여를 유지. 실제 외부 공유 링크 수신과 계정별 권한은 이번 UI 정리 검증만으로 완료 처리하지 않음.
- 내 여행을 공유하려는 사람: 내 여행에서 대상을 찾아야 함. 홈에는 공유할 여행을 제안하는 직접 행동이 없어 발견성이 낮음.

후속 우선순위
P1: 여행 상태에 맞는 영수증 추가·여행 이어가기·기록 공유 행동을 실제 기존 흐름에 연결.
P1: 사용 허가와 국가·도시 집계 단위를 확인한 추천 데이터 확보. 현재 편집 추천과 구분.
P2: 초안이 많을 때 최근 항목과 나머지 목록 분리. 삭제·계정 격리·복원은 유지.
P2: 선택한 나라·도시에 맞는 준비 정보 및 앱 추천 확대.
별도 기존 결함: 상하이 가이드 출처 창을 닫으면 스크롤 위치가 이동하는 문제. 이번 홈 문구 정리에서 수정하지 않음.
