홈 정보 구성 개선 검수 — 2026-10-26

승인 상태: 2026-10-26 사용자가 현재 홈 개선안을 우선 적용하도록 승인했다.
반영 상태: 앱 코드에 반영된 개선안을 현행 홈 기준으로 확정했다. 운영 배포·원격 푸시는 하지 않았다.
기존 검증 결과와 아래의 미해결 항목은 유지한다. 승인을 전체 오류 해소나 통계 자동 추천 완료로 해석하지 않는다.

요청과 적용 범위
추천 여행지 → 퀵메뉴 → 작성하던 여행·다가오는 여행 → 여행 준비 → 공개 여행 기록 순서로 홈을 구성했다.
소개용 일러스트 배너를 실제 도시 사진·가이드 카드로 바꿨다. 헤더·GNB 및 공통 디자인 토큰은 유지했다.
여행지 검색은 현재 가이드가 있는 8개 도시를 검색하며, 검색 결과는 실제 도시 상세로 연결한다.
여행 준비 카드는 지원 지역을 밝히고 공식 안내로 연결한다. 앱 설치·결제·예약을 대신 수행하지 않는다.

계획 이어가기
새 여행 작성 화면의 ‘나중에 계속하기’로 계정별 최대 5개 초안을 이 기기에 저장한다.
입력값과 작성 단계, 생성 멱등 키를 보존한다. 홈에서 다시 열고, 확인 후 삭제할 수 있다.
저장 실패 시 현재 입력과 화면을 유지한다. 다른 계정의 저장값이나 손상된 값은 복원하지 않는다.
서버 여행에는 수정 시각 필드가 없어 최근 수정 순위를 만들지 않았다. 기존 진행 중·다가오는 여행 선택 규칙을 유지했다.
정식 생성 성공 후 해당 초안을 정리한다. 정리 실패가 서버 생성 성공을 실패로 바꾸지 않으며 같은 멱등 키로 중복 생성 위험을 줄인다.
초안은 기기별 저장이다. 브라우저 저장 데이터 삭제 시 복원할 수 없고, 다른 기기와 동기화하지 않는다.

추천 데이터의 범위와 남은 과제
월에 따라 자동 선택되는 3개 도시는 편집 추천이다. ‘한국인이 작년 이맘때 많이 간 곳’으로 표시하지 않는다.
한국관광 데이터랩의 2025년 10월 주요 목적지 통계는 국가 단위 자료이며 도시별 순위를 증명하지 않는다.
확인한 게시물은 공공누리 제4유형(출처 표시·상업적 이용 금지·변경 금지)이므로 이 자료를 변환한 상용 순위 자동화를 연결하지 않았다.
후속 개발: 상용 이용·가공이 허용되는 데이터 확보 → 국가·도시 집계 단위 분리 → 기준월·출처·수집 실패 처리 → 정기 갱신.
별도 하루 추천 일정 카탈로그 확장은 남은 과제다. 이번 홈에서는 상단의 하루 추천 도시 가이드와 실제 공개 여행 기록을 제공한다.
