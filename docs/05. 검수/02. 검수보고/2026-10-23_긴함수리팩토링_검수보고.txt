검사 중 확인한 문제

기존 saveEditor 검수 도구가 선택창을 닫는 순간의 DOM을 읽어 재시도 버튼을 기다렸다.
실제 다음·저장·재시도 행동이 보일 때까지 기다리고, 다음 단계 전환 자체도 확인하도록 고쳤다.
기능을 통과시키려고 제품 검증이나 기대 결과를 완화하지 않는다.
수정 중 시작한 최초 번들 검사는 새 파일 생성과 겹쳐 실패했으며 승인 근거에서 제외한다.
새 소스로 완성한 격리 번들만 최종 화면 검수에 사용한다.

공개 화면에서 Escape로 이탈 확인창을 열면 같은 키의 keyup이 새 확인창까지 닫는 실제 오류를 발견했다.
앱은 keydown, React Native Web 모달은 keyup에서 닫기를 처리하고 있었다.
공통 모달의 Escape를 keyup으로 맞추고 최상위 창 하나만 처리하도록 수정했다.
공개 미리보기·헤더 복귀·Escape·폼 재진입·저장 중 뒤로가기 검사를 보강했다.
중첩 창·초점 복귀·이탈 보호와 헤더·GNB도 수정본으로 다시 검사한다.

기존 시간대 입력 도우미에도 선택창 전환 중 헤더가 잠깐 없는 상태를 잘못 읽는 같은 문제가 있었다.
제거된 여행 생성 시간대 입력과 실제 편집 입력을, 화면이 나타난 뒤 구분하도록 수정했다.
