TripPrint 고객 여행 기록 개선 처리표
기준일: 2026-10-16 / Asia/Seoul
범위: 기획 고객여정_검토.txt CJ-01~07의 기능·API 보완과 빌드 전 준비. 공통 헤더의 병행 변경 보존. AAB/APK 생성·원격 배포·업로드·커밋·푸시 미실행.
현재 판정: 로컬 고객 흐름 기능 보완·회귀 통과. 기획 독립 인수10/10 통과로 로컬 고객 흐름 승인. 운영 조건 미충족으로 빌드/배포 준비는 HOLD. 실제 공급자·설치본 인수와 전체 출시 승인은 별도.

CJ-01 / 수용·수정
FlightTicketEditor에 항공권 직접 입력을 추가. 항공사 조회 결과가 없어도 편명·서로 다른 공항·현지 출발일/시각을 공통 계약으로 검증. 도착일/시각·터미널은 선택 입력이며 누락 정보를 생성하지 않음.
조회·직접 입력 전환과 목록 복귀 시 슬롯별 임시 입력 보존. 완료 시 해당 슬롯만 목록에 반영. 출발/도착/추가편은 기존 flights 배열과 각 출발일 DAY에 연결.
기존 ‘수동 버튼 없음’ 검사를 변경. 조회0건/503·지난 왕복/추가편·뒤로가기 초안·저장 재조회 회귀 추가.

CJ-02 / 기존 보완 유지·운영 조건 미충족
지난 날짜라는 이유로 일정 저장을 막지 않음. 지도·검색 실패와 별도로 제목·메모 등 직접 입력을 유지. 기획 채팅의 빈 지도·DAY2 검색·응답 취소 보완을 보존.
staging GOOGLE_PLACES_API_KEY 미등록, Android 지도 키의 Play 앱 서명 제한·실제 타일 미확인. 실제 Google 검색은 이번 검사에서 호출하지 않음.

CJ-03 / 수용·수정
발자국과 내 여행에 ‘다녀온 여행 기록하기’ 추가. /new-trip?mode=record로 기존 생성·저장 계약 사용. 과거 종료일을 입력한 일반 생성도 기록 문구로 전환. 날짜를 자동 채우거나 새 여행을 복제하지 않음.

CJ-04 / 수용·수정·외부 미검수
촬영/앨범→비공개 원본 등록→인식 초안→확인/수정→일정/실제 지출 연결 흐름 유지. 저장된 영수증의 수정 경로 추가.
receipt.update는 기존 영수증·실제 지출 ID를 유지하고 같은 batch에서 교체. keepPhoto=false인 수정에서 이미 제거한 media.path를 읽던 오류 수정. 사진 보관 선택 변경·다른 원본 탈취·빈 연결의 새 장소 생성 거부.
원본 보관 여부와 관계없이 수정/삭제·재조회·공개 제외를 로컬 모델 및 브라우저로 검증 완료. D1 HTTP 명령으로 기존 ID의 수정·재조회도 확인. 실제 staging 회원 OCR/AI·카메라·R2 업로드 성공은 미검수.

CJ-05 / 수용·수정
비용 허브는 실제 지출과 사용한 통화부터 표시. 예상 비용은 명시적으로 펼침. 다이어리와 같은 정확한 정수 소수 합산 사용. 지원 통화 KRW/JPY/USD를 분리하며 환산하지 않음.
직접1000 KRW+영수증2500 JPY+예상500 JPY에서 실제1000 KRW/2500 JPY, 예상500 JPY 확인. 영수증 금액 수정 시 같은 지출 교체, 삭제 시 동일 ID 지출 제거. 재공개 전 기존 공개 게시물은 자동 변경하지 않음.

CJ-06 / 수용·수정
공개 화면에서 ‘기록 정리 마치기’→바텀시트의 ‘기록 정리 완료’→‘공개 내용 작성’으로 연결. 날짜 경과만으로 저장 status/게시를 변경하지 않음. 취소 시 명령 없음.
정리 완료 후에도 공개는 별도 선택·미리보기·게시. 소유자·보관/조회 권한·명시적 선택·원본 제외 계약 유지.

CJ-07 / 수용·수정
다이어리에 ‘기록 더 추가’와 ‘여행 경비 요약’ 추가. 같은 여행 ID로 복귀. viewer/보관 상태에서는 추가 행동을 표시하지 않음.
게스트는 이 기기의 문서·사진 보관이며 회원의 서버 보관과 구분해 안내. 공개 철회 후 비공개 영수증/사진/지출/일정 보존을 검사. 실제 재로그인·다른 기기 보존은 별도 인수.
