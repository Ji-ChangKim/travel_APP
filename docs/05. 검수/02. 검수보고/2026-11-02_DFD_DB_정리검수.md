## 요청과 변경 범위

최초 `check:docs` 실행은 임시 테스트 폴더의 Windows junction 생성에서 `EPERM`으로 실패했습니다. 같은 명령을 샌드박스 밖에서 재실행해 5개 테스트와 전체 문서 연결 검사를 모두 통과했습니다. 검사 코드를 바꾸거나 건너뛰지 않았습니다.

Mermaid 그림은 코드 경계·저장소·데이터 이름을 대조했습니다. 별도 렌더러의 화면 배치·이미지 출력 검수는 실행하지 않았습니다.

문서만 변경했으므로 전체 `npm run check`, 인증·헤더·API 동작 회귀 검사와 Android 빌드는 실행 대상에서 제외했습니다. DB-DOC-01은 SQL의 빈 로컬 적용 검사이며 기존 데이터의 마이그레이션 안전성이나 Cloudflare D1 서비스 동작을 보증하지 않습니다. Mermaid는 문서 안의 기술 흐름도이며 실제 앱 화면 시안이 아닙니다.

## 남은 확인

- 승인 정책의 초대 7일·기존 멤버 미소비와 현재 코드의 차이는 구현 작업으로 남습니다.
- 영수증 확인과 본인 방문·원본 진위 보증을 구분합니다. 별도 방문 모델·인증 배지는 이번에 추가하지 않았습니다.
- `0010_home_server_data.sql`까지 원격 D1에 적용됐는지 확인하지 않았습니다. 새 현행 명세는 저장소의 SQL을 기준으로 합니다.
- 이전 V11 HTML 흐름도와 검수 결과는 당시 범위로 보존합니다. 현행 전체 흐름은 새 DFD를 기준으로 읽습니다.
