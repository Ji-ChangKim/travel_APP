# BI 배경·중앙 배치 검수

상태: 로컬 웹 검수, 설치본 미검증 / 검수일: 2026-11-04 / 대상: `b913093` 이후 이번 변경 작업 트리.

## 요청과 적용

사용자가 첨부한 HTML의 배경색과 로고 위치만 참조했다. 위 `#FFF9F6` → 아래 `#FFF0EC`의 세로 그라데이션을 BI에 적용했다. 기존 원본 심볼의 너비 160과 비율을 유지하고, 앱 표시 영역 전체의 가로·세로 중앙에 배치했다. 첨부의 외부 이미지·글꼴·스크립트·82vh 높이는 가져오지 않았다.

BI의 장식 로고에서 안전 영역 여백을 제거했다. 이미지 실패 시 브랜드 글자도 같은 중앙에 둔다. 로그인으로 넘어가는 이동용 로고 역시 전체 영역의 중앙에서 시작한다. 최종 상단 로고와 버튼은 기존 안전 영역을 유지한다. BI 배경은 심볼 이동 640ms에 맞춰 사라지고 기존 로그인 canvas로 이어진다.

OS 스플래시는 단색 `#FFF9F6`을 사용하도록 설정했다. 그라데이션은 React BI에서 표시한다. 네이티브 설정은 새 설치본 빌드가 필요하며 이번에 기기에 반영한 것은 아니다. 일반 화면·로그인 완료 배경·공통 헤더·GNB·인증 정책·DB는 변경하지 않았다.

증거는 `outputs/startup-motion-app/`에 보관했다. `bi-390x844.png`, `bi-320x568.png`, `bi-844x390.png`와 실제 로그인 캡처 `login-390.png`를 직접 열어 배경·중앙·원본 비율·최종 버튼 배치를 대조했다. 나머지 크기는 좌표·배경 자동 검사와 캡처를 남겼다. 작은 화면·큰 글자·오류 상태는 실제 앱 웹 검사에 포함했다.

최초 추가 검사에서는 웹 안전 영역 측정 요소가 두 개인데 단일 요소로 선택해 5개가 실패했다. 측정 요소 모두에 같은 시험 값을 적용하고 각각 복귀 이벤트를 전달하도록 수정했다. 검사 코드의 첫 프레임 누락 가능성도 엄격 타입 검사에 맞춰 명시적으로 처리했다. 앱 동작의 기대 좌표·허용 오차·안전 영역 기준은 낮추지 않았다. 수정 후 16개가 모두 통과했다.

필수 `npm run check`는 최종 종료 코드 0으로 통과했다. 문서·디자인 대비·리소스·구조·헤더/GNB 경계·TypeScript·ESLint·Prettier를 포함한다. 로그는 `outputs/startup-motion-app/bi-check.log`다. 헤더·GNB 경계 검사는 452개 소스·23개 화면에서 위반 0건이었다. 검수 보고 추가 후 문서 링크·서식도 다시 확인한다.

## 미실행과 남은 차이

- Android·iOS 설치본은 미검증이다. 기기의 실제 표시 영역·노치·시스템 바·멀티윈도·새 OS 스플래시 반영은 빌드·설치 후 확인해야 한다. 웹의 안전 영역 모사를 실기기 통과로 보고하지 않는다.
- 실제 Google 인증·서버 저장은 이번 표시 변경의 검수 범위에서 실행하지 않았다. 기존 110개 예외 체크리스트 전체를 통과한 것으로 보지 않는다.
- 공통 헤더·GNB·뒤로가기·이탈 보호 로직은 변경하지 않아 해당 웹 검사 묶음을 재실행하지 않았다. 필수 검사에 포함된 경계 검사는 별도로 확인한다.
- 운영 배포·기기 설치·의존성 추가·DB 변경은 수행하지 않았다. 기존 작업 트리의 체크리스트·이전 검수 보고 변경을 보존했다.
