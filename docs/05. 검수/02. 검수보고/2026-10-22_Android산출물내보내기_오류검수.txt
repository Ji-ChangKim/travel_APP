Android 산출물 내보내기 오류 검수
검토일: 2026-10-22
상태: 기존 AAB 복구 및 코드 품질 검사 통과
범위: Android Studio의 :app:bundleRelease 후처리 오류

확인 결과

스크린샷의 실패 지점은 scripts/android/android-export.gradle에서 Node 내보내기 작업을 실행하는 부분이다.
원본 apps/mobile/android/app/release/app-release.aab와 14:58에 만들어진
TripPrint_261022_Ver01.aab.partial이 남아 있었고, 두 파일의 SHA-256이 일치했다.
앱 번들 생성과 서명은 끝났으며, 출력 폴더에서 최종 파일명으로 내보내는 후처리가 실패했다.

기존 Gradle 코드는 Node의 표준 오류를 캡처한 뒤 화면에 보여주지 않았다.
따라서 원래 IDE 실행의 OS 오류 코드와 잠금을 일으킨 프로세스는 확인할 수 없다.
복사가 끝난 .partial만 남았다는 점에서 최종 파일명 변경 실패가 유력하다.
별도 검사에서는 샌드박스의 rename EPERM을 재현했지만 일반 권한에서는 통과했다.
이 재현을 원래 IDE 실행의 오류 코드나 백신 잠금의 증거로 간주하지 않는다.

수정 내용

- export-android-build.mjs: EPERM·EACCES·EBUSY에 한해 최대 5.1초 동안 재시도한다.
  다른 오류는 즉시 중단한다. 기존 파일을 덮어쓰지 않으며 실패한 임시 파일을 보존한다.
- android-export.gradle: Node 종료 코드, 표준 오류, 원본 경로를 실패 메시지에 표시한다.
  성공하면 실제 내보낸 파일 경로를 표시해 출력 폴더 환경 변수도 반영한다.
- public/release.json: 기존 ver.text의 12/0.1.0과 릴리스 안내를 맞췄다.
  ver.text 자체는 변경하지 않았다. 원격 웹에는 배포하지 않았다.
- check-docs.mjs: 문서 관리 규칙에 따라 비공개 98. keys 내부를 순회하지 않는다.
  비공개 영역 안의 기존 호환용 junction으로 발생하던 검사 오류를 해소했다.
  비공개 키 파일 내용과 연결 대상은 수정하지 않았다.
- 헤더GNB_규격.md: 기존 목록 앞에 누락된 빈 줄 하나를 추가해 서식 검사를 맞췄다.
  문서의 규격 내용과 화면 구현은 변경하지 않았다.
