# DEV-00~02 신규 계획 개발·검수 기록

작성일: 2026-10-27. 운영 배포 없음.

## 이번에 연결한 흐름

여행 기본 정보 입력 → 저장할 때 로그인 → 같은 입력으로 돌아오기 → 사용자가 저장 확인 → 초안 또는 여행 저장 → 서버에서 다시 읽기.

- 로그인 전에도 새 여행의 기본 정보를 입력합니다. 항공권 단계로 넘어가거나 저장하려면 회원 로그인이 필요합니다.
- 로그인 뒤 자동으로 저장하지 않습니다. 같은 여행 이름·나라·날짜와 생성 요청 ID를 복원합니다.
- 웹은 외부 로그인 왕복을 위해 같은 탭에 최대 1시간 임시 보관합니다. 앱은 현재 실행 메모리를 사용합니다. 종료 후 복원을 보장하지 않습니다.
- 회원으로 복원한 입력은 그 계정에 귀속합니다. 다른 계정에는 전달하지 않습니다.
- 초안을 저장해도 작성 화면에 남습니다. 서버가 반환한 버전을 다음 저장과 여행 생성에 사용합니다.
- 여행 생성·명시적 폐기 때 인증 복귀 자료를 지웁니다. 초안 저장 때는 실제 저장한 내용과 버전으로 갱신합니다.
- 서버는 게스트의 새 여행 생성·공개 여행 담기·초안 쓰기를 거절합니다. 이전 게스트 자료 조회와 계정 연결은 유지합니다.

## 변경 범위

앱: 공개 신규 계획 진입, 로그인 복귀 보관, 복귀 목적 검증, 초안 저장 피드백, 여행 저장의 회원 확인, 이탈 보호.
서버: 검증한 익명 회원 여부 전달 및 생성·초안 쓰기 차단. DB 스키마 변경 없음.
문서: DB 객체사전에 인증 세션과 복귀 자료의 수명·정리 규칙 추가.
검수: 신규 계획 흐름, 인증 단위 검사, 실제 로컬 Worker/D1 검사, 공통 헤더 회귀.

## 기존 동작 확인

첫 로컬 검사는 실행 환경의 통신 제한으로 중단됐습니다. 로컬 실행 권한을 적용한 뒤에는 회원가입과 프로필 설정까지 진행했습니다. 이후 홈 버튼의 바뀐 이름을 예전 테스트가 찾고 있어 중단됐습니다. 현재 접근성 이름으로 검사 대상을 수정했습니다. 로그인 실패로 분류하지 않습니다.

## 디자인과 리소스

기준: 디자인시스템.md, design-tokens.json, 헤더GNB_규격.md. 공통 헤더·버튼·LINE Seed 글꼴·색상·간격을 유지합니다. ui-ux-pro-max의 폼 오류·피드백 기준으로 입력 유지, 저장 중 잠금, 다시 시도 안내를 대조합니다.
이번에는 새 아이콘이나 썸네일이 필요하지 않습니다. 기존 브랜드와 하루 이미지를 사용합니다. icon-generator는 앱 설치 아이콘 출력 도구이므로 화면 아이콘을 임의의 비트맵으로 교체하지 않습니다. imagegen 생성물은 추가하지 않았습니다.

실제 화면 확인: outputs/planning-v11/00-login-return-draft-saved-390.png, 01-dates-destination-390.png, 03-restored-320-large.png를 열어 공통 헤더·본문·저장 피드백과 큰 글꼴 줄바꿈을 확인했습니다. 신규 화면 레이아웃이나 공통 토큰을 바꾸지 않았습니다. 모든 페이지의 시각 검수와 실기기 검수 완료를 뜻하지 않습니다.

DEV-00은 로컬 검수 기반과 기존 실패 원인을 확인했습니다. DEV-01~02의 핵심 연결은 구현·검증했습니다. 전체 완료 판정에는 기존 헤더/GNB 검사 정리와 실기기 검증이 남습니다. 최대 초안 수·버전 충돌은 기존 서버 정책을 유지하며, 화면 안내는 한도와 충돌 가능성을 함께 알립니다. 원인별 안내 세분화는 후속 작업입니다.

## 실기기에서 남은 확인

- Android/iOS Google 로그인: 외부 앱 왕복, 취소, 로그인 후 프로필 설정 복귀.
- 앱이 백그라운드에서 종료된 경우: 이전 입력을 복구했다고 잘못 안내하지 않는지 확인.
- 기기 키보드·안전 영역·큰 글꼴에서 입력·CTA 접근 확인.
- 실제 배포 환경 OAuth 설정과 DB 적용 상태. 이번에는 운영 서버·운영 DB를 변경하지 않았습니다.
