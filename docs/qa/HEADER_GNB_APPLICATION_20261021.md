# 헤더·GNB 실제 앱 적용 검수

기준일: 2026-10-21. 사용자 요청 범위는 공통 헤더·하단 탐색·관련 복귀와 작성 보호다. Android 빌드와 외부 서버·웹 배포는 실행하지 않는다. 이번 변경에 DB 스키마 변경은 없다.

## 적용 기준

- `docs/design/DESIGN.md`
- `docs/design/design-tokens.json` 3.0.4
- `docs/design/SCREEN_HEADER_SPEC.md`
- `docs/design/headers/index.html`의 H01~H08 비교판
- `docs/1.uiux/`의 화면별 승인 기준, 홈·내 여행·발자국의 최신 화면 예외

정적 비교판과 실제 앱은 구분한다. 아래 검수에는 Expo의 실제 앱 컴포넌트를 웹으로 내보낸 로컬 번들을 사용한다. 인증·여행 API 응답은 테스트의 HTTP 경계에서 격리하며 실제 사용자의 계정이나 DB에 검수 자료를 넣지 않는다.

## 검증 기록

- `npm run test:headers:web`: 13개 통과. 33개 화면·상태를320·390·430 × 글자100%·200%로 검수하고198회 캡처했다. 헤더6개 조건·WCAG3개·GNB3개·복귀1개 시나리오다.
- 관련 브라우저 동작: 18개 통과. 새 여행·비용·프로필·정보·기간·공개·영수증의 이탈 보호, 저장 중 닫기 잠금, 모달·페이지·장소 슬라이드 시간, 동작 줄이기, 백그라운드 복귀, 검색 조건 유지와 직접 링크 복귀를 확인했다. 앞의 GNB·복귀4개 시나리오를 포함한 재검증이다.
- 관련 단위 검사: 접근성 전환·저장 세션·폼 명령19개 통과. 접근성 확인 전/화면 읽기/동작 줄이기/배경의 즉시 전환, 늦은 전환 완료 폐기, 저장·충돌·재시도 계약을 확인했다.
- 색상 대비: 기존 조합과 GNB6개 상태를 포함한75/75 통과. 실제 페이지의 입력·안내·눌림·비활성 대비 검사도 통과했다.

### 실제 캡처와 규격판 대조

- `plans-390-100.png`: 제목·검색·계정이 공통 기준선과 크기로 표시된다. 중복 홈 복귀 없음.
- `plans-320-200.png`: 제목은 줄바꿈하며 검색·계정 터치 영역과 겹치지 않는다.
- `gnb-320-200.png`: 라벨 줄 수가 달라도 일반 아이콘의 시작선이 같다. 중앙 원은56, 선택 영역은48×28이며 라벨을 자르지 않는다.
- `receipt-capture-320-200.png`: 촬영 안내에도 동일 헤더가 보이고 내용은 아래까지 스크롤할 수 있다.
- `public-error-320-200.png`, `profile-320-200.png`: 오류 복귀·큰 제목·시트 본문 스크롤과 배경 메뉴 차단을 확인했다.

정적 H01~H08 규격판과 실제 앱 캡처를 대조해 제목·아이콘·폰트·색·줄바꿈을 확인했다. 큰 글꼴에서는 브랜드의 계정 행동과 제목이 필요한 높이만큼 늘어나는 것이 정상이다. 기존 본문 카드·사진·브랜드 색 범위는 유지한다. 기기별 안전 영역과 TalkBack 실제 발화는 아래 후속 검수 범위로 남긴다.

## 확인 범위와 남은 기기 검수

브라우저의320·390·430 논리 폭, 글자100%·200%, 키보드 초점·Escape·브라우저 뒤로가기·동작 줄이기·가시성 변경을 검사한다. 이 결과는 Android 실기기의 TalkBack 발화, 운영체제 글자 배율, 키보드·노치·제스처 안전 영역, 시스템 뒤로가기 실기기 검수를 대체하지 않는다. Android 빌드는 사용자 요청에 따라 하지 않는다.

## 검수 중 발견한 보완

- 공개 상세 오류 안내의 이전 메뉴명 `발견`을 `발자국`으로 통일했다. 마지막390 캡처와 복귀 검사에서 수정 문구를 확인했다.
- 이전 테스트가 공개 발자국에서 개인 보관함 제목을 찾던 부분을 현재 두 화면의 주소로 분리했다. 기존 대비 검사는 유지했다.
- 기본 높이56과48 터치+상하6의 실제60 높이를 구분해 검사했다. 제목만 있는 행은 최소56이다.
- 200% 캡처에서 라벨 줄 수에 따라 GNB 아이콘 기준선이 달라지는 문제를 발견해 공통 아이콘 자리를 확보했다.
- 병행 작업으로 들어온 폼 명령 테스트 자료의 필수 nullable 속성(timeSlot/memo/address)을 보완했다. 제품 데이터 계약을 느슨하게 하지 않았다.
- 저장 세션을 구성하는 콜백 팩토리는 렌더 중 ref를 읽지 않는다. 컨트롤러에서 훅 역할이 드러나는 이름으로 연결해 React 검사기의 호출 의미를 명확히 했다. 저장·재시도 동작은 바꾸지 않았다.
