사용자 요구
제공한 원문은 4일 여행계획 전체다. 커뮤니티는 계획 요약 카드에서 일차별 장소·선택지·설명·메뉴·팁을 여는 구조로 제공한다. 긴 본문에 원문을 붙이거나 요약문으로 대체하지 않는다.
원본: tests/fixtures/osaka-community-source.txt. 사용자 첨부 원문을 복사했다. 일차별 장소 수는8/7/3/1, 총19곳이다. 일차 제목·컨셉과 장소 설명을 분리해 재조합한 결과, 공백을 제외한 원문의 모든 문장이 일치한다. 장소별 설명 최대350자다.
원문의 평점·가격·영업 표시는 입력 당시 자료로 보존한다. 실시간 조회 결과나 실제 결제금액으로 바꾸지 않는다. 없는 주소·좌표·방문 시각·항공편·사진·지출을 생성하지 않는다.

실제 기능 보완
- DAY의 planTitle/planConcept를 저장하고 같은 DAY ID로 수정한다.
- 일정의 planContent.description에 장소별 원문 전체를 저장한다. 비공개 memo와 분리한다.
- 카페/저녁의 choiceGroup·choiceLabel, 대체 지점의 choiceKind를 저장한다. 모든 후보를 필수 방문으로 표시하지 않는다.
- kind=plan으로 명시한 계획 공유는 PLANNED 상태에서도 가능하다. 여행을 COMPLETED로 바꾸지 않는다. 최소1곳 이상 선택해야 한다.
- 커뮤니티는 일차·장소 수가 있는 요약 카드와 ‘여행계획 열어보기’를 제공한다. 공개 상세 /community/[postId]에서 DAY를 고르고 장소 설명을 펼친다.
- 상세는 공개 선택 순서와 관계없이 저장한 sortOrder로 방문 순서를 표시한다. 비공개 메모·영수증·미선택 장소는 공개하지 않는다.
- 단건 공개 API로 오래된 계획도 직접 열 수 있다. 철회/없는 글404에서는 다시 시도와 커뮤니티 복귀를 제공한다.
- 기존 여행기록 공개의 완료 조건과 사진·비용 선택은 유지한다. 게시 본문2000자·서버 요청16KiB 상한은 유지한다.

검수용 날짜
원문에는 실제 달력 날짜가 없다. 기존 개인 여행 저장 계약 때문에 내부 QA 여행에는2026-10-01~10-04를 사용한다. 실제 여행일로 간주하지 않고 공유 화면은 DAY1~4로 표시한다. 계획 소개에도 검수용 날짜임을 밝힌다.
