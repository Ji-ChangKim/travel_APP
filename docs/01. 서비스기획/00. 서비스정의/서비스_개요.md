# 서비스 개요

## 1. 서비스 정의

**TripPrint**는 여행 계획을 세우고, 여행 중·여행 후 영수증과 사진으로 실제 방문과 지출을 기록하며, 직접 선택한 여행 일정만 커뮤니티(발자국)에 공유하는 모바일·웹 여행 서비스입니다.

---

## 2. 핵심 가치

1. **간편한 여행 계획**: 목적지, 기간, 동행 여부만 고르면 일차별(`DAY 1~N`) 타임라인과 예산을 즉시 구성합니다.
2. **영수증 기반 실제 방문·지출 기록**: 영수증 촬영·업로드(OCR)로 상호, 결제 일시, 통화, 총액, 품목(메뉴)을 추출하고 사용자 확인을 거쳐 일정·가계부에 반영합니다.
3. **기본 비공개와 선택적 공유**: 모든 여행 기록과 원본 영수증은 기본적으로 비공개이며, 소유자가 직접 선택한 일정·사진·총액 요약만 발자국에 공개합니다.

---

## 3. 지원 환경 및 계정 체계

- **지원 플랫폼**: Android 앱, iOS 앱, 반응형 모바일/데스크톱 웹 (`apps/mobile`, Expo Router 기반)
- **백엔드 인프라**: Cloudflare Workers + Hono, Cloudflare D1(SQLite), 비공개 Cloudflare R2, Better Auth
- **계정 모드**:
  - **게스트 모드**: 로그인 없이 이 기기 저장소에서 여행 계획·일정·영수증 기록을 즉시 사용합니다.
  - **회원 모드**: Google·카카오·네이버 로그인 및 프로필 설정 완료 후 서버 동기화, 동행자 초대, 발자국 공개 기능을 사용합니다.
