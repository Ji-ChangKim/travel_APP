# 여행 핵심 정책 확정 사항

2026-11-02 핵심 흐름 적용: 계획 생성부터 세부 일정 저장·재진입까지의 공통 기준은 [계획 생성·일정 저장 정책](계획생성_일정저장_정책.md)을 따릅니다. 날짜가 있는 서버 초안도 정식 생성 전에는 작성 중이며, 위·아래 다음과 저장 후 날짜 복귀가 같은 계약을 따릅니다. 아래 네 확정 정책은 유지합니다.

확정일: 2026-10-27 / 상태: 사용자 승인 / 적용 범위: 신규 계획·동행 초대·공개 공유와 관련 인증·저장

승인 근거: 사용자가 “네 가지 정책은 권장안대로 진행하자”라고 결정했습니다. 이 문서가 아래 네 정책의 현행 기준입니다. [코드 대조와 대안](<../03. 검토안/핵심정책_구현대조_선택안.md>)은 결정 이력으로 남깁니다. 정책 확정은 구현·배포·실제 검증 완료를 뜻하지 않습니다.

## 1. 기본 정보는 로그인 전에 입력합니다

- 여행 이름·목적지·날짜 등 기본 정보는 정식 로그인 전에 입력할 수 있습니다.
- 서버 초안 저장·여행 생성, 동행 초대 발급·수락, 공개 발행은 정식 로그인 후 진행합니다. 영수증·사진의 새 업로드도 로그인 이후로 둡니다.
- 익명 게스트 세션을 정식 로그인으로 취급하지 않습니다. 앱과 서버가 같은 기준으로 제한해야 합니다.
- 저장을 선택하면 로그인하고, 필요한 회원 설정을 마친 뒤 입력하던 곳으로 돌아옵니다. 로그인 왕복·취소 동안 기본 정보를 보존하고 실제 저장은 사용자의 의도를 확인한 뒤 진행합니다. 로그인 성공만으로 여행 저장 성공을 표시하지 않습니다.
- 입력 중에는 저장 완료라고 안내하지 않습니다. 앱 종료 후 미저장 입력 복원은 별도 보장하지 않습니다.
- 기존 게스트 기록은 보존합니다. 삭제·자동 이전하지 않으며 복구와 명시적 가져오기 경로를 유지합니다. 새 게스트 여행·일정 저장은 기본 입력 체험으로 대체할 개발 대상입니다.

## 2. 날짜 미정은 초안으로 저장합니다

- 출발일 없는 계획은 작성 중입니다. 출발일만 있고 도착일이 없을 때도 초안으로 저장하며 정식 여행을 생성하지 않습니다.
- 정식 생성은 기존 계약의 나라·출발일·도착일·시간대 등 조건을 충족해야 합니다. 기간은 시작일 포함 1~90일이며 제목·도시·항공편을 필수로 바꾸지 않습니다.
- 초안은 정식 로그인한 계정의 서버에 저장합니다. 현재 최대 5개 한도를 유지하며 초과 시 기존 내용을 덮어쓰지 않습니다.
- 초안 저장 → 재조회 → 이어쓰기 → 날짜 확정 → 정식 생성 → 일정 등록으로 연결합니다. 저장한 초안과 생성된 여행을 중복된 두 여행처럼 보여주지 않아야 합니다.
- 날짜 없는 초안의 동행 협업·날짜별 일정 편집은 이번 범위에 추가하지 않습니다. 날짜 미정 정식 여행은 만들지 않습니다.

## 3. 초대는 7일 동안 새 참여자 한 명이 사용합니다

- 여행 소유자가 읽기 또는 편집 역할을 선택해 발급합니다. 링크는 발급 시점부터 7일 동안 유효하며 새 참여자 한 명이 수락하면 사용을 마칩니다.
- 여러 명을 초대하려면 각각 링크를 만듭니다. 링크는 특정 이메일에 묶인 신원 보장이 아니므로 전달받은 다른 사람이 먼저 사용할 수 있다는 한계를 유지합니다.
- 이미 참여한 사용자는 기존 역할을 유지하고 링크를 소비하지 않습니다. 같은 요청 재시도와 새 참여를 구분해 중복 멤버를 만들지 않습니다.
- 소유자는 미사용 초대를 철회할 수 있습니다. 수락 후 링크 철회로 이미 참여한 멤버를 자동 제거하지 않습니다. 멤버 제거는 별도 행동입니다.
- 보관 여행의 초대, 만료·철회·사용 완료 링크를 통한 새 참여는 허용하지 않습니다. 두 사람이 동시에 수락해도 새 참여자는 한 명만 추가해야 합니다.

## 4. 소유자가 공개하고 직접 확인해 갱신합니다

- 계획은 여행 전부터 공유할 수 있습니다. 선택한 일정이 한 개 이상이어야 하며 보관된 여행은 제외합니다. 여행 기록 공개는 완료 상태에서 진행합니다.
- 소유자만 발행·갱신·공개 중단을 할 수 있습니다. 편집 동행자에게 공개 권한을 자동 부여하지 않습니다.
- 여행당 공개글은 하나입니다. 계획글을 기록글로 바꾸면 기존 글을 대체합니다. 원본 여행과 공개 사본은 구분합니다.
- 선택 일정·일반 사진과 공개되는 장소·주소·시각·여행 날짜 등을 확인한 뒤 발행합니다. 비용은 선택 시 여행 전체 실제 지출을 통화별 합계로 공개하며 선택 일정 비용만으로 표현하지 않습니다.
- 영수증 원본·품목, 개인 메모, 동행 개인정보는 자동 공개하지 않습니다. 공개 링크를 열어도 비공개 원본 조회·수정 권한을 얻지 않습니다.
- 원본의 일반 수정은 공개 사본에 자동 반영하지 않습니다. 사용자가 공개될 내용을 다시 확인하고 갱신합니다.
- 공개에 쓰이지 않은 사진 삭제는 공개글에 영향을 주지 않습니다. 공개에 사용한 사진을 삭제할 때는 영향을 확인하고 공개를 중단하거나 삭제할 사진이 빠진 사본을 발행해야 합니다. 실제 사진 삭제와 공개 처리를 안전하게 연결하는 순서는 개발 인계에서 정의합니다.
- 공개 중단 후 새 열람은 막습니다. 외부 다운로드·캡처까지 회수한다고 보장하지 않습니다.
