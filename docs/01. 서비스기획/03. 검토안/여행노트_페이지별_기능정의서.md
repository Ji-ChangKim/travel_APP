## 1. 개편 배경 및 핵심 디자인 원칙

### 1.1 개편 배경 (탈 AI 선언)

기존 화면은 LLM 모델이 양산한 전형적인 템플릿 느낌(AI Slop: 카드 중첩 지옥, "떠나요. 남겨요." 같은 챗봇형 감성 독백, 거대한 마스코트 일러스트 공간 때우기, 어두운 네모 박스 텍스트 땜질, 어드민식 풀위드 버튼 적층)으로 인해 실제 여행자가 손에 쥐었을 때의 실용성과 설렘이 결여되어 있었습니다. 이에 따라 브랜드명과 마스코트의 본질적 가치만 남기고 전 페이지의 시각적·기능적 아키텍처를 전면 재설계합니다.

### 1.2 보존할 2대 핵심 아이덴티티

1. **브랜드명 `TripPrint`**:
   - **철학**: "나만의 여행을 티켓과 영수증으로 정교하게 인쇄(Print)하여 영구 소장하는 아날로그 감성의 디지털 여행 노트"
   - **시각화**: 보딩패스 티켓(Boarding Pass) 메타포(양쪽 홈과 절취 점선), 영수증 펀치(Ledger Punch), 감성적인 스탬프 인터랙션.
2. **마스코트 `Haru`**:
   - **역할 전환**: 공간 때우기용 거대 일러스트 ➔ **"묵묵히 곁에서 챙겨주는 똑똑한 여행 조력자"**
   - **시각화**:
     - 목적지 환율/날씨의 `💡 하루의 여행 팩트 팁` 마이크로 뱃지
     - 영수증 인증 성공 시 쿵 찍히는 `하루의 인증 도장(Verified Stamp)`
     - 첫 온보딩 시 단정한 `하루의 나침반(🧭)` 미니 뱃지

### 1.3 공통 UI/UX 규칙

- **상단 헤더**: 홈 화면([`HomeHeader`](file:///j:/002.%20Project_Service/travel_APP/apps/mobile/src/components/HomeHeader.tsx))에서 우측 상단 프로필을 완전히 제거하고 좌측 `TripPrint` 브랜드에 집중.
- **하단 GNB**: 4대 탭 유지 ([홈], [내 여행], [커뮤니티], [MY]). 불필요한 중앙 큰 버튼 제거 및 단정한 아이콘+라벨.
- **타이포그래피**: LINE Seed (KR/Sans/JP) 기반, 가독성을 위한 점진적 그라데이션 스크림(Scrim) 적용 (투박한 네모 박스 땜질 금지).
- **액션 아키텍처**: 빽빽한 수직 버튼 적층을 폐기하고, 한 손 조작에 최적화된 **2열 퀵 액션 그리드** 및 상황 반응형 CTA 제공.

## 2. 사용자 여정별 3대 핵심 플로우 (Customer Journeys)

[ Journey 1: 여행 전 (Planning) ]
홈 진입 ➔ 보딩패스 티켓 발권 (D-Day 확인) ➔ 2열 퀵 허브 [✈️ 새 일정] ➔ 날짜·항공편·호텔·장소 타임라인 구성

[ Journey 2: 여행 중 (In-Trip & Live) ]

홈 진입 ➔ 영수증 서랍 정리 ➔ Haru의 완주 인증 도장 ➔ 발자국 커뮤니티에 '선택 공개' 발행 ➔ 나만의 여행 노트 완성

## 3. 전체 페이지별 상세 기능 정의

### [구역 A] 앱 시작 및 인증 영역

#### Page01 | 앱 시작 및 스플래시 (`/index.tsx`)

- **역할**: 앱 시작 시 세션 복원, 무결성 점검, 네트워크 상태 확인.
- **개편 포인트**:
  - 촌스러운 로딩 게이지 대신 `TripPrint` 심볼 로고와 절제된 미니멀 페이드인 모션.
  - 복원 중 이전 계정의 캐시가 깜빡이며 노출되지 않도록 화면 가림막 유지.
- **데이터 흐름**: 기기 보안 저장소 토큰 확인 ➔ `/api/v1/auth/session` 검증 ➔ 목적지 라우팅.
- **예외 처리**: 오프라인 시 이전 저장된 캐시 여행 모드로 부드럽게 진입 안내.

#### Page02 | 로그인 및 회원가입 (`/login`)

- **역할**: Google 간편 로그인 및 이메일 인증, 둘러보기 진입.
- **개편 포인트**:
  - 상단에 `TripPrint` 브랜드와 "영수증으로 완성하는 여행 노트" 한 줄 카피만 단정하게 노출.
  - 복잡한 온보딩 카드들을 걷어내고 간결한 소셜 로그인 버튼 및 게스트 둘러보기 제공.
- **데이터 흐름**: OAuth 2.0 / 이메일 인증 ➔ 성공 시 원래 가려던 딥링크 목적지로 복귀.
- **예외 처리**: 인증 취소 시 입력값 유지, 네트워크 장애 시 "잠시 후 다시 시도해 주세요" 토스트.

#### Page03 | 인증 콜백 (`/auth/callback`)

- **역할**: 소셜 로그인 리다이렉트 토큰 수신 및 세션 교환.
- **개편 포인트**: 불필요한 안내 팝업을 끼우지 않고 0.5초 이내 즉각 목적지로 전환.
- **예외 처리**: 만료된 일회용 코드는 오류 없이 로그인 화면으로 재연결.

#### Page04 | 프로필 설정 (`/profile-setup`)

- **역할**: 최초 가입자 닉네임 및 기본 프로필 설정.
- **개편 포인트**: 폼 전체를 감싸는 답답한 카드 테두리를 벗겨내고, 큼직한 텍스트 인풋과 실시간 중복 체크 피드백 제공.
- **예외 처리**: 특수문자/길이 제한을 입력창 아래에 붉은색 안내로 즉시 표시.

### [구역 B] 홈 & 탐색 대시보드 영역

#### Page05 | 상태별 스마트 홈 대시보드 (`/`)

- **역할**: 사용자 상태(여행 전/중/후/빈 상태)를 감지하여 최적의 여행 유틸리티를 제공하는 메인 허브.
- **상단 헤더**: 우측 프로필 아이콘을 완전히 제거하여 좌측 `TripPrint` 로고와 여백이 시원하게 보이도록 정돈.
- **3대 뷰포트 상태 정의**:
  1. **다가오는 여행 (D-Day 모드)**:
     - **보딩패스 티켓 히어로**: 항공권 도착 정보(KIX 10:25 도착), D-Day 뱃지, 점선 절취선(Perforation) 디테일.
     - **2열 퀵 액션 허브**: `[ 🧾 영수증 등록 ]` + `[ ✈️ 새 여행 만들기 ]` 타일 그리드.
     - **실시간 팩트 시트**: 목적지(오사카) 맞춤 엔화 환율(100엔 = 908원) 및 현지 날씨 인포그래픽.
     - **하이라이트 스트립**: DAY 1, DAY 2 핵심 장소 가로 스와이프 카드.
  2. **여행 중 (In-Trip / 라이브 모드)**:
     - **NOW TRAVELING 배너**: 현재 여행 일차 및 당일 방문 장소 수 요약.
     - **원터치 영수증 스캐너**: 결제 직후 1초 만에 촬영해 타임라인에 꽂는 점선 카메라 카드.
     - **당일 실시간 지출 피드**: 오늘 저장된 영수증과 결제 메뉴 실시간 집계.
  3. **첫 여행 (Empty State 모드)**:
     - 거대 마스코트 퇴출, 단정한 `🧭 하루의 나침반 뱃지` + "어디로 떠나시나요? 일정을 등록하고 영수증을 모아보세요."
     - 에디터 추천 여행지 가로 카드 스트립.
- **하단 정리**: 어드민식 풀위드 관리 버튼 4개 적층을 없애고, [내 여행] 탭 및 컴팩트 텍스트 링크로 분산.

#### Page06 | 여행지 큐레이션 안내 (`/destinations/:key`)

- **역할**: 특정 도시의 기본 정보, 추천 장소, 여행 팁 제공.
- **개편 포인트**: 백과사전식 텍스트 나열을 피하고, 매거진 형태의 풀블리드 사진과 하단 "이 도시로 일정 시작하기" 플로팅 바 제공.

#### Page07 | 내 여행 목록 (`/plans`)

- **역할**: 내가 생성하거나 초대받은 전체 여행(예정/완료/초안) 관리 및 검색.
- **개편 포인트**:
  - 복잡한 필터 칩을 단순화: [전체] / [예정된 여정] / [완료된 기록] / [작성 중인 초안].
  - 여행 카드를 미니 티켓 형태로 통일하여 일관된 브랜드 경험 제공.
  - 검색창은 상단에 가볍게 접히는 미니멀 서치바로 개선.

### [구역 C] 여행 계획 및 작업 공간 허브 (Trip Workspace)

#### Page08 | 새 여행 만들기 (`/new-trip`)

- **역할**: 목적지, 여행 일자, 항공편 유무를 입력해 새 여행 발권.
- **개편 포인트**:
  - 지루한 폼 입력을 "여행 티켓 발권(Ticket Issuance)" 프로세스로 연출.
  - 1단계: 어디로 떠나나요? (도시 자동완성) ➔ 2단계: 언제 떠나나요? (감각적인 캘린더 피커) ➔ 3단계: 누구와 함께하나요?
  - 완료 시 티켓이 프린트되어 나오는 마이크로 모션 제공.

#### Page09 | 여행 상세 메인 작업 공간 (`/trips/:id`)

- **역할**: 일정, 지도, 비용, 준비물, 동행을 한곳에서 통합 조작하는 메인 워크스페이스.
- **개편 포인트 (5대 세부 탭)**:
  - **09_01. 일정 탭 (Timeline)**:
    - 날짜를 넘기는 상단 DAY 스트립을 가로 스크롤 가능한 칩 형태로 구성.
    - 시간순 방문 장소 카드 사이에 이동 수단 및 소요 시간을 점선으로 연결.
    - 영수증 인증이 완료된 장소에는 `하루의 인증 도장(Verified Stamp)`을 표시하여 계획과 실제 방문을 시각적으로 구분.
  - **09_02. 지도 탭 (Map Canvas)**:
    - Google Maps 기반 핀 넘버링과 실제 일차별 동선 폴리라인 렌더링.
    - 하단 장소 미니 시트 스와이프 연동.
  - **09_03. 비용 & 영수증 탭 (Expenses & Ledger Punch)**:
    - 통화별 정밀 집계 (KRW, JPY, USD) 및 카테고리별 도넛 차트.
    - 영수증 원본 썸네일과 구매 품목(메뉴) 리스트를 영수증 영수증 형태로 카드화.
  - **09_04. 준비물 탭 (Checklist)**:
    - 필수 준비물(여권, 비자, 어댑터)과 개인 짐을 체크박스로 신속 토글.
  - **09_05. 동행 관리 탭 (Companions)**:
    - 참여 멤버 아바타 및 간편 카카오톡/링크 초대 생성.

#### Page09_10 | 영수증 촬영 및 업로드 (`/trips/:id?section=expenses&action=scan`)

- **역할**: 카메라로 영수증을 촬영하거나 앨범에서 불러오기.
- **개편 포인트**:
  - 뷰파인더 가이드라인 제공 (영수증 모서리 자동 인식 피드백).
  - 촬영 즉시 서버 AI OCR 엔진에 비동기 스트리밍 전송.

#### Page09_11 | 영수증 분석 및 메뉴 매핑 확인

- **역할**: OCR 결과(상호명, 결제 일시, 통화, 총액, 상세 메뉴 품목) 검토 및 보정.
- **개편 포인트**:
  - 좌측: 영수증 원본 이미지 확대 뷰어 / 우측(모바일 하단): 추출된 메뉴 품목 편집 리스트.
  - 사용자가 "품목 추가/삭제/단가 수정"을 터치 한 번으로 쉽게 완료할 수 있는 인라인 키패드.
  - 확인 버튼 터치 시 "기존 일정에 연결" 또는 "새 방문 장소로 자동 생성" 선택 옵션 제공.

#### Page09_12 | 영수증 상세 및 인증 스탬프 뷰어

- **역할**: 저장된 영수증 원본 고해상도 열람 및 인증 내역 확인.
- **개편 포인트**:
  - 영수증 상단에 하루(Haru) 캐릭터가 찍어준 스탬프 날짜 도장 시각화.
  - R2 스토리지의 안전한 서명 URL 기반 원본 확대/축소 제스처 지원.

### [구역 D] 공개 및 커뮤니티 영역

#### Page10 & Page11 | 발자국 공개 피드 (`/footprints`, `/community`)

- **역할**: 다른 여행자들이 정성스럽게 기록한 여행 노트를 탐색하는 에디토리얼 매거진 피드.
- **개편 포인트**:
  - SNS식 자극적인 좋아요/댓글 중심을 탈피하고, **"실제 여행 일정과 검증된 맛집 영수증이 담긴 신뢰도 높은 여행기"**를 매거진 카드로 큐레이션.
  - 도시별, 기간별 필터 지원.

#### Page12 | 공유된 여행 상세 및 내 여행으로 담기 (`/community/:postId`)

## 4. 공통 데이터 계약 및 예외 처리 아키텍처

### 4.1 핵심 데이터 계약 (Data Contracts)

| 식별자  | 엔드포인트 / 모델                         | 설명                                                   |
| :------ | :---------------------------------------- | :----------------------------------------------------- |
| **D01** | `GET /api/v1/trips`                       | 내 여행 목록 조회 (상태·기간·타임존 보존)              |
| **D02** | `GET /api/v1/trips/:id/workspace`         | 여행 메인 작업공간 스냅샷 (일정·비용·영수증·멤버십)    |
| **D03** | `GET/PUT /api/v1/plan-drafts`             | 기기 및 계정 임시 저장 초안 동기화                     |
| **D04** | `GET /public/travel-tips`                 | 발행된 여행 팩트시트 팁 (빈 결과 숨김, 실패 시 재시도) |
| **D05** | `POST /api/v1/trips/:id/commands`         | 멱등 키(`Idempotency-Key`) 기반 일정·비용 변경 커맨드  |
| **D06** | `GET /public/community`                   | 검증된 공개 여행 사본 피드 조회                        |
| **D07** | `GET /api/v1/trips/:tripId/media/:id/url` | R2 보안 서명 이미지 다운로드 URL                       |

### 4.2 오류 및 예외 처리 코드 (Error Codes)

- **E01 (401 Unauthorized)**: 세션 만료 시 작성 중인 폼 데이터를 로컬에 임시 보존한 후 로그인 화면으로 유도.
- **E02 (403 Forbidden)**: 권한 부족 시 쓰기 도구를 비활성화하고 뷰어 모드로 안전하게 전환.
- **E04 (400/422 Validation)**: 입력 오류 필드에 즉시 붉은색 테두리 및 정확한 수정 가이드 표시.
- **E05 (409 Conflict)**: 동행자와 동시 편집 충돌 시 최신 원본을 불러와 비교 후 재편집 지원.
- **E07 (5xx / Network Timeout)**: 실패를 빈 화면으로 때우지 않고 명확한 재시도 버튼 제공.
- **E08 (Idempotency Recovery)**: 네트워크 지연으로 응답 유실 시 중복 생성 없이 이전 요청 결과 재조회.
