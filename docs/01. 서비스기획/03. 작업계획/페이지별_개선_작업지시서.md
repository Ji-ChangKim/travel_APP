# 페이지별 개선 작업지시서

## 1. 목적과 읽는 법

이 문서는 기획서이자 작업지시서다. 페이지마다 **지금 상태 → 문제 → 할 일 → 완료 기준** 순서로 적는다. 개발자는 작업 ID 한 줄을 보고 무엇을, 어느 파일에서, 어디까지 하면 끝인지 알 수 있어야 한다.

- 기준일: 2026-11-13. 작업 브랜치 `codex/prepare-0.0.1`과 미커밋 수정 기준.
- 근거: 웹 빌드(390px) 게스트 직접 조작, 코드 확인, [화면 흐름도](https://claude.ai/artifact/97kMqZ4MBR4Xt348cxfYaW), [차별화 전략](<../00. 서비스정의/차별화_전략.md>).
- 확인 수준: **직접 확인**은 웹에서 눌러 본 결과, **코드 기준**은 코드로만 확인한 내용이다. Google 회원 흐름과 Android 실기기는 직접 확인하지 않았다.

### 1.2 모든 작업의 공통 완료 기준

1. `npm run check`, `npm run test:auth`가 통과한다. 화면·이동을 바꾸면 관련 웹 검사도 통과한다.
2. 화면을 바꾸면 320·390·430px, 글자 200%, 한·영·일 세 언어로 실제 화면을 확인하고 캡처를 `outputs/`에 남긴다.
3. 새 화면 문구는 번역 사전(`features/localization/messages.json`)에 세 언어로 넣는다.
4. 헤더·하단 메뉴는 공통 규격을 바꾸지 않는다([헤더·GNB 규격](<../../02. 디자인/00. 공통규격/헤더GNB_규격.md>)).
5. 저장을 바꾸면 저장 직후뿐 아니라 다시 열기·새로고침 뒤에도 같은 결과인지 확인한다.

파일 경로는 `apps/mobile/src/`를 생략해 적는다.

## 4. ① BI·로그인·프로필 등록

### 4.1 지금 상태

- 앱 실행 → 브랜드 화면 → 첫 시작(`/welcome`)에서 **Google 계정으로 계속** 또는 **게스트로 시작하기**를 고른다. 직접 확인.
- Google을 쓸 수 없으면 버튼이 잠기고 ‘Google 로그인 다시 확인’과 안내가 나온다. Google 시작 실패는 ‘다시 시도·다른 방법으로 로그인·닫기’ 팝업을 띄운다. 직접 확인.
- 이메일 가입과 생일·성별 입력은 제거됐다. 로그인 뒤 추가 입력 없이 홈으로 간다(**프로필 등록 단계 없음**). 닉네임·사진은 MY에서 Google 회원만 바꾼다.

### 4.2 문제

1. 웹 첫 진입 때 약 4초간 흰 화면만 보인다.
2. 이미 시작한 게스트가 앱을 다시 열면 ‘게스트로 시작하기’가 또 보인다. 데이터는 유지되지만 처음부터 시작하는 것처럼 읽힌다.
3. 실패 팝업이 보조기기에 경고로 알려지지 않는다(코드 기준: 팝업에 경고 역할 없음).
4. 시작·로그인 화면에 언어 선택이 없어 한국어를 못 읽는 첫 사용자가 바꿀 방법이 없다.

## 5. ② 홈 메인화면

### 5.1 지금 상태

- 여행이 없으면 인사, ‘나만의 맞춤 여행 일정 만들기’, 목적지 검색, **새 여행 만들기**, 인기 코스 둘러보기, 추천 여행지 가이드(8개 도시)가 보인다. 직접 확인.
- 여행이 있으면 여행 카드에 영수증 촬영·친구 초대·일정 보기가 있다. 도구로 Google Maps 장소 가져오기·준비물·비상 안내가 있다. 코드 기준.
- 로그인 전 공개 홈은 없어졌고, 홈은 Google·게스트 선택 뒤에만 열린다.

### 5.2 문제

1. 차별화의 대표 행동인 **영수증으로 기록하기**가 첫 화면에서 보이지 않는다. 여행 카드 안 여러 버튼 중 하나다.
2. 다녀온 여행을 기록하려는 사람의 진입점이 없다. ‘새 여행 만들기’에서 과거 날짜를 골라야만 ‘다녀온 여행 기록하기’로 바뀐다.
3. 진입점이 많아 무엇부터 할지 흐려진다(검색·새 여행·인기 코스·가이드·도구·여행 카드).
4. 가이드가 8개 도시뿐이고 실제 사용자 기록과 연결되지 않는다.

## 6. ③ 여행 만들기

### 6.1 지금 상태

- 목적지 선택(검색·국가 칩·도시 목록·직접 입력) → 기간 선택(달력·빠른 칩·일수만 정하기) → **세부 일정 만들기** 순서다. 직접 확인.

7. 기간 변경 화면만 브라우저 기본 날짜 입력을 쓴다.
