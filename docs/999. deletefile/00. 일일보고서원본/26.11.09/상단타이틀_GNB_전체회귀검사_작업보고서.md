# 상단 타이틀·GNB 전체 회귀 검사 작업 보고서

## 작업 결과

현재 여행 상세 구조에 맞춰 남아 있던 검사 경로를 정리하고, `npm run test:headers:web`의 **22개 검사를 모두 통과**했다. `npm run check`도 종료 코드 0으로 통과했다. 글자 대비·제목 크기·행간·최소 터치 영역·키보드 초점·이탈 보호 기준은 유지했다.

검사 중 발견한 실제 화면 문제도 수정했다. 320px 화면에서 글자를 200%로 키우면 여행 상세의 버튼들 때문에 긴 제목 폭이 한 글자보다 좁아졌다. 큰 글꼴에서 뒤로가기와 우측 행동이 함께 있으면 공통 헤더의 아래 제목 행을 사용하도록 바꿨다. 제목과 버튼을 줄이지 않고 헤더 높이를 늘려 전체 제목을 표시한다.

요청한 보고서 위치는 `docs/998. 일일 업무 보고서/26.11.09/`다. 기존 사용자 흐름 문서·이미지와 앞선 여행 화면 변경은 보존했다. 커밋·운영 배포·운영 데이터 변경은 수행하지 않았다.

## 검증 환경과 판정

- 대상 버전: 기준 HEAD `d92abb9cfd640fd84a8aa5eb3aeceaec99ad7eb0`, `main`의 현재 작업 사본. 변경 파일 해시는 `outputs/header-regression/source-manifest.json`에 기록한다.
- 환경: Windows, Node.js 22.17.0, npm 11.5.2, Chrome, 최신 로컬 웹 빌드와 전용 포트 8810.
- 사전 조건: 외부 API 응답은 검수 자료로 대체. 실제 화면·입력·키보드·복귀·이탈 보호 동작을 사용한다. 운영 계정과 서버 자료를 변경하지 않는다.

## 실제 화면 대조와 증거

참조한 기준은 [헤더·GNB 공통 규격](<../../02. 디자인/00. 공통규격/헤더GNB_규격.md>)과 [여행 일정 화면 규격](<../../02. 디자인/01. 화면설계/여행일정_화면규격.md>)이다. 작은 화면과 큰 글꼴에서 실제 캡처를 대조했다. 긴 제목은 전체 폭에서 줄바꿈하며, 모든 글자와 버튼이 화면 안에 표시된다. 알려진 제목 넘침은 남아 있지 않다.

로컬 캡처는 실행 화면이며 완성 시안이나 실기기 인수 결과로 대체하지 않는다. 다른 환경의 담당자도 수정 사항과 결과를 읽을 수 있도록 이 보고서와 [현행 검수 기록](<../../03. 개발/04. 검증/상단타이틀_GNB_규격화검수.md>)에 원인·조치·판정을 함께 남긴다.

## 검토 기록과 남은 범위

- SHELL-NAV-01 / 제목·이동 검사: 변경 후 재검토 1회. 현재 조작 경로와 22개 검사 결과 일치. 검사 반복 실행은 기획 재검토 횟수와 구분한다.

- SHELL-REPORT-PATH-01 / 보고서 폴더: 최초 0회. 사용자 지정 경로만 예외로 허용하며 잘못된 날짜·위치·이름과 깨진 링크는 계속 차단.
- 주 에이전트가 구현·검사·실제 캡처를 확인했다. 서브에이전트 검토는 진행하지 않았다.

이번에 요청한 22개 회귀 검사에는 남은 실패가 없다. 실제 Google 외부 인증·실기기 설치본·실제 서버 저장·전체 여행 작성 사이클과 나머지 웹 검사 묶음은 이번 실행 대상이 아니다. 외부 응답을 대체한 웹 회귀를 해당 기능의 실제 서비스 검수 완료로 보고하지 않는다.
