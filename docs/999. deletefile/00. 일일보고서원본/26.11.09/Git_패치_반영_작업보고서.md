## 검증 근거

이전 검수와 현재 프로필 주요 파일의 SHA-256을 대조했으며 차이가 없었다. 이미 통과한 동일 코드의 검사는 반복하지 않고 기록을 확인했다. 커밋 전 새 보고서의 문서 연결·서식을 검사하고 저장소의 커밋 전 검사도 실행한다.

| ----------------------------------- | --------------------------------------------------------------------------------- | ----------------------------------------------------------------- |

| 변경 파일 대조                      | 프로필 주요 코드·검사 파일의 해시 일치, Git 공백 오류 없음                        | `outputs/member-profile/source-manifest.json`, `git diff --check` |

이번 커밋 준비에서는 `npm run test:release` 106개가 통과했다(`outputs/member-profile/git-patch-release.log`). 보고서 추가 후 `npm run check:docs`도 7개 검사와 문서 47개·링크 207개를 오류 없이 통과했다(`outputs/member-profile/git-patch-docs.log`).

현재 GitHub CI는 `main` 푸시 후 자동 검사를 실행한다. 웹·API 배포와 Play 내부 배포는 별도 수동 실행 작업이다. 로컬 검사 통과와 푸시 후 CI 결과를 구분하며 원격 검사 결과는 최종 전달 때 확인된 상태로 안내한다.

## 남은 항목과 제외 범위

원격 DB의 `0016_member_profile_names.sql` 적용, API·웹 배포, 실제 Google OAuth, Android·iOS 실기기 촬영·권한, 원격 R2 업로드·재조회는 수행하지 않는다. 로컬 구현·검수 결과를 해당 환경의 완료로 표시하지 않는다. 실제 반영 때는 대상 DB·백업을 확인한 뒤 마이그레이션 → API → 앱 순서를 따른다.

게스트 여행 기록의 서버 저장·재조회와 새 홈 레이아웃은 후속 작업이다. 전체 과거 여행 편집 검사 묶음은 이번 Git 반영을 위해 새로 실행하지 않는다. 비밀 설정·키·로컬 `outputs/`는 커밋하지 않는다.
