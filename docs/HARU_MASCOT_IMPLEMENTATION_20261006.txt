목적
로딩·조회 오류·빈 기록을 하루와 구체적인 안내 및 다음 행동으로 표현한다.
첨부된 SD 캐릭터의 검은 단발/머리 고리/갈색 눈/푸른 체크 셔츠/흰 가방을 유지한다.
사용자 원본 세 장은 수정하지 않았다.

수정 파일과 동작
1. apps/mobile/assets/brand/haru-v1/TripPrint_Haru_loading_1233x1275.png
   걷는 하루와 민트 캐리어의 투명 PNG. 실제 요청 대기 안내용.
2. apps/mobile/assets/brand/haru-v1/TripPrint_Haru_error_1024x1536.png
   지도를 살펴보는 하루의 투명 PNG. 조회·인증 실패 및 잘못된 주소 안내용.
3. apps/mobile/assets/brand/haru-v1/TripPrint_Haru_empty_1024x1536.png
   손 인사와 기록 노트가 있는 하루의 투명 PNG. 공개 피드·완료 기록의 빈 상태용.
4. apps/mobile/assets/brand/haru-v1/manifest.json
   자산 크기·용도·참고 이미지·생성/추출 프롬프트·도구와 모드를 기록.
   image_gen.imagegen 내장 도구를 사용했다. 최종 RGBA 알파를 그대로 보존했다.
5. apps/mobile/src/components/HaruState.tsx
   상태별 포즈, 전체/간결 배치, 보조기기 설명, 오류 알림, 실제 대기 스피너 제공.
   버튼은 소비 화면에서 전달하며 자동 이동이나 가짜 진행률을 만들지 않는다.
6. apps/mobile/src/components/TripPrintLoading.tsx
   기존 로고 중심 준비 화면을 가로 로고와 하루 대기 안내로 변경.
7. apps/mobile/src/app/+not-found.tsx
   잘못된 주소에 하루와 길 찾기 안내 및 홈 복귀 버튼을 제공.
8. apps/mobile/src/app/auth/callback.tsx
   로그인 확인 중/실패 화면에 하루 적용. 실제 인증 교환 로직은 유지.
9. apps/mobile/src/features/workspace/HomeScreen.tsx
   인증 복원·여행 조회의 간결한 로딩 안내, 조회 실패와 재시도 버튼 연결.
   첫 방문 목적지 선택·새 여행·기존 여행 재개 행동은 계속 제공.
10. apps/mobile/src/features/workspace/CommunityScreen.tsx
    공개 피드 로딩·오류·빈 상태에 적용하고 조회 재시도/여행 시작 버튼 제공.
    재조회 실패에 기존 빈 상태 안내가 동시에 표시되지 않도록 조건 구분.
11. apps/mobile/src/features/workspace/FootprintsScreen.tsx
    로딩·조회 실패·완료 여행이 없는 상태에 적용. 여행 계획 복귀 버튼 추가.
12. apps/mobile/src/features/workspace/DiaryScreen.tsx
    실제 다이어리 조회의 로딩·오류 및 기존 재시도 행동에 적용.
13. apps/mobile/src/features/workspace/WorkspaceScreen.tsx
    여행 상세 로딩·오류 및 조회 재시도에 적용. 입력 검증 문구는 인접 표시 유지.
14. apps/mobile/package.json
    웹 내보내기 이후 postbuild:web 훅으로 하루 404 산출물을 준비.
15. scripts/prepare-web-not-found.mjs

16. scripts/preview-trail.mjs
