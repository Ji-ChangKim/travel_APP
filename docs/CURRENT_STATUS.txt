TripPrint 현재 개발·검수 기준
기준일: 2026-10-16 / Asia/Seoul
상태: 사용자 확정 4단계 상태·홈 브리핑·메뉴 제거 보완, 최종 검증 중. Play 내부 테스트용 빌드 생성 전.

1. 문서 우선순위

사용자 직접 확정 사항 → SCREEN_REVIEW.txt(2026-10-16 화면 보완) → 원본 화면별 상세기능정의서 v3 → 현행 DB/API 계약 → 디자인 자료 순으로 해석한다.
원본 기능정의서는 입력 자료로 보존한다. 원본의 필터·홈·빈 일정 규칙과 이번 보완의 차이는 SCREEN_REVIEW.txt에 명시한다.
기능 구현·로컬 테스트·Play 설치·실제 기기 인수를 서로 다른 결과로 기록한다.

2. 구현 기준

- 프로필: 닉네임2~20byte, 공백 포함. 기존 회원 값 유지. 생일 선택, 생일 없이 온보딩 완료.
- 인증: 실제 지원하는 Google·이메일·기기 게스트 경로만 안내. 초대/공유/여행 목적을 로그인·온보딩 뒤 복원.
- 저장: 입력 검증·중복 제출 차단·미저장 이탈 보호·버전 충돌/응답 유실 재시도 유지.
- 여행: 국가 변경 시 도시 초기화, 기간 축소 연결 기록 안내, 유지되는 날짜의 DAY ID 보존.
- 상태: 날짜 미정/D8 이상은 준비 중, D7~D1은 임박/예정, 시작일~종료일은 여행 중, 종료 다음 날부터 여행 완료. 보관은 별도 속성. 원본 저장 상태·공개는 자동 변경하지 않는다.
- 홈/내 여행: 홈은 현재/가까운 여행 한 건의 실제 다음 일정 브리핑·팁·추천. 내 여행은 전체 검색·필터·아카이브. 홈 팝업·내 여행의 홈 이동 링크·하단 탭 중복 경로 제거.
- 일정: 빈 DAY에서 추천 코스·장소 검색으로 작성 시작. 코스는 기존 도시 가이드의 장소 미리보기이며 현재 DAY를 유지한다. 제목·설명만 채우고 확인 후 저장 전까지 기록을 만들지 않는다.
- 위치: 권한·대략 위치·서비스 꺼짐·설정 복귀와 이전 요청 폐기. 유료 자동 검색이나 가짜 인기 장소를 생성하지 않는다.
- 영수증/공개: 합계 차이 확인·미지원 통화 원본 보존, 원본 영수증/품목/비공개 메모의 공개 제외.
- 도시:8개 도시 저작자·라이선스·원문·변경 표시, 이미지 실패에도 가이드 유지.
- 접근성: 공통 전환·5초 순환·큰 글꼴·읽기·동작 줄이기·배경 보호. 실기기 음성/OS 실행은 내부 테스트에서 별도 인수.
- BI: 현재 영상 미제작. 흰 배경 중앙 로고. 승인 tripprint_bi.mp4를 지정 경로에 추가한 빌드는 자동 포함하며 오류/첫 프레임 지연은 같은 정적 대체.

3. 빌드와 최종 테스트

사용자 확정: 이번 범위는 Google Play 내부 테스트용 빌드 생성 전까지. USB 연결 없이 내부 테스터 설치본으로 최종 기기 테스트한다.
AAB/APK 생성·업로드·배포·커밋·푸시는 실행하지 않는다. 빌드 시 Play 최대 versionCode와 업로드 서명·현재 소스/배포 API 대응을 확인한다.
빌드 인계: PLAY_INTERNAL_PREBUILD.txt. 실제 기기 검수표: qa/DEVICE_ACCEPTANCE.txt.
R08 실제 최소/권장 지원 운영값은 미확정·필수 정책 비활성. 임의 활성화하지 않는다.
영상 실제 인코딩/디코딩 감수는 승인 MP4 제공 후 진행한다.

4. 검증 기준

R13 기준선: npm run check, 모델184/184, 릴리스46/46, Chrome39/39, 실제 두 배 글꼴 보정1/1, Android 네이티브 컴파일 통과.
