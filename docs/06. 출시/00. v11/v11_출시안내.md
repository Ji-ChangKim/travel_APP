## 핵심 사용자 흐름

구매한 항공권이 있는 이용자가 앱 실행→계획 만들기→날짜 선택→국가·도시 선택→항공권 입력→DAY별 계획 추가·편집·순서 변경·삭제를 진행한다. 여러 도시를 방문할 때 도시를 추가하고 DAY에 배정한다. 추천 장소는 실제 공급자에서 확인하며 사용자가 선택·확정한 장소만 일정으로 저장한다. 이동시간은 실제 경로 응답으로 조회한다.

회원 여행은 서버에 저장한 뒤 새 로그인 세션에서 다시 읽는다. DAY 소개와 장소 설명·팁은 여행계획에서 작성하고, 공개할 항목 선택→미리보기→확정으로 공유한다. 공유본을 담으면 독립된 본인 여행이 된다. 기기 게스트의 여행은 이 기기에 보관하며 자동으로 계정에 업로드하지 않는다.
