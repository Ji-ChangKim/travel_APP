4. 현재 구현과 요구의 차이
- TC-079 차단: 촬영 전 안내를 거쳐 시스템 카메라가 열린다. 선택한 사진은 즉시 전송된다. 앱 자체의 전송 전 사진 미리보기·재촬영 선택은 미구현.
- TC-080 차단: 현재는 정보 확인 선택 → 사진 보관 선택 → 별도 최종 저장 버튼이다. 한 번의 최종 확인 등록 UX는 미반영.
- 두 차단은 소스 검토로 기록했다. 실기기에서 실패를 직접 재현한 결과로 표시하지 않았다.
- Google OAuth, Google Places 조회, 전체 Google 북마크 자동 동기화, 앱 내 지도 동선 화면은 완료로 선언하지 않는다.
- 현재 제공하는 이메일 로그인, 단일 공유 장소 가져오기, 외부 Google Maps 열기와 구분한다.
- 전체 영문 UI 및 언어 전환은 미구현. 한국어 앱의 영어 영수증 인식과 영문 UI 지원은 서로 다른 검증이다.
- TC 완성 및 번들 성공은 서비스 출시 승인 또는 APK 기기 QA 완료가 아니다.
