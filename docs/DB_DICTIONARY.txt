1. 데이터베이스 개요 및 공통 Enum 타입
================================================================================

* 기본 데이터베이스명: postgres (wherego_travel)
* 문자셋: UTF-8
* 고유 식별자(PK): UUID v4 (uuid_generate_v4())
* 시간 표준: TIMESTAMPTZ (UTC 기준)

[ Enum 타입 정의 ]

1) trip_status (여행 진행 상태)
   - 'DRAFT'       : 작성 중인 임시 여행
   - 'PLANNED'     : 여행 예정 (출발 전 D-Day)
   - 'IN_PROGRESS' : 여행 중 (실시간 Travel Mode / Today 화면 대상)
   - 'COMPLETED'   : 여행 완료 (발자국 스크랩북 전환 및 정산 대상)
   - 'ARCHIVED'    : 보관된 여행

2) place_category (장소 분류)
   - 'stay'        : 숙소 (호텔, 리조트, 펜션, 게스트하우스 등)
   - 'food'        : 식당/음식점
   - 'cafe'        : 카페/디저트
   - 'sightseeing' : 관광지/자연명소/유적지
   - 'activity'    : 액티비티/체험/레저
   - 'etc'         : 기타

3) member_role (동행 멤버 권한)
   - 'owner'       : 방장 (여행 생성자, 모든 편집/삭제/멤버관리 권한)
   - 'editor'      : 편집자 (일정/가계부/체크리스트 추가 및 수정 권한)
   - 'viewer'      : 뷰어 (읽기 전용 조회 권한)

4) verification_method (발자국 방문 인증 방식)
   - 'gps'         : 현재 위치 위경도 기반 반경 200m 자동 인증
   - 'manual'      : 사용자 수동 방문 완료 체크인
   - 'receipt'     : 영수증 촬영/OCR 결제 내역 매칭 인증

5) schedule_type (일정 항목 성격)
   - 'PLACE'       : 방문 명소 및 식당
   - 'TRANSPORT'   : 항공/기차/버스/렌터카 등 이동 수단
   - 'STAY'        : 숙박 시설 및 체크인/아웃
   - 'RESERVATION' : 사전 티켓/투어 예약
   - 'TODO'        : 여행 중 챙겨야 할 할 일
   - 'MEMO'        : 참고 메모 및 꿀팁

6) expense_category (가계부 지출 카테고리)
   - 'food'        : 식비/카페
   - 'transport'   : 항공/대중교통/주유/택시비
   - 'stay'        : 숙박비
   - 'activity'    : 입장료/티켓/체험비
   - 'shopping'    : 쇼핑/기념품
   - 'etc'         : 여행자보험/기타 잡비
