## 2026-10-20 홈 HTML 적용 범위

정상 조회 뒤 진행할 여행이 없을 때 인사 → 여행 시작 카드 → 활용 팁 세 개 → 실제 공개 여행 카드 순서로 표시합니다. 지난 여행만 있으면 다음 여행 준비 문구를 쓰고, 진행할 여행이 있으면 기존 여행 요약을 유지합니다. 조회 중·오류를 빈 여행으로 안내하지 않습니다. 빈 홈의 중복 생성 카드와 도시 바로 생성 버튼은 제거하며, 새 여행 버튼에서 기존 나라·도시 입력을 사용합니다. 조회 오류와 기존 여행 화면의 시작 행동은 유지합니다.

- 바탕 #F8F9FF, 카드 #FFFFFF, 본문 #0B1C30, 보조 #45464D, 주행동 #B3261E/흰색, 선택 칩 #000000/흰색. 홈 전용 homeTheme.ts와 기존 ledger 토큰을 조합합니다.

- 하단 공통 메뉴는 병행 작업의 현행 디자인과 이동 경로를 보존하며 홈 안에 별도 하단 바를 추가하지 않습니다. 통합 검사에서 발견한 미사용 import를 정리하고, 200% 글자에서 라벨이 겹치지 않도록 높이60 고정을 최소60과 콘텐츠 높이로 바꿉니다. 다른 메뉴 디자인은 바꾸지 않습니다.

## 2. 컴포넌트별 상세 기능 및 텍스트(UX Writing) 명세

### 1) 상단 탑바 (Top Bar)

- **로고 및 타이틀**: 심볼 핀 도트(`#FF5C39`) + `Home` 타이틀 노출
- **알림 아이콘 (🔔)**:
  - 읽지 않은 알림 존재 시 우측 상단 레드 뱃지 인디케이터 표시
  - 터치 시 알림 목록 이동 (현재는 빈 알림 대응)
- **비로그인 사용자 대응**: `userId` 미보유 상태 시 `로그인` 버튼 노출

### 2) 환영 섹션 (Welcome Area)

- **온보딩 뱃지**:
  - `New explorer!`: 하늘색 뱃지(`#E8F3FF`, 텍스트 `#0066FF`)
  - `TripPrint #001`: 가입 순번/환영 고유 코드 (`#8A9BA8`)
- **헤드라인**: `"환영해요, {닉네임}님! 👋"`
  - 닉네임 미설정 혹은 게스트일 경우 `"환영해요, 여행자님! 👋"` 기본값 제공
- **서브헤드**: `"설레는 첫 여정을 함께 건너볼까요?"`

### 3) 중앙 Hero 카드 (Empty State & Primary CTA)

- **목적**: 등록된 여행 일정이 0개일 때 사용자의 심리적 허들을 낮추고 첫 일정을 만들도록 유도
- **마스코트 비주얼**: 원형 프레임 내 TripPrint 공식 마스코트 '하루(Haru)' 일러스트 배치
- **상태 태그**: `✈️ Passport Ready`, `🔖 첫 번째 여정`
- **헤드라인**: `"아직 등록된 여행이 없어요"`
- **설명 카피**: `"가고 싶은 여행지를 등록하면 일정 계획, 동선 추천, 명소 팁, 영수증 서랍 정리까지 한 번에 채워드릴게요!"`
- **주요 버튼 (Primary CTA)**:
  - 레이블: `＋ 첫 여행 계획 만들기 >`
  - 컬러: 브랜드 코랄(`#FF5C39`), 입체적 그림자 적용
  - 동작: `/new-trip` 일정 생성 플로우로 라우팅
- **안심 마이크로카피**: `"⏱️ 3분이면 나만의 템플릿 일정이 완성돼요"`

### 4) 추천 코스 섹션 (WHERE TO GO / Recommended Courses)

- **카테고리 & 타이틀**: `WHERE TO GO` / `"어디로 떠나볼까요? 추천 코스"`
- **가로 스크롤 카드들 (Horizontal Carousel)**:

  - **제주**: `제주도 · 2박 3일` / `"에메랄드빛 제주 드라이브"`
  - **오사카**: `오사카 · 3박 4일` / `"오사카 미식 & 유니버설"`
- **여행 일정 보기 (`여행 일정 보기`)**:
  - 해당 버튼 클릭 시 도시/국가/통화 기본값이 자동 채워진 상태로 새 일정 생성 진입 (`/new-trip?destination={key}`)
- **전체보기**: 클릭 시 탐색/발자국 탭으로 전환

### 5) TripPrint 활용 가이드 & 얼리어답터 후기

## 3. 하단 글로벌 내비게이션 바 (GlobalNavigation) 명세

- **5버튼 구조**:
  1. `홈` (Ionicons `home-outline` / `home`) -> `/(tabs)`
  2. `일정` (Ionicons `calendar-outline` / `calendar`) -> `/(tabs)`
  3. **중앙 돌출 FAB `+`** (원형 코랄 `#FF5C39`, 직경 52px, 상단 22px 돌출, `add` 아이콘):

     - 클릭 시 즉시 새 여행 일정 생성(`/new-trip`) 화면으로 진입
  4. `발자국` (Ionicons `map-outline` / `map`) -> `/(tabs)/footprints`
  5. `MY` (Ionicons `person-outline` / `person`) -> `/(tabs)/my`
- **안전 영역 대응**: iOS Safe Area Insets (`bottom`) 및 안드로이드 시스템 네비게이션 바 여백 자동 계산

## 4. 예외 처리 및 엣지 케이스 (Edge Cases)

1. **이미 일정이 등록된 사용자가 로그인한 경우**:
   - `continuingTrips(trips).length > 0` 판정 시 Empty State Hero 카드는 렌더링되지 않으며, 기존의 **'진행 중인 여행 / 다가오는 여행' 티켓 카드([HomeTripList])**로 자동 전환됨.
2. **닉네임 예외**:
   - 닉네임이 공백이거나 없는 경우 `resolveDisplayName`을 통해 기본값 `여행자`로 자동 대체.
   - 글자 수 10자 초과 시 줄바꿈 및 레이아웃 깨짐을 방지하도록 유연한 레이아웃 적용.
3. **네트워크 오류/조회 지연**:
   - 로딩 중: 마스코트 로딩 인디케이터(`HaruState kind="loading"`) 표시.
   - 오류 발생: `HaruState kind="error"` 및 `내 여행 다시 불러오기` 복구 액션 제공.
4. **버튼 중복 터치 방지**:
   - 생성 버튼 터치 시 비활성화 및 디바운스 적용으로 다중 라우팅 방지.
