TripPrint 서비스 흐름 개선 기록
기준일: 2026-10-06 (Asia/Seoul)

수정 내용
1. 로그인: 실제 제공하는 이메일 인증을 주 행동으로 표시하고 미연결 소셜 버튼 및 OS 배지를 제거했다. 계획·동행·기록 가치를 안내한다. 기존 인증 모듈은 유지한다.
2. 게스트: 공개 커뮤니티로 진입하고 마이페이지에는 둘러보기 상태를 표시한다. 모든 페이지의 인증 복원에서 저장된 게스트를 복원한 뒤 실제 서버 세션을 확인한다.
3. 마이페이지: 연결되지 않은 GPS/오프라인/알림 스위치를 제거했다. 내 여행과 동일한 계정별 서버 trips 조회로 총 여행/예정 여행/완료 발자국을 집계한다. 조회 대기·실패를 0으로 표시하지 않는다.
4. 여행 생성: 목적지·날짜 → 선택 제목 → 선택 항공편 → 통화·현지 시간대 순으로 입력한다. 항공편 없이 시작하는 것이 기본이며 추가한 경우에만 기존 flight 계약으로 저장한다.
5. 여행 상세: 일정/비용/사진·영수증/준비물/동행/발자국 공유로 영역을 분리한다. DAY 필터와 현재 선택 DAY를 새 일정 기본값으로 연결한다. 여행 설정은 펼친 경우에만 표시하고 명시적 목록 복귀를 제공한다.
6. 화면 표현: 주 행동/보조/삭제/간단 이동 버튼을 구분한다. 서버 상태·멤버 권한을 한국어로 표시하고 발자국 명칭을 통일한다.
7. 발자국: 완료한 서버 여행만 표시한다. 기존 기기 기록이 있는 경우 마이페이지에서 보존 화면에 접근한다. 다이어리 첫 여행 사진을 표지에 표시하고 공유 선택 영역으로 직접 이동한다.
8. 도메인 문서: DB_DICTIONARY.txt에 항공편 생략 기본값·선택 DAY·서버 통계 원본을 기록했다. DB/API 스키마 변경은 없다.

npm run test:release: 20/20 통과.

기존 검증: 실제 사용자 폼 입력·세션 복원·요청 유실 재시도·영수증 수동 확인·종료 다이어리·공개 선택·초대 읽기 권한 유지.

제공 범위
실제 이메일 인증·서버 저장·권한·비공개 사진 및 수동 영수증 확인은 유지한다.
Google Places/Vision OCR/소셜 인증 공급자 연결, 지도 내부 표시, 계정 복구 메일, 운영 지원 및 Android 실기기 인수는 완료로 표시하지 않는다.
이 변경은 화면과 사용자 흐름 개선이며 앱 전체의 서비스 인수 완료를 의미하지 않는다.
