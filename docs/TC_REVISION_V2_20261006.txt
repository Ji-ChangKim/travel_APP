3. 영문 지원 기준과 현재 상태
- 작성 기준 소스: fc38cef. 서비스 식별자: test-1-service-copy.
- 현재 앱 UI는 한국어 중심이며 영문 리소스와 언어 선택 기능이 구현되어 있지 않다. 목적지의 영어 검색어 지원은 영문 UI 지원과 별개다.
- 영문 문구 57개는 구현·검수에 사용할 제안안이며 현재 서비스에 반영된 번역으로 표시하지 않았다.
- 초기 언어는 기기 언어가 한국어이면 한국어, 그 외에는 영어를 사용하는 기준을 제안했다. 사용자가 직접 선택한 언어를 우선하고 재시작 뒤에도 유지하도록 검사한다.
- 언어 전환 전후 로그인, 작성 중인 여행·영수증, 날짜와 금액이 유지되어야 한다.
- UI 언어와 여행 현지 날짜·시간대·통화는 별도로 처리한다. 영어 날짜는 월·일 순서가 모호하지 않아야 하며 금액에 원래 통화가 표시되어야 한다.
- 사용자가 작성한 내용, 식당 이름·주소 및 영수증 메뉴 원문을 임의로 번역하거나 덮어쓰지 않는다.
- 번역 누락, 한국어/영어 혼용, 내부 키·원시 오류 노출, 긴 영어의 버튼·탭 잘림, 글자 확대, 시스템 권한·공유 및 오류 안내까지 검사한다.
- 영문·다국어 TC는 영어 화면만 검사하는 항목이 아니라 한국어 회귀와 양방향 전환도 포함한다.

4. 실행 및 판정 방식
- 각 TC에 한국어 결과와 영문 결과를 별도 입력한다. 실제 동작·문구 기록, 실행자, 언어별 실행 일시, 빌드/기기, 증거·결함, 심각도를 기록한다.
- 한국어 실행 대상 102건, 영문 실행 대상 128건으로 총 230건의 언어별 실행을 계획한다.
- 영문·다국어 전용 26개 TC의 한국어 결과 N/A는 시트 구조상 대상 제외 표시다. 실행 완료 판정이 아니다.
- 새 회차의 한국어 102건과 영어 128건은 모두 미실행이다. 새 PASS 결과는 0건이다.
- 기존 자동화 검증 이력은 참고 자료이며 이번 APK/언어별 수동 TC의 PASS로 옮기지 않았다.
- 실행요약은 언어별 통과·실패·차단·미실행·제외와 중요 결함을 자동 집계한다. 빌드 정보가 없거나 영문 빌드가 없으면 테스트 준비 완료로 표시하지 않는다.
- 결과와 심각도 선택 목록, 필터, 고정된 헤더/식별자, 실패·차단 강조, 상태 차트를 제공한다.
