2. 빌드 입력 확인

앱 식별자: com.tripprint.app
현재 ver.text: versionName0.1.0 / versionCode6
빌드 프로필: play-internal → preview 공개 환경 상속, distribution=store, Android app-bundle(AAB).
버전: local 소스 사용·autoIncrement=false. 루트/모바일 설정 동일 확인.
공개 환경: 기존 staging API·인증 복귀 주소 유지. 형식/필수 공개 설정 검사 통과.
영상: 아직 미제작. 이번 후보는 흰 배경 중앙 로고를 사용하며 영상 없어도 빌드된다.
자산: 폰트·브랜드·도시 이미지·로컬 네이티브 모듈·Expo 플러그인·워크스페이스 패키지를 빌드 입력으로 유지한다.
EAS 제외: 기존 Git 제외 규칙을 모두 보존하고 outputs/scratch/로컬 작업·IDE 폴더를 추가 제외했다.
네이티브 앱 폴더는 Expo에서 새로 생성하고 로컬 Play 업데이트 모듈의 Android 소스는 포함한다.

3. 빌드를 시작하는 시점에 확인할 사항

- Play Console의 이미 사용한 최대 versionCode를 확인하고 새 번호를 ver.text에 확정한다. 현재6의 재사용 가능 여부는 원격 확인하지 않았다.
- GitHub 경로는 현재 수정·신규 파일을 포함한 승인 소스가 main에 반영되어야 한다. 로컬 HEAD만으로 미커밋 변경을 식별할 수 없다.
- GitHub AAB에는 기존 업로드 서명 Secrets가 필요하다. EAS 경로는 기존 프로젝트 접근과 업로드 키를 사용한다. 원격 자격 증명의 유효성은 빌드 시 확인한다.
- 최종 내부 테스트 전 staging API/DB가 이번 앱 계약(R04 선택 생일 등)과 맞는지 해당 배포본에서 확인한다. 이번 준비 요청으로 원격 배포하지 않았다.
- R08 운영값은 확정 전까지 필수 정책 비활성 상태를 유지한다. 이번 일반 기능 검수 빌드의 선행 조건으로 임의 운영값을 채우지 않는다.
- BI 영상의 실제 인코딩/디코딩 감수는 제작 후 추가한다. 현재 로고 대체 후보를 준비하는 데 영상 제공은 필요하지 않다.

이 항목은 빌드·배포 실행 시의 확인 사항이며 이번 작업에서는 빌드를 시작하지 않는다.
