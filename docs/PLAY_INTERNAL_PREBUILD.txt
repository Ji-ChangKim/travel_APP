3. 빌드를 시작하는 시점에 확인할 사항

- Play Console의 이미 사용한 최대 versionCode를 확인하고 새 번호를 ver.text에 확정한다. 현재8의 재사용 가능 여부는 이 기획 검수에서 원격 확인하지 않았다.
- GitHub 경로는 현재 수정·신규 파일을 포함한 승인 소스가 main에 반영되어야 한다. 로컬 HEAD만으로 미커밋 변경을 식별할 수 없다.
- GitHub AAB에는 기존 업로드 서명 Secrets가 필요하다. EAS 경로는 기존 프로젝트 접근과 업로드 키를 사용한다. 원격 자격 증명의 유효성은 빌드 시 확인한다.
- 실제 staging에서 R04 선택 생일·항공권 상세·영수증 수정 계약 불일치를 확인했다. 검색503·항공 조회404도 재현했다. 서버 후보 반영 후 재검사한다. 원격 배포는 실행하지 않았다.
- R08 운영값은 확정 전까지 필수 정책 비활성 상태를 유지한다. 이번 일반 기능 검수 빌드의 선행 조건으로 임의 운영값을 채우지 않는다.
- BI 영상의 실제 인코딩/디코딩 감수는 제작 후 추가한다. 현재 로고 대체 후보를 준비하는 데 영상 제공은 필요하지 않다.

이 항목은 빌드·배포 실행 시의 확인 사항이며 이번 작업에서는 빌드를 시작하지 않는다.
