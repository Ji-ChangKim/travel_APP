# TripPrint 9번 업데이트

기준일: 2026-10-21 / Asia/Seoul. Android versionCode 9, 표시 버전 0.1.0, 앱 식별자 com.tripprint.app. 기존 9번 설정을 유지하며 자동 증분하지 않는다. 사용자의 최신 선택에 따라 빌드 전 준비까지만 진행한다.

## 반영 내용

- 홈의 여행 시작 이미지·안내·실제 공개 일정 탐색을 새 시안에 맞췄다.
- 발자국을 실제 공개 일정 목록으로 연결하고 상단의 독립 검색창을 제거했다. 조건 칩과 하단 메뉴5개를 유지했다.
- 내 여행은 등록 있음·없음, 검색·상태·정렬, 실제 사진과 일정 정보로 구성했다. 현재 소스의 ‘내 여행 계획’ 공통 헤더와 읽기 보완을 보존했다.
- 발자국 카드·공개 상세·내 여행 추천에 ‘일정 담기’를 연결했다. 출발일과 이름을 확인하면 본인 여행으로 저장하고 기존 편집기로 이동한다. 공개 원본과 사본은 서로 독립적이다.
- 담는 일정의 날짜 간격·DAY 소개·장소·시간·주소·공개 설명을 보존한다. 원본 항공권·사진·실제 지출·개인 메모·동행자·공개 상태는 복사하지 않는다.
- 회원은 서버의 본인 여행으로, 게스트는 이 기기의 여행으로 저장한다. 응답 유실과 연속 클릭은 같은 요청 키로 처리한다.
- 실제 목록이 비었거나 조회가 실패했을 때 예시 여행을 넣지 않는다. 기존 검수용 공개 글 정리 결과와 사용자 공개 원본을 보존한다.
- 배포 번들에 로컬 검수 주소·테스트 인증값·서버 비밀이 들어가지 않도록 검사한다.

세부 계약과 기존 검수 근거는 [일정 담기](../qa/COMMUNITY_IMPORT_20261020.md), [내 여행](../qa/MY_TRIPS_HTML_UPDATE_20261020.md), [발자국](../qa/STAGING_FOOTPRINTS_DEPLOY_20261020.md), [공개 목록 정리](../qa/PUBLIC_FEED_CLEANUP_20261020.md)를 따른다. 과거 검사 수치를 이번 후보의 새 결과로 사용하지 않는다.

## 빌드와 설치

`ver.text`가 Expo·Gradle·CI의 버전 원본이다. 정적 공개 메타데이터 release.json도 9번 후보로 갱신했다. 이는 앱 강제 업데이트 정책이나 Play 출시 완료를 뜻하지 않는다. 서버·웹 주소는 기존 staging을 유지한다.

직접 빌드 경로와 서명 설정은 [AAB 빌드 안내](../ANDROID_GITHUB_BUILD.md)를 따른다. Play에서 9번을 이미 사용했는지는 Console에서 확인해야 한다. 실제 Google 로그인·지도·카메라·권한 복귀·게스트 보존은 새 Play 내부 테스트 설치본에서 확인한다.

이번 후보의 검사 결과·소스 해시·빌드 착수 조건은 [9번 빌드 전 점검](../qa/PREBUILD_V9_20261021.md)에 기록한다. 실제 AAB/APK 생성·서명·Play 업로드·Git 커밋/푸시는 이번 선택 범위에 포함하지 않는다.
