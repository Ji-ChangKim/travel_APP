# TripPrint 문서 안내

이 저장소의 모든 문서는 **현재 MVP 단일 기준**만 기술합니다. 과거 변경 이력, 폐기된 시안, 누적 검토 로그는 본 문서 트리에 남기지 않습니다.

---

## 1. 폴더 구조

| 폴더                                         | 설명                                                                                           |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| [00. 문서안내](<00. 문서안내/README.md>)     | 문서 관리 규칙, 에이전트·스킬 운영 및 검수 기록 기준                                           |
| [01. 서비스기획](<01. 서비스기획/README.md>) | 서비스 개요, MVP 핵심 기능·정책 규격, 사용자 탐색 흐름                                         |
| [02. 디자인](<02. 디자인/README.md>)         | 단일 디자인 토큰, 디자인 시스템, 헤더·GNB·팝업 규격, 화면별 UI/UX 규격, 리소스 경로            |

- `98. keys`는 비공개 로컬 설정 영역이며 문서 색인·Git·빌드 업로드에 포함하지 않습니다.
- `999. deletefile`은 폐기·이관된 구버전 문서 보관 폴더이며 현행 기준으로 참조하지 않습니다.
