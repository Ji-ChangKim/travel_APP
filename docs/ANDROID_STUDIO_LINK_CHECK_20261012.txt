1. 최초 상태
- 저장소 루트 .idea/modules.xml에는 travel_APP 일반 Java 모듈만 등록되어 있었다.
- apps/mobile/android 네이티브 프로젝트와 Gradle 연결 설정이 없었다.
- Android Studio: C:/Program Files/Android/Android Studio
- Android SDK: C:/Users/Jichang/AppData/Local/Android/Sdk
- SDK 플랫폼은 android-37.0만 설치되어 있었고 Build Tools 36.0.0은 설치되어 있었다.
- 기본 PATH의 Java는 Java 8이며 별도로 Microsoft OpenJDK 21.0.8이 설치되어 있다.
- ADB를 직접 실행해 emulator-5554 연결을 확인했다. 실물 휴대폰 연결은 확인되지 않았다.

2. 적용한 변경
- 설치된 Expo 57.0.26의 template.tgz로 apps/mobile/android를 생성했다.
- Node 22.17.0의 prebuild가 템플릿 추출 뒤 중단되어, 설치된 Node 24.19.0으로 재실행했고 정상 종료했다.
- 생성된 Android 패키지는 com.tripprint.app, 앱 이름은 TripPrint이다.
- 기존 앱 설정의 android.allowBackup=false가 생성된 AndroidManifest.xml에 반영되었다.
- .idea/gradle.xml: 루트 프로젝트에 apps/mobile/android를 Gradle 프로젝트로 연결했다.
- .gradle/config.properties 및 apps/mobile/android/.gradle/config.properties: 로컬 Gradle JDK를 C:/Program Files/Android/openjdk/jdk-21.0.8로 지정했다.
- apps/mobile/android/local.properties: 설치된 Android SDK 경로를 지정했다.
- apps/mobile/android/gradle.properties: android.overridePathCheck=true로 Windows 한글 경로에 대한 모듈 동기화 차단을 해제했다. 이 옵션은 경로를 바꾸지 않으므로 NDK/CMake 컴파일까지 성공하는지는 별도 검증해야 한다.
- apps/mobile/android/.idea/gradle.xml: Android 폴더를 직접 열 때도 같은 Gradle/JDK 설정을 사용하도록 했다.
- .gitignore: .gradle/ 로컬 캐시 및 컴퓨터별 JDK 설정을 Git에서 제외했다.
- Gradle 재검증 과정에서 수락된 기존 SDK 라이선스를 확인하고 NDK 27.1.12297006(r27b)을 Android SDK에 설치했다.
- prebuild가 자동으로 바꾼 package.json의 android/ios 스크립트는 원래 값으로 복원했다.
- docs/ANDROID_GITHUB_BUILD.md: 로컬 Android Studio 연결 설명과 이 보고서 링크를 추가했다.
- Android 생성물, 로컬 경로 설정, Gradle 캐시는 Git에 포함하지 않는다. DB/도메인 변경은 없다.

4. 추가 확인할 SDK 구성
- 현재 React Native 버전 카탈로그 요구: compileSdk/targetSdk 36, Build Tools 36.0.0, NDK 27.1.12297006.
- 설치된 플랫폼 37.0은 요구 플랫폼 36을 대신하지 않는다.
- Android SDK Command-line Tools, 플랫폼 36, NDK는 최초 점검 시 설치되어 있지 않았다.
- NDK 27.1.12297006은 재검증 중 자동 설치가 완료되었다.
- 최종 확인 시 플랫폼은 android-37.0만 설치되어 있다. 실제 컴파일 전에 SDK Manager에서 Android API 36을 추가해야 한다.
- SDK XML v4를 기존 도구가 v3까지 이해한다는 경고가 있었으나 이번 작업 목록 검증은 성공했다.
- 최종 판정: Android 프로젝트 및 Gradle 모듈 연결 검증 성공. Android Studio GUI Sync, API 36 기반 APK/AAB 컴파일, 에뮬레이터 앱 실행 및 네이티브 성능은 미검증.

5. Android Studio에서 확인하는 방법
- File > Open에서 J:/개인 프로젝트/App/travel_APP/apps/mobile/android 폴더를 연다.
- 저장소 루트를 계속 사용할 경우 프로젝트를 다시 열고 Gradle 연결 경로가 apps/mobile/android인지 확인한다.
- Gradle JDK는 GRADLE_LOCAL_JAVA_HOME이며 로컬 config.properties에서 JDK 21을 읽는다.
- SDK Manager에서 Android API 36을 추가 설치한다. NDK (Side by side) 27.1.12297006은 이번 검증 과정에서 설치 완료했다.
- 개발 빌드는 앱 JS 로딩에 Metro가 필요하다. 저장소 루트에서 npm start로 실행한다.
- 이 점검은 Play 업로드용 서명 AAB 생성이나 배포 완료를 의미하지 않는다.
- CLI 재검증 캐시는 .release/gradle-home에 있다. Android Studio 기본 Gradle 사용자 홈과는 별도이므로 IDE에서 처음 Sync하면 의존성을 다시 준비할 수 있다.
