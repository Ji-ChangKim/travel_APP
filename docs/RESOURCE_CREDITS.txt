2026-10-15 R11 재확인·표시 보완

위 8개 Commons 파일 설명 페이지의 저작자와 선택한 라이선스를 다시 대조했다. 실제 포함 JPEG의 가로 크기는 모두960px이며 사진 파일은 교체하지 않았다.
도시별 확인일·HTTPS 라이선스·축소/화면 자르기 표시는 apps/mobile/assets/destinations/credits.json에 반영했다.
다낭은 Commons 원본 파일명과 원문에 cropped 이력이 있으므로 이 이전 자르기도 앱 모달에 표시한다.
앱 내 공통 출처 모달에서 실제 작품명·저작자·원문·라이선스·변경 내용을 먼저 읽고, 명시적으로 고른 원문이나 이용 조건만 외부로 연다.
관광청 참고 자료는 해당 제공 기관과 TripPrint 한국어 편집 사실을 표시한다. 사진의 CC 라이선스를 관광청 원문 전체에 적용하지 않는다.
위키백과 도시 이야기는 실제 도시·문서가 일치하는 발췌에만 기여자·CC BY-SA 4.0·일반 텍스트 발췌/공백·길이 정리를 표시한다.
사진 출처별 재확인 근거는 위 도시별 Commons 원문 URL, 라이선스 조건은 각 원문에 연결된 Creative Commons 문서다.
발췌 이용 조건 참고: https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use/en#7._Licensing_of_Content
이미지 크기·현재 포함 파일 SHA-256·도시별 메타데이터 대조: outputs/r11-resource-audit.json.
사진·추가 소개·외부 열기 실패 시에도 같은 도시의 기본 가이드와 계획하기를 유지한다.
