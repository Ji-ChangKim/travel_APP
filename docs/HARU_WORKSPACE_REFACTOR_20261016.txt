TripPrint · 목록 CTA와 여행 상세 리팩토링
작업일: 2026-10-16

이번 요청에 맞춘 최종 위계
- 내 여행의 새 여행 만들기는 공통 헤더 오른쪽 44px + 아이콘으로 이동했다. 본문의 큰 생성 버튼은 제거했다.
- 검색·필터 결과에서 첫 번째로 보이는 카드 열기만 코랄 Primary다. 나머지 카드 열기는 작은 텍스트 버튼이다. 카드가 없는 경우 헤더 +로 여행을 시작한다.
- 상세는 일정·지도·비용 세 탭만 표시한다. 사진·영수증·준비물·동행·발자국 공유와 소유자의 여행 정보·기간 변경은 상단 ⋯ 메뉴로 통합했다.
- 상세 진입 시 글로벌 하단 탭을 숨기는 기존 탐색 정책을 유지하고 실제 화면에서 확인했다.
- 일정 화면 하단 가운데에 + 일정 추가 하나를 표시한다. 최대 폭은 320px이며 지도·카메라·앨범을 함께 두지 않는다. 보기 전용·지도·비용·부가 화면에서는 일정 추가 바를 숨긴다.
- 사진·촬영·영수증은 기존 타임라인과 사진·영수증 영역의 맥락에서 제공한다. 지도는 핵심 탭과 기존 장소 위치 확인에서 연다.

빈 일정의 실제 시작 경로
- 하루 안내와 두 개의 아웃라인 가이드 카드: 추천 코스 불러오기 / 장소 검색으로 추가.
- 추천 코스는 앱에 이미 있는 도시 가이드의 장소를 미리 보여준다. 장소 하나를 고르면 선택한 날짜의 일정 작성에 이름·설명만 채운다. 최적 동선·시간·좌표·비용은 추정하지 않는다.
- 저장하기 전에는 여행이 바뀌지 않는다. 미리보기 취소와 일정 작성 취소를 구분한다.
- 추천이 없는 도시는 빈 결과와 장소 검색을 안내하며 가짜 추천을 채우지 않는다.
- 장소 검색 카드는 작성 화면의 지도 검색·공유 링크 입력을 펼친다. 화면 표시용 placeSearchExpanded는 저장 명령에서 제외했다.
- 두 날짜를 모두 보더라도 하단 주요 버튼은 하나다. 읽기 전용에는 작성 가이드와 저장 행동을 노출하지 않는다.

유지한 디자인 규격
- 기존 하루 원본·코랄·네이비·아이보리와 Pretendard를 사용한다.
- 기본 글자 16px, 보조 글자 14px, 전역 내비게이션 13px. 실제 단색 배경 글자 대비 4.5:1 이상을 검사한다.
- 버튼의 눌림·초점·선택·로딩·비활성 상태는 공통 컴포넌트를 사용한다.
- 공통 헤더 56px, 뒤로가기와 헤더 아이콘 터치 영역 44px. 큰 글자는 제목 줄을 분리한다.
- 기간은 공통 YYYY-MM-DD – YYYY-MM-DD 표기를 유지한다.
