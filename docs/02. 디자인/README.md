# 02. 디자인

TripPrint 앱의 단일 디자인 토큰, 공통 UI 컴포넌트, 상단 헤더·하단 GNB, 화면별 설계 규격 및 리소스 경로를 정의합니다.

## 1. 공통 규격 (`00. 공통규격`)

- [design-tokens.json](<00. 공통규격/design-tokens.json>): 색상·타이포그래피·여백·모서리·컨트롤·네비게이션·WCAG AA 대비 단일 토큰
- [디자인 시스템](<00. 공통규격/디자인시스템.md>): 색상, 타이포그래피, 4px 그리드, 48×48dp 터치 영역, 공통 UI 컴포넌트 규칙
- [헤더·GNB 규격](<00. 공통규격/헤더GNB_규격.md>): `AppHeader`(`HomeHeader`/`ScreenHeader`) 및 4탭 `GlobalNavigation` 규격
- [팝업 규격](<00. 공통규격/팝업_규격.txt>): 공통 모달·확인창(`AppPopup`) 규격
