# 상단 헤더 및 하단 GNB 공통 규격

이 문서는 앱의 모든 화면이 공유하는 상단 헤더(`AppHeader`, `HomeHeader`, `ScreenHeader`)와 하단 글로벌 네비게이션 바(`GlobalNavigation`)의 단일 규격입니다.

페이지별 기능과 타이틀·GNB 배정 기준은 [앱 기본 구조 페이지별 기능 정의서](<../../01. 서비스기획/01. 기능정의/앱기본구조_페이지별기능정의서.md>)에 있습니다. 사용자의 구현 지시에 따라 홈은 브랜드 헤더, 내 여행·커뮤니티·MY는 공통 제목 헤더를 사용합니다. 커뮤니티 브랜드 헤더 예외를 해제하며 공통 치수·토큰·GNB 구성은 유지합니다.

---

## 1. 핵심 원칙

1. **공통 컴포넌트 단일 사용**: 모든 화면은 `apps/mobile/src/components/navigation/`의 공통 헤더와 하단 GNB만 사용하며, 개별 화면에서 자체 헤더나 탭 바를 만들지 않습니다.
2. **토큰 기반 스타일**: 색상·높이·여백은 [`design-tokens.json`](design-tokens.json)의 `navigation.header` 및 `navigation.gnb`를 그대로 따릅니다.
3. **자동 경계 검증**: `npm run check:navigation`으로 로컬 스타일 덮어쓰기나 비인가 헤더 생성 여부를 상시 검사합니다.

---

## 2. 상단 헤더 (`navigation.header`)

### 2.1 치수 및 색상

- **최소 높이**: `56dp` (안전 영역 상단 inset 별도 합산, 큰 글꼴에서 줄바꿈 시 자동 확장)
- **수평 여백**: 기존 공통 구현을 유지하며 **수직 여백**은 `navigation.headerPaddingVertical: 6`, **우측 액션 간격**은 `navigation.headerActionGap: 8`을 참조합니다.
- **배경/하단 경계선**: `#FFFFFF` / `1px solid #E2E8F0`
- **제목/부제 색상**: `#203247` / `#596574`
- **보조 액션 버튼**: 최소 `48×48dp`, 배경 `#F1F4FA`, 전경 `#203247`
- **주요 액션 버튼**: 최소 터치 영역 `48dp`, 색상은 `color.action` 및 공통 `HeaderAction`의 실제 변형을 따릅니다. 화면에서 색상을 덮어쓰지 않습니다.

### 2.2 헤더 유형

1. **홈 헤더 (`HomeHeader`)**: 좌측 브랜드 로고(`TripPrint`), 우측 핵심 진입 액션 최대 2개.
2. **기본 화면 헤더 (`ScreenHeader`)**:
   - 기본 루트 탭(`/plans`, `/footprints`, `/community`, `/my`): 뒤로가기 없이 각각 `내 여행`·`커뮤니티`·`커뮤니티`·`MY` 제목을 배치합니다. 홈(`/`)만 `HomeHeader`의 브랜드를 사용합니다.
   - 하위 상세·작업 화면: 좌측에 `48×48dp` 뒤로가기 버튼 + 화면 제목(필요 시 부제), 우측에 화면 핵심 액션 배치.
   - 앱의 큰 글꼴 설정에서 뒤로가기·우측 액션이 함께 있으면 제목은 공통 헤더의 아래 전용 행에서 전체 폭으로 표시합니다. 제목 크기·행간·액션의 터치 영역은 유지하고 헤더 높이만 확장합니다. 뒤로가기·행동이 없는 빈 행은 만들지 않습니다. 루트 탭과 우측 액션이 없는 하위 화면의 배치는 유지합니다.
3. **헤더 생략 예외**: 시작·웰컴 화면(`/welcome`)에 한해 상단 헤더를 생략합니다.

---

## 3. 하단 GNB (`navigation.gnb`)

### 3.1 탭 구성 (4탭 고정)

1. **홈** (`/`)
2. **내 여행** (`/plans`)
3. **커뮤니티** (`/footprints`, `/community` 호환)
4. **MY** (`/my`)

구현 기준은 `navigationModel.ts`와 `screenNavigationPolicy.json`입니다. `/trips/:id`는 여행 상세이며 `/account`는 설정 아래 계정 관리 화면입니다. 앱 기본 구조 작업은 현재 탭 개수·순서·스타일·모션을 바꾸지 않고 문서의 예전 이름과 주소를 실제 구성에 맞춥니다.

### 3.2 치수 및 색상

- **최소 높이**: `64dp` (하단 안전 영역 inset 별도 합산)
- **터치 영역**: 각 탭 최소 `48×48dp` 이상(`flex: 1`)
- **배경/상단 경계선**: `#FFFFFF` / `1px solid #E2E8F0`
- **비활성 탭**: 아이콘·라벨 `#596574`
- **활성 탭**: 아이콘·라벨 `#A43E31`, 활성 알약 배경 `#FFF0EB`
- **라벨 타이포그래피**: `typography.navigation`의 `13px` / 행간 `20px`, 아이콘 크기 `22dp`

### 3.3 노출 정책

- 루트 탭(`/`, `/plans`, `/footprints`, `/community`, `/my`)에서만 하단 GNB를 표시합니다. 커뮤니티의 두 주소는 같은 탭 선택으로 처리합니다.
- 로그인·프로필 설정, 여행 생성·편집 워크스페이스, 영수증 스캔·확인, 공개 여행 상세 화면에서는 하단 GNB를 숨깁니다.
