# 상단 헤더 및 하단 GNB 공통 규격

이 문서는 앱의 모든 화면이 공유하는 상단 헤더(`AppHeader`, `HomeHeader`, `ScreenHeader`)와 하단 글로벌 네비게이션 바(`GlobalNavigation`)의 단일 규격입니다.

---

## 1. 핵심 원칙

1. **공통 컴포넌트 단일 사용**: 모든 화면은 `apps/mobile/src/components/navigation/`의 공통 헤더와 하단 GNB만 사용하며, 개별 화면에서 자체 헤더나 탭 바를 만들지 않습니다.
2. **토큰 기반 스타일**: 색상·높이·여백은 [`design-tokens.json`](design-tokens.json)의 `navigation.header` 및 `navigation.gnb`를 그대로 따릅니다.
3. **자동 경계 검증**: `npm run check:navigation`으로 로컬 스타일 덮어쓰기나 비인가 헤더 생성 여부를 상시 검사합니다.

---

## 2. 상단 헤더 (`navigation.header`)

### 2.1 치수 및 색상

- **최소 높이**: `56dp` (안전 영역 상단 inset 별도 합산, 큰 글꼴에서 줄바꿈 시 자동 확장)
- **수평 여백**: `16dp`, **수직 여백**: `8dp`, **우측 액션 간격**: `8dp`
- **배경/하단 경계선**: `#FFFFFF` / `1px solid #E2E8F0`
- **제목/부제 색상**: `#203247` / `#596574`
- **보조 액션 버튼**: 최소 `48×48dp`, 배경 `#F1F4FA`, 전경 `#203247`
- **주요 액션 버튼**: 최소 높이 `48dp`, 배경 `#B84A39`, 전경 `#FFFFFF`

### 2.2 헤더 유형

1. **홈 헤더 (`HomeHeader`)**: 좌측 브랜드 로고(`TripPrint`), 우측 핵심 진입 액션 최대 2개.
2. **기본 화면 헤더 (`ScreenHeader`)**:
   - 루트 탭 화면(`/trips`, `/footprints`, `/account`): 뒤로가기 버튼 없이 좌측에 화면 제목 배치.
   - 하위 상세·작업 화면: 좌측에 `48×48dp` 뒤로가기 버튼 + 화면 제목(필요 시 부제), 우측에 화면 핵심 액션 배치.
3. **헤더 생략 예외**: 시작·웰컴 화면(`/welcome`)에 한해 상단 헤더를 생략합니다.

---

## 3. 하단 GNB (`navigation.gnb`)

### 3.1 탭 구성 (4탭 고정)

1. **홈** (`/`)
2. **내 여행** (`/trips`)
3. **발자국** (`/footprints`)
4. **내 정보** (`/account`)

### 3.2 치수 및 색상

- **최소 높이**: `64dp` (하단 안전 영역 inset 별도 합산)
- **터치 영역**: 각 탭 최소 `48×48dp` 이상(`flex: 1`)
- **배경/상단 경계선**: `#FFFFFF` / `1px solid #E2E8F0`
- **비활성 탭**: 아이콘·라벨 `#596574`
- **활성 탭**: 아이콘·라벨 `#A43E31`, 활성 알약 배경 `#FFF0EB`
- **라벨 타이포그래피**: `12px` / 행간 `16px`, 아이콘 크기 `22dp`

### 3.3 노출 정책

- 4대 루트 탭(`/`, `/trips`, `/footprints`, `/account`)에서만 하단 GNB를 표시합니다.
- 로그인·프로필 설정, 여행 생성·편집 워크스페이스, 영수증 스캔·확인, 공개 여행 상세 화면에서는 하단 GNB를 숨깁니다.
