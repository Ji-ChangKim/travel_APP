# 공통 팝업(AppPopup) 규격

## 1. 목적 및 적용 범위
- 앱 내 모든 확인 대화상자, 경고 모달, 작업 취소 확인, 권한 안내는 개별 `Modal`이나 브라우저 기본 `alert`/`confirm` 대신 공통 컴포넌트 `apps/mobile/src/components/ui/AppPopup.tsx`를 사용한다.

## 2. 레이아웃 및 스타일 규격
- 배경 딤(Overlay): `color.surface.overlay` (`rgba(32, 50, 71, 0.48)`)
- 팝업 카드 표면: `color.surface.card` (`#FFFFFF`), 모서리 반경 `radius.sheet` (`20dp`), 내부 패딩 `20dp`
- 최대 너비: 모바일 좌우 여백 `20dp` 확보, 최대 폭 `400dp`
- 제목: `typography.headlineSmall` (`18px`, 행간 `26px`, 굵기 `700`, 색상 `#203247`)
- 본문 설명: `typography.bodySmall` (`14px`, 행간 `20px`, 색상 `#596574`)
- 버튼 영역:
  - 모든 버튼은 최소 높이 `48dp` (`minimumTouchTarget: 48`) 이상을 유지한다.
  - 보조(취소/닫기) 버튼: 배경 `#F1F4FA` (`color.surface.low`), 글자 `#203247`
  - 주요(확인/실행) 버튼: 배경 `#B84A39` (`color.action.primary`), 글자 `#FFFFFF`
  - 위험(삭제/탈퇴/폐기) 버튼: 배경 `#B42318` (`color.status.error`), 글자 `#FFFFFF`

## 3. 접근성 및 동작 규칙
- 팝업이 열리면 배경 스크롤과 뒤쪽 요소 조작을 차단한다.
- 화면 읽기 도구(스크린리더)가 제목과 본문, 버튼을 순서대로 읽을 수 있도록 접근성 레이블을 부여한다.
- 큰 글꼴 설정에서도 문구가 잘리지 않도록 버튼 세로 쌓기(Stack) 또는 높이 확장을 허용한다.
