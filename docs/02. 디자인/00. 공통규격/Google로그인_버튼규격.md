# Google 로그인 버튼 규격

상태: 디자인 규격·목업·앱 코드 반영, 로컬 웹 검수. 확인일: 2026-11-04. Android·iOS 설치본과 실제 Google 계정 인증은 별도 검증 대상이다.

## 목적과 적용 범위

여행자가 Google 계정으로 TripPrint를 시작하는 버튼을 쉽게 알아보도록 한다. Google 버튼만 공급자 브랜드 규격을 사용한다. 게스트 버튼, TripPrint 로고, 본문, 공통 헤더·GNB와 인증 로직은 바꾸지 않는다. `/welcome`과 목적이 있는 `/login` 모두 앱 적용 시 이 규격을 따른다.

기준은 사용자가 지정한 [Google 한국어 가이드](https://developers.google.com/identity/branding-guidelines?hl=ko), [최신 영문 원문](https://developers.google.com/identity/branding-guidelines?hl=en), [공식 PNG·SVG 배포 묶음](https://developers.google.com/static/identity/images/signin-assets.zip)이다. 한국어 문서는 2025-12-10, 영문 원문은 2026-07-07 갱신으로 표시돼 있다. 한국어의 Roboto와 영문의 Google Sans 지시가 다르므로 최신 영문과 현재 배포 자산을 우선한다. SDK가 렌더링하는 공식 버튼을 우선 검토하되, 기존 인증 흐름의 교체 여부는 별도 구현 작업에서 판단한다.

## 채택한 모습

밝은 테마의 직사각형 버튼을 사용한다. Google이 정한 값과 앱에서 선택한 값을 구분한다.

| 항목             | 기준과 선택 이유                                                                                                                                                                  |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 문구             | 한국어 `Google 계정으로 계속`, 영어 `Continue with Google`, 일본어 `Google で続行`. Google 인증으로 TripPrint를 이용한다는 뜻을 유지한다.                                         |
| 배경·글자·경계   | 공식 Light 기준 `#FFFFFF`·`#1F1F1F`·`#747775`, 안쪽 1px 경계. 앱의 네이비 글자와 공통 컨트롤 경계로 덮어쓰지 않는다.                                                              |
| 글꼴             | 영문·숫자는 Google Sans Medium 500, 기본 14/20. 한글은 Noto Sans KR Medium을 대체 글꼴로 선택한다. 한글 대체는 프로젝트의 현지화 선택이며 Google의 의무 지정으로 설명하지 않는다. |
| G 로고           | 공식 그라데이션 G 원본. 20×20 표시 영역에서 원본 비율 유지, 가운데 맞춤. 재작성·단색화·필터·찌그러뜨림·다른 아이콘 대체 금지.                                                     |
| Android·웹 여백  | 로고 앞 12, 로고와 글자 사이 10, 글자 뒤 최소 12. 여분 너비는 글자 영역에 둔다.                                                                                                   |
| iOS 여백         | 로고 앞 16, 로고와 글자 사이 12, 글자 뒤 최소 16. 플랫폼별 차이를 공통 24 패딩으로 덮어쓰지 않는다.                                                                               |
| 모서리           | 공식 직사각형 자산의 반경 4를 채택한다. 앱 공통 버튼의 반경 12를 강제하지 않는다.                                                                                                 |
| 너비·높이        | 앱 선택: 좌우 화면 여백 20, 가용 너비 전체, 최소 높이 52, 최소 터치 영역 48. 공식 예시 Android·웹 180×40, iOS 188×44는 모든 화면의 고정 크기가 아니다.                            |
| 큰 글자          | 사용자의 글자 배율을 반영해 글자·버튼 높이를 늘리고 줄바꿈한다. G와 플랫폼 여백을 유지한다. 문구 잘림이나 글자 축소로 대응하지 않는다.                                            |
| 다른 로그인 수단 | 추가할 때 Google과 크기·비중을 비슷하게 맞춘다. 게스트는 다른 소셜 인증 제공자로 분류하지 않는다. 두 버튼의 가용 너비와 최소 높이는 맞춘다.                                       |

20 로고와 반경 4는 공식 묶음의 `Android + Web/SVG/Light/Theme=Light, Show text=Yes, Shape=Square, Platform=Android+Web.svg`와 iOS 대응 파일을 대조했다. 별도 패딩 도해 링크는 확인 당시 404여서, 본문에 명시된 플랫폼 여백과 다운로드 자산을 함께 확인했다.

## 버튼을 누른 뒤의 표시

Google G와 기본 문구는 처리 중에도 유지한다. 중복 누르기를 막고 버튼 바깥에서 진행 상황을 알린다. 화살표·다른 서비스 로고·로딩 원을 G 자리에 넣지 않는다. 취소를 로그인 완료로 표시하지 않는다. 실패하면 버튼 아래에서 다시 시도할 방법을 안내한다.

목업의 눌림 표현은 글자·G를 바꾸지 않는 중립색 상태 레이어로 제공한다. 이 상태 레이어와 키보드 초점 표현은 프로젝트의 상호작용 선택이다. Google의 인증 승인이나 브랜드 심사 완료로 표현하지 않는다.

## 원본과 구현 인계

기존 `apps/mobile/assets/brand/tripprint-v1/Google_G.png`는 공식 `g-logo.png`와 SHA-256이 일치했다. 크기는 200×204이며 `contain`으로 표시한다. 해시는 `d1ce9c2af0b10a7333abc99bc706f9a6a199e5b65bf3e3009624f076b8638e6a`다.

목업 글꼴은 공식 Google Fonts에서 받은 Google Sans Medium과 Noto Sans KR Medium이다. 원본 URL·해시·라이선스, 공식 ZIP과 대조 파일은 로컬 검수 폴더의 `google-reference/`에 기록했다. 이후 실제 앱 적용에서 Google Sans와 한·일 대체 글꼴을 앱에 등록하고 자산·라이선스·리소스 명세를 함께 기록했다.

실제 앱의 `GoogleLogin`은 전용 `GoogleBrandButton`을 사용한다. 공급자 전용 색·글꼴·여백과 기존 콜백·사용 가능 여부·중복 요청 방지를 연결했다. Google G와 문구는 처리 중에도 유지한다. 앱의 한·일·영 버튼 글꼴과 라이선스·해시는 `assets/fonts/google-sign-in/font-manifest.json`에 등록했다. 인증 SDK·OAuth 설정 변경과 배포는 이번 적용 범위에 포함하지 않는다.

## 검수 기준과 이번 결과

대상은 2026-11-04 목업 v2다. 설치된 Chrome의 로컬 목업에서 버튼 선택과 전환, 320·390·430 너비, 글자 100%·200%, 긴 문구, 움직임 줄이기를 확인한다. 색·굵기·행간·로고 표시 크기·패딩·반경은 계산된 스타일로도 대조한다. 증거는 `outputs/startup-login-mockup-2026-11-04/`에 둔다.

실제 앱의 로컬 웹 빌드 검증은 [적용 검수 기록](<../../05. 검수/02. 검수보고/2026-11-04_BICI_로그인연출_적용검수.md>)을 따른다. Google 계정 인증 성공과 iOS·Android 설치본은 미검증이다. 문서·목업·시험 응답만으로 Google 심사 통과나 실기기 검수 완료를 보고하지 않는다.
