TripPrint 앱 뼈대 재설계 / 2026-10-27

2026-11-02 핵심 흐름 보완: 날짜가 있는 서버 초안도 정식 생성 전에는 작성 중이다. 초안 카드는 이어쓰기로만 연결하고, 예정·여행 중의 세부 일정·영수증 행동은 정식 여행에만 제공한다. 정식 전환한 여행과 같은 ID의 남은 초안 조회 결과는 중복 표시하지 않는다. 나머지 공통 배치와 헤더·GNB는 유지한다. 단계별 저장 기준은 docs/01. 서비스기획/01. 기능정의/계획생성_일정저장_정책.md를 따른다.

요청과 적용 범위
로고·브랜드명 TripPrint·하루의 원본 자산을 보존한다. 이번 구현은 앱 진입 구조와 홈, 공통 탐색을 재구성하는 첫 뼈대다. 상세 일정·생성·계정·커뮤니티 화면은 실제 동작하는 기존 화면에 연결한다. 모든 상세 화면의 시각 재설계 완료를 뜻하지 않는다. 운영 배포는 하지 않는다.

현행 실행 경로와 문제
실제 / 경로는 PlanningStartScreen이다. 이전 HomeScreen은 현행 첫 화면이 아니므로 그 화면의 추천 배치 문제를 현행 문제로 오인하지 않는다.
1. PlanningStartScreen: 예정 여행이 0개여도 제목과 숫자를 노출한다. 빈 사용자에게 필요 없는 정보다.
2. HomeTravelCard/homeTravelStyles: 사진이 없을 때 검토용 마젠타가 실제 앱에 표시된다.
3. navigationModel: 내 여행이 전역 메뉴에 없고 생성 행동이 목적지와 섞여 있다.
4. homeTravelModel: 완료 여행은 홈 분류에서 빠진다. 여행 후 영수증 정리 진입이 보이지 않는다.
5. PlanningStartScreen: 사용자 데이터가 없는 상태에서 앱의 기록 가치를 설명하는 시작점이 부족하다.

설계 근거
UI UX Pro Max의 접근성·탐색 예측 가능성·명시적 행동 이름·빈 상태 기준을 적용했다. 디자인 시스템 검색의 Aurora UI/스크롤 스토리텔링 추천은 여행 관리 도구에 맞지 않아 채택하지 않았다. 아래 구성은 현재 제품과 원본 브랜드에 맞춘 설계 판단이다.

앱 흐름
앱 시작 → 인증 복원 → 홈
홈 → + 새 여행 만들기 → 로그인(필요 시) → 날짜/여행지 → 저장 → 여행 상세
홈 → 기록할 여행 선택 → 실제 저장한 여행 선택(완료 여행 포함) → 비용 → 기존 영수증 등록/검토/저장
홈 → 전체 여행 관리 → 내 여행 목록
홈 → 작성 중인 계획 관리 → 초안 이어쓰기/기존 기기 초안 가져오기
하단 내 여행 → 기존 여행 목록·검색·상태 필터 → 여행 상세
하단 커뮤니티 → 기존 공개 여행 목록 → 공개 여행 상세
하단 MY → 계정·언어·설정

홈 표현 규격
배경은 공통 canvas, 읽기 면은 card, 영수증 면은 selectedSurface를 사용한다.
본문 최대640, 좌우20, 구역24, 카드 안쪽20~24, 반경20~24.
공식 하루는 시작 카드에96×128 contain으로 표시하며 장식으로 처리한다.
시작 제목30/40 Bold, 설명16/26, 보조14/22. 한국어·영어·일본어 LINE Seed를 유지한다.
생성 버튼에 + 아이콘24. 버튼 최소48 터치, 큰 글꼴에서 높이 확장. 고정 문구는 번역하고 사용자 여행 이름은 원문을 유지한다.
사진 미등록/조회 실패는 중립 색상으로 처리하며 가짜 여행 사진을 넣지 않는다.
일정 분류와 D-day는 기존 서버 데이터 및 현지 날짜 계산을 유지한다. 출발일 없는 여행만 작성 중이다.

공통 탐색
홈(/), 내 여행(/plans), 커뮤니티(/footprints), MY(/my)의 4개 목적지.
기존 GlobalNavigation과 ScreenHeader/HomeHeader, 선택 상태, 최소48 터치, 안전 영역, 모달 차단, 미저장 이탈 보호를 유지한다. 생성은 선택 가능한 탭이 아니라 홈의 명시적 행동이다.

상태별 동작
정상: 실제 여행과 초안, 실제 공개 팁만 표시.
빈 상태: 생성 안내. 예정 여행0 제목 숨김. 영수증 선택 목록이 없으면 여행 생성 안내.
조회 중: 불러오는 중 표시, 빈 상태와 구분.
오류: 실패한 조회별 재시도. 실패를 빈 데이터나 예시 여행으로 바꾸지 않음.
영수증 선택: 비로그인은 로그인 후 내 여행 목록으로 연결. 보관 처리된 여행 제외, 완료 여행 포함. 아직 서버 여행이 아닌 초안 제외. 선택 후 기존 비용 화면으로 이동하며 촬영이 바로 시작된다고 표현하지 않음.

검증 및 후속
npm run check, 헤더/GNB 회귀, 새 홈의 빈 상태·오류·완료 여행 선택·생성 동선·320/390/430 및 큰 글꼴 검증.
웹 테스트 응답은 테스트용 고정 데이터이며 운영 DB 인수 증거가 아니다.
후속 화면 재설계 순서: 내 여행 목록 → 여행 생성 → 여행 상세/영수증 → 커뮤니티 → MY.
실기기에서는 카메라/사진 권한, 안전 영역, 키보드, 시스템 글꼴 확대, Android 뒤로가기를 별도 확인한다.
