# 디자인 시스템 (MVP 단일 기준)

이 문서는 TripPrint 모바일·웹 앱이 준수하는 **단일 UI/UX 디자인 시스템 규격**입니다. 모든 화면과 스타일은 [`design-tokens.json`](design-tokens.json) 및 `apps/mobile/src/constants/theme.ts`를 단일 소스로 참조하며, 개별 화면에서 임의의 헥사코드(`#...`)나 별도 테마 파일을 선언하지 않습니다.

---

## 1. 핵심 원칙

1. **단일 토큰 소스**: 모든 색상·타이포그래피·여백·모서리 반경·컨트롤 치수는 [`design-tokens.json`](design-tokens.json)에서 정의하고 `apps/mobile/src/constants/theme.ts`를 통해 공급합니다.
2. **공통 컴포넌트 우선**: 상단 헤더(`AppHeader`), 하단 탭(`GlobalNavigation`), 모달·확인창(`AppPopup`), 텍스트(`AppText`), 버튼(`Button`), 입력창(`Input`), 카드(`Card`), 칩(`Chip`), 표면(`Surface`) 등 `apps/mobile/src/components/ui/`의 공통 컴포넌트를 재사용합니다.
3. **WCAG 2.1 AA 명도 대비**: 일반 텍스트는 **4.5:1 이상**, 큰 텍스트와 핵심 컨트롤 경계선은 **3.0:1 이상**의 대비를 유지하며 `npm run check:design`을 100% 통과해야 합니다.
4. **최소 터치 영역**: 모든 클릭·터치 가능한 요소는 최소 **48×48dp**(`minimumTouchTarget: 48`)를 확보합니다.

## 3. 타이포그래피

- **기본 글꼴**: `LINESeedKR` (`LINESeedKR-Rg`, `LINESeedKR-Bd`)
- **폴백 글꼴**: `Pretendard`, `Noto Sans KR`, `Noto Sans JP`, `sans-serif`
- 모든 텍스트는 `AppText`를 통해 렌더링하며 시스템 글자 크기 확대 시 고정 높이(`height`) 대신 `minHeight`와 줄바꿈을 허용합니다.

## 4. 공간·레이아웃·모서리 반경

- **여백(`spacing`)**: `xs: 4`, `sm: 8`, `md: 12`, `lg: 16`, `xl: 20`, `xxl: 24`, `section: 32`
- **레이아웃(`layout`)**:
  - 모바일 좌우 기본 패딩(`screenPaddingMobile`): `20px`
  - 모바일 콘텐츠 최대 폭(`mobileMaxWidth`): `640px`
  - 데스크톱/태블릿 확장 분기(`wideBreakpoint`): `1024px` (`wideMaxWidth: 1200px`, `wideGutter: 24px`, `sidebarWidth: 256px`)
  - 카드 내부 기본 패딩(`cardPadding`): `16px`, 카드 간 기본 간격(`gridGap`): `12px`
- **모서리 반경(`radius`)**: `chip: 10`, `button: 12`, `card: 16`, `sheet: 20`, `pill: 999`
- **컨트롤 높이(`control`)**: 주요 CTA(`primary.height`): `52dp`, 보조·일반 버튼(`secondary`/`quiet`): `48dp`

## 5. 공통 입력 검수

- 일반 텍스트 입력은 공통 `DesignInput`을 사용하며 기본 크기 16px·행간 24px과 LINE Seed 글꼴을 적용합니다. 큰 글자 설정을 유지하고 글꼴 로딩 실패 시 시스템 글꼴로 입력을 허용합니다.
- 한글 조합 중인 원문을 저장용 정규화나 문자열 절단으로 덮어쓰지 않습니다. 길이·허용 문자 검사는 각 필드의 규칙에 따라 초점 이동 또는 제출 시 확정합니다.
- 글자 수 상한, 계산 단위, 공백·줄바꿈·허용 문자, 기존 값 예외, 실패 시 입력 보존을 필드별로 명시합니다. 숫자 상한만 적은 것으로 검수를 끝내지 않습니다.
- 웹의 조합 취소 키가 모달 닫기나 폼 제출로 이어지지 않는지 확인합니다. 값 붙여넣기 검사와 실제 키보드 조합 검사를 구분해 기록합니다.
