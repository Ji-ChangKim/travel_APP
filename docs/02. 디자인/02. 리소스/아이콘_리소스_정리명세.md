- **문서 버전**: v1.0.0
- **기준일자**: 2026-10-27
- **문서 상태**: 보유 자산 목록과 향후 교체 후보. 전 화면 적용 완료를 뜻하지 않음
- **적용 대상**: `apps/mobile/assets/icons/tripprint/`, `apps/mobile/src/components/icons/`. 공통 헤더·GNB는 승인된 기존 아이콘을 유지
- **관련 문서**: [디자인 가이드 모듈화 규격](<../00. 공통규격/디자인가이드_모듈화규격.md>), [리소스 이름규칙](리소스_이름규칙.md), [아이콘 카탈로그](icon-catalog.html)

## 1. 개요 및 정리 배경

### 1.1 현황 진단

저장소에는 SVG 53종과 `TripIcon` 렌더러가 있습니다. 파일이 있다는 사실과 화면에서 사용한다는 사실은 구분합니다.

현재 화면은 `TripIcon`과 `@expo/vector-icons`를 함께 사용합니다. 특히 공통 헤더·GNB의 Ionicons는 기존 규격입니다. 이 문서를 근거로 전면 교체하지 않습니다.

### 1.2 교체를 검토할 때 확인할 내용

1. 같은 역할의 아이콘이 같은 크기·선 두께·색·터치 영역을 따르는지 확인합니다.
2. 변경할 화면과 유지할 공통 규격을 먼저 정합니다.
3. 파일 수만으로 성능 저하를 단정하지 않습니다. 실제 번들 포함량과 로딩 시간을 측정해야 합니다.

### 1.3 정리 목표

- **53종 자체 아이콘 자산의 카테고리별 표준화 및 전수 명세화**.
- **사용자가 교체를 요청할 때 참고할 매핑 후보 정리. 공통 아이콘 전면 교체는 별도 승인·검증 대상**.
- **향후 신규 아이콘 추가 및 글로벌 스킬(`icon-generator`)을 통한 앱 런처 아이콘 빌드 파이프라인 정립**.

## 2. 아이콘 제작 및 디자인 표준 규격

### 2.1 기하 구조 및 벡터 규격

- **기준 캔버스 (viewBox)**: `0 0 24 24` (24×24dp)
- **기본 선 두께 (Stroke Width)**: `2px`
- **예외 선 두께**: 강조 액션 플로팅 버튼(`plus-outline`) 및 상태 피드백(`success`, `warning`, `error`, `info`)은 가독성 확보를 위해 `2.5px` 허용.
- **선 끝 및 연결 (Stroke Cap / Join)**: `stroke-linecap="round"`, `stroke-linejoin="round"` 적용으로 부드러운 여행 감성 부여.

### 2.2 3대 형태 변형 (Variants)

1. **`outline` (선형)**:
   - 기본 상태 및 일반 메뉴/버튼에 사용.
   - `fill="none"`, `stroke="currentColor"`.
2. **`filled` (면형)**:
   - 탭 선택 상태, 북마크 완료, 좋아요 활성 상태에 사용.
   - `fill="currentColor"`, `stroke="none"`.
3. **`duotone` (2도 채색형)**:
   - 주요 여행 카테고리(장소, 교통, 카메라 등)의 시각적 포인트를 줄 때 사용.
   - 주 라인은 `currentColor`, 내부 포인트 영역은 `#FF6B57` (코랄) 또는 소프트 배경색 적용.

### 2.3 파일 네이밍 규칙

```text
icon-{meaning}-{variant}.svg
```

- 영문 소문자, 숫자, 하이픈(`-`)만 사용.
- 의미(`meaning`)는 영문 단수형 권장.
- 변형(`variant`)은 반드시 `outline`, `filled`, `duotone` 3가지 중 하나로 명시.

## 4. 컴포넌트 구현 및 호출 규격

모든 화면은 `@expo/vector-icons`를 직접 import하지 않고, 공통 `TripIcon` 컴포넌트를 사용합니다.

### 4.1 기본 사용법

```tsx
import TripIcon, { type TripIconName } from '@/components/icons/TripIcon';
import { colors } from '@/constants/theme';

// 1. 기본 크기(24px) 및 기본 텍스트 색상 사용
<TripIcon name="receipt-scan-outline" />

// 2. 크기 및 브랜드 색상 지정
<TripIcon name="flight-outline" size={20} color={colors.brandCoral} />

// 3. 듀오톤 아이콘 (포인트 코랄 컬러 자동 렌더링)
<TripIcon name="metro-duotone" size={24} color={colors.text} />
```

### 4.2 색상 치환 원리 (`TripIcon.tsx`)

- 단색 아이콘: 전달된 `color` prop이 SVG의 `currentColor`로 자동 매핑됩니다.
- 듀오톤 아이콘: 내부의 시그니처 코랄(`brandCoral #FF6B57`) 포인트는 유지되며, 주 라인만 지정한 `color`로 렌더링되어 TripPrint 고유의 통일된 브랜딩을 유지합니다.
