# 리소스 저장 경로 규격

이 문서는 앱에서 사용하는 브랜드 로고·캐릭터, 글꼴, 아이콘, 도시 이미지의 물리 저장 경로와 관리 규칙을 정의합니다.

---

## 1. 폴더별 역할 (`apps/mobile/assets/`)

| 경로                                     | 용도                                                          | 관리 규칙                                                                        |
| ---------------------------------------- | ------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `apps/mobile/assets/brand/tripprint-v1/` | TripPrint 로고, 앱 아이콘, 스플래시 이미지 및 `manifest.json` | 앱 설정(`app.config.ts`) 및 시작 화면과 직접 연결됨                              |
| `apps/mobile/assets/brand/haru-v1/`      | 하루(Haru) 캐릭터 일러스트 및 `manifest.json`                 | 온보딩·빈 상태·안내 화면에서 공통 사용                                           |
| `apps/mobile/assets/fonts/line-seed/`    | 기본 글꼴 `LINESeedKR` (`Rg`, `Bd`, `Th`) 및 라이선스         | `design-tokens.json`의 `font` 토큰과 일치해야 함                                 |
| `apps/mobile/assets/fonts/pretendard/`   | 폴백 글꼴 `Pretendard`                                        | 다국어 및 보조 렌더링 폴백용                                                     |
| `apps/mobile/assets/icons/tripprint/`    | SVG 아이콘 원본 및 `icon-manifest.json`                       | 런타임 컴포넌트는 `apps/mobile/src/components/icons/tripprint-icons.ts`에서 참조 |
| `apps/mobile/assets/destinations/`       | 추천 목적지 대표 이미지 및 `credits.json`                     | 라이선스·작성자 출처를 `credits.json`에 반드시 기록                              |
| `apps/mobile/assets/illustrations/`      | 홈 히어로 등 화면별 고정 일러스트                             | 정적 require/import 경로 무결성 유지                                             |

---

## 2. 검증 및 주의사항

1. **사용자 업로드 데이터 분리**: 사용자가 촬영·업로드하는 영수증과 여행 사진은 소스 저장소(`assets/`)에 넣지 않으며, 기기 저장소(게스트) 또는 비공개 Cloudflare R2(회원)에만 보관합니다.
2. **자동 무결성 검사**: 리소스 파일을 추가·이동·삭제할 때는 반드시 `npm run check:resources`를 실행하여 코드 내 `require`/`import` 경로, 글꼴 바이트, `credits.json` 출처 명세가 모두 일치하는지 확인합니다.

## 3. 시작 화면 무음 영상

`apps/mobile/assets/brand/tripprint-v1/tripprint_bi.mp4`는 사용자가 승인한 4초 무음 영상입니다. `tripprint_bi_poster.png`는 영상 재생 전과 재생 실패 시 표시하는 정지형입니다. 두 파일의 크기·SHA-256과 영상 규격은 같은 폴더의 `startup-motion-manifest.json`에 기록합니다. 파일 교체 시 명세도 함께 갱신합니다. 설치 아이콘과 다른 화면의 로고 원본은 교체하지 않습니다.
