# 설치 아이콘 적용

적용일: 2026-10-27. 사용자가 `Logo_APP.png`를 설치용 아이콘으로 지정하고 적용을 요청했다.

## 어떤 이미지인가요?

휴대폰에 앱을 설치하면 보이는 빨간 바탕·흰색 심볼 아이콘이다. 시작 화면 안의 투명 심볼과 영문 로고는 별도 자료다. 첫 화면에는 앞서 받은 투명 로고를 계속 쓴다.

앱 원본 폴더는 `apps/mobile/assets/brand/tripprint-v1/`다.

| 파일                              | 역할                                                                                                   |
| --------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `tripprint-launcher-source.png`   | 사용자가 준 1254 × 1254 RGB 원본. 원래 이름은 Logo_APP.png이며 파일 내용과 해시를 보존                 |
| `tripprint-launcher-icon.png`     | 설치·빌드용 1024 × 1024 PNG. 원본 전체 비율과 배경을 유지하며 투명 픽셀이 없음                         |
| `tripprint-launcher-adaptive.png` | Android용 흰색 심볼 전경. 밝은 심볼의 알파를 분리하고 안전 여백을 추가. 테마 아이콘에도 같은 알파 사용 |
| `provided-assets-manifest.json`   | 원본 이름·출처·해시·크기·가공 방식·연결 정보를 기록                                                    |

Android는 기기마다 원형이나 둥근 사각형으로 아이콘을 자른다. 비행기와 궤도가 잘리지 않도록 전경을 원본 전체 기준 70%로 중앙 배치했다. 전경 배경은 투명하고 별도 바탕색은 원본에서 가져온 `#FC5041`이다. 이 색은 설치 아이콘 전용이며 앱의 공통 주요 색상을 변경하지 않는다. 일반 아이콘에는 원본 배경을 그대로 사용한다.

## 어디에 연결했나요?

`apps/mobile/app.config.ts`의 `icon`을 새 일반 아이콘에 연결했다. iOS도 이 공통 아이콘을 사용한다. Android `adaptiveIcon`의 전경·단색 전경·배경색도 갱신했다. 기존 패키지 이름, 계정, 여행 데이터, 웹 파비콘, 스플래시 화면은 이 변경 대상이 아니다.

Android Studio가 사용 중인 로컬 네이티브 프로젝트의 mipmap 아이콘과 `iconBackground`도 같은 Expo 아이콘 생성기로 갱신한다. 이 네이티브 폴더는 Git 제외 대상이므로 다른 환경에서는 새 앱 설정을 바탕으로 네이티브 프로젝트를 생성해야 한다. 이전 브랜드 파일은 과거 시안 참조를 위해 보존한다.

## 다시 만드는 방법

`icon-generator` 스킬과 Pillow를 사용한다. 아래 명령의 스킬 경로는 실행 환경에 맞춘다.

```powershell
node scripts/design/export-launcher-assets.mjs --generator 'C:/Users/Jichang/.codex/skills/icon-generator/scripts/icon_generator.py'
```

스킬이 Android 밀도별 PNG·스토어용 이미지·iOS AppIcon 세트를 `outputs/launcher-icons/`에 만든다. 프로젝트의 재생성 도구는 여기서 일반 아이콘을 가져오고 Android 전경을 만든다. 이 전경 분리 방식은 이번 밝은 심볼 원본 전용이다. 다른 그림에 자동으로 재사용하지 않는다.

아이콘은 앱을 새로 빌드해 설치해야 바뀐다. 개발 화면 새로고침이나 웹 갱신만으로 이미 설치된 아이콘이 교체되지는 않는다. 재설치 확인은 기존 앱의 데이터를 지우지 않는 업데이트 설치로 진행한다. 스토어 배포는 이번 범위에 포함하지 않는다.

## 확인 기준

원본 해시 일치, 일반 아이콘의 1024 정사각형·불투명 여부, Android 심볼의 중앙 안전 원 안 배치를 검사한다. 원형·둥근 사각형 미리보기를 보고 비행기와 궤도가 잘리지 않는지도 확인한다. 로컬 증거는 `outputs/launcher-icons/validation.json`과 `launcher-preview.png`다.

에뮬레이터 설치 확인과 실제 Android 기기·iOS 설치 확인은 구분해서 보고한다. 테마 아이콘은 런처 지원 여부와 사용자 설정에 따라 달라진다.
