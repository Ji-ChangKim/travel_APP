# 시작·로그인 예외 처리 규격

- **적용 경로**: `apps/mobile/app/welcome.tsx`, `apps/mobile/app/login.tsx`, `apps/mobile/app/profile-setup.tsx`
- **공통 기준**: [디자인 시스템](<../00. 공통규격/디자인시스템.md>), [팝업 규격](<../00. 공통규격/팝업_규격.txt>)

---

## 1. 앱 시작 시 버전·네트워크 예외

1. **필수 업데이트 필요**:
   - 서버 정책이 요구하는 최소 지원 버전보다 앱 버전이 낮으면 업데이트 안내 모달(`AppPopup`)을 표시하고 스토어 이동 버튼을 제공합니다.
2. **시작 정책 조회 실패**:
   - 일시적 네트워크 오류로 정책 조회에 실패해도 기존 로컬 데이터나 게스트 둘러보기 진입을 부당하게 차단하지 않으며, 재시도 버튼을 함께 제공합니다.

---

## 2. 로그인 및 게스트 병합 예외

1. **사용자 취소 및 인증 중단**:
   - 외부 브라우저 소셜 로그인 창을 닫거나 취소한 경우, 기술적 예외 원문(SQL·토큰·스택트레이스)을 노출하지 않고 다시 로그인하거나 둘러보기로 돌아갈 수 있는 안내 문구를 표시합니다.
2. **게스트 기록 가져오기 충돌·실패**:
   - 게스트 여행을 회원 계정으로 가져오는 도중 네트워크 오류가 발생하면 기기에 저장된 게스트 원본 데이터를 삭제하지 않고 그대로 보존하여 재시도를 보장합니다.
3. **닉네임 중복 및 입력 오류**:
   - 프로필 생성 시 중복된 닉네임이나 금칙어가 입력되면 입력창 하단에 `#B42318`(`color.status.error`) 색상의 쉬운 한글 안내를 표시하고 입력값을 유지합니다.
