## 앱 시작

필수 업데이트는 공통 안내와 스토어 이동을 제공한다. 시작 정책·세션 확인 실패에는 실제 재시도를 연결한다. 통신 실패를 새 게스트 선택으로 처리하거나 회원 기록을 지우지 않는다. 기기에 있는 기록은 보존하며 아직 확인하지 못한 상태를 정상으로 표시하지 않는다.

## Google 로그인과 기본 프로필

인증 창 취소는 로그인 성공으로 넘기지 않는다. 입력했던 목적지·작성 내용을 유지하고 Google 재시도나 게스트 시작으로 돌아간다. 공급자·세션·기본 프로필의 실패를 가짜 회원·예시 데이터로 대체하지 않는다.

기본 프로필은 추가 입력을 요구하지 않는다. 과거 닉네임·생일 입력 오류와 중복 확인을 로그인 관문으로 사용하지 않는다. 조회 실패에는 계정 확인 재시도와 로그인 복귀를 제공하고, 계정 전환 후 늦은 응답은 무시한다.

## 게스트 기록 가져오기

Google 인증 성공만으로 기기 기록 전체를 전송하지 않는다. 사용자가 고른 여행만 가져오고 실패 시 기기 원본을 보존한다. 재시도에서도 같은 여행이 중복 생성되지 않아야 한다. 게스트 서버 저장은 별도 구현 과제이며 현재 기기 전용 기록을 서버에 보관한 것으로 안내하지 않는다.

## 계정 관리

신규 계정 삭제에는 90일 복구 유예를 안내하지 않는다. 최근 인증 요구·소유권 이전 필요·버전 충돌·통신 실패를 구분한다. 삭제 사전 확인 실패 시 삭제 요청 버튼을 열지 않는다. 접수 응답과 실제 삭제 완료를 구분하고 실패를 성공으로 표시하지 않는다.
