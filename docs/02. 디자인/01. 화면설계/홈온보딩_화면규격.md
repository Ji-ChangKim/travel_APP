# 홈·온보딩 화면 규격

- **적용 경로**: `apps/mobile/src/app/(tabs)/index.tsx` (`/`), 실제 화면은 `features/workspace/planning/ui/PlanningStartScreen.tsx`
- **스타일 소스**: `apps/mobile/src/features/workspace/home/styles/homeTheme.ts`, `homeTravelStyles.ts` (`@/constants/theme` 연동)
- **공통 기준**: [디자인 시스템](<../00. 공통규격/디자인시스템.md>), [헤더·GNB 규격](<../00. 공통규격/헤더GNB_규격.md>)

별도 웹사이트 홈의 로그인 전·후 본문과 버튼·복귀 흐름은 [웹 홈페이지 화면 계획](웹홈페이지_화면계획.md)의 검토안을 따른다. 웹에는 게스트 시작을 제공하지 않는다. 해당 검토안은 기존 앱 홈과 아래 공통 헤더·GNB의 변경 지시가 아니다.

---

## 1. 상단 헤더 및 하단 GNB

- **상단 헤더**: `HomeHeader`의 `travel-home` 유형. 좌측 `TripPrint` 브랜드를 표시하며 현재 우측 액션은 없습니다. 새 여행 만들기는 본문 진입점을 사용합니다.
- **하단 GNB**: 4탭 `GlobalNavigation` 표시 (`홈` 탭 활성).

앱 기본 구조 작업은 [앱 기본 구조 화면 규격](앱기본구조_화면규격.md)을 따른다. 홈의 진입점만 정리하고 여행 제작 화면은 변경하지 않는다. 추천 자료는 공식 여행 정보로 설명하며 자동 동선 완성·실제 방문 검증을 주장하지 않는다. 추천 카드의 생성 버튼은 도시를 선택한 여행 만들기로 이동한다고 표시한다. 경비 도구는 실제 기록할 여행 선택으로 연결한다.

---

## 2. 상태별 화면 구성

### 2.1 빈 상태 (등록된 여행이 없을 때)

- **히어로 플래너 카드 (`HomeEmptyHero` / `emptyPlannerCard`)**:
  - 카드 배경 `#FFFFFF`, 테두리 `#E5EEFF`, 모서리 반경 `20~24dp`, 내부 패딩 `20dp`.
  - 주요 CTA (`새 여행 만들기`): 최소 높이 `50~52dp`, 배경 `#A43E31`, 텍스트 `#FFFFFF`.
  - 보조 행동 (`다른 여행자의 일정 둘러보기`): 최소 높이 `48dp`, 텍스트 `#203247`.

### 2.2 진행 중·예정 여행이 있을 때 (컨시어지 홈)

- **퍼스트 폴드 컨시어지 카드 (`conciergeCard`)**:
  - 상단 요약(`#F1F4FA`), 현재/다음 일정 안내 박스(`#FFFFFF`), 하단 빠른 행동 버튼(`일정 열기`, `영수증 등록` 등 최소 높이 `48dp`)으로 구성합니다.
- **콤팩트 새 여행 시작 바 (`compactCreateBar`)**:
  - 진행 중인 여행이 있어도 언제든 새 여행을 추가할 수 있도록 `48dp` 이상 높이의 시작 버튼을 제공합니다.

### 2.3 공통 하단 섹션

- **공식 여행 가이드 캐러셀 (`courseSection`)**: 공식 여행 정보를 참고한 도시 카드를 제공합니다. 도시 안내 열람 또는 해당 도시를 선택한 여행 만들기로 연결합니다. 전체 코스 복사나 실제 방문 검증으로 표현하지 않습니다.
- **핵심 도구 그리드 (`toolsSection`)**: 여행 경비 기록과 준비물은 대상 여행 선택으로, 안전 안내는 실제 안내 열기로 연결합니다. 도구의 후속 저장 기능은 별도로 검수합니다.

페이지 기능과 타이틀·GNB 배정은 [페이지별 기능 정의서](<../../01. 서비스기획/01. 기능정의/앱기본구조_페이지별기능정의서.md>)에서 함께 검토합니다. 이 문서의 개별 카드 표현으로 공통 헤더·버튼 토큰을 덮어쓰지 않습니다.
