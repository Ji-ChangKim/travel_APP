# MY 닉네임·프로필 사진 변경 규격

## 목적과 적용 범위

Google 회원은 MY(`/my`)에서 앱에 표시할 닉네임과 사진을 선택한다. 로그인 직후에는 추가 입력 없이 기본 프로필로 시작한다. 사용자의 2026-11-09 지시에 따라 기존 MY 읽기 전용 정책 중 닉네임·사진만 변경을 허용한다. 소개·성별·생일·여행 스타일 입력은 추가하지 않는다.

기준은 [앱 기본 구조](앱기본구조_화면규격.md), [디자인 시스템](<../00. 공통규격/디자인시스템.md>), [디자인 토큰](<../00. 공통규격/design-tokens.json>), [헤더·GNB](<../00. 공통규격/헤더GNB_규격.md>)다. 기존 `MY` 헤더·설정 행동·하단 4탭을 유지한다. 프로필 카드 아래에 변경 행동을 배치하고 공통 버튼·입력창·ActionSheet를 사용한다. 공통 치수·색상·글꼴을 덮어쓰지 않는다.

## 닉네임

사용자는 ‘닉네임 변경’ → 이름 입력 → 중복 확인 → 저장 순서로 바꾼다. 저장 후 MY와 홈에 반영하며 화면 재진입·서버 재조회에도 같은 이름을 보여준다. 기존 공개 게시물 작성자와 참여 여행의 표시 이름도 갱신한다. 여행 내용은 변경하지 않는다.

| 항목      | 확정 기준                                                                                                   |
| --------- | ----------------------------------------------------------------------------------------------------------- |
| 허용 문자 | 영어, 숫자, 한글, 일본어 히라가나·가타카나. 일본어 장음 기호 `ー` 허용                                      |
| 길이      | NFC 정규화 후 문자 수 1~10자. 내부 공백도 포함                                                              |
| 공백      | ASCII 공백만 문자 사이에 총 2개까지. 앞뒤 공백·공백만 있는 이름·탭·줄바꿈 거부. 자동으로 잘라 저장하지 않음 |
| 중복      | 선택한 닉네임 전체에서 검사. NFC + 영어 소문자로 비교. 내부 공백은 보존                                     |
| 변경 간격 | 서버의 마지막 성공 저장 시각부터 30일, 정확히 2,592,000,000ms. 달력의 월 변경과 무관                        |
| 최초 저장 | 아직 선택하지 않은 회원은 즉시 저장 가능. 최초 성공 저장부터 30일 계산                                      |
| 같은 값   | 현재 닉네임과 완전히 같은 값은 변경으로 세지 않고 마지막 변경 시각을 유지                                   |
| 동시 저장 | 중복 확인은 예약이 아님. 실제 저장에서 고유 제약·30일 조건을 다시 검사                                      |
| 기본 표시 | 미설정 ‘여행자’는 공용 기본 표시이며 닉네임 예약이 아님. 직접 선택한 이름만 중복 검사 대상                  |

`A가나다`와 `a가나다`는 같은 이름이다. `a b c`와 `a  b`는 허용한다. ` asd`, `asd `, `asd`, `a b c d`, 한자·이모지·특수문자는 거부한다. `a b`와 `a  b`는 내부 공백 수가 달라 별개 이름이다.

30일이 지나기 전에는 변경 버튼을 잠그고 다음 변경 시각을 보여준다. 중복·잘못된 입력이면 입력을 보존하고 수정하도록 안내한다. 저장 응답을 확인하지 못하면 성공으로 표시하지 않고 현재 프로필을 다시 조회한다. 재조회 행동을 제공하며 실패한 요청 때문에 변경 기회를 차감하지 않는다.

## 사진

Google 회원은 앨범 선택 또는 촬영으로 사진을 언제든 바꾼다. 닉네임의 30일 제한은 사진에 적용하지 않는다. 취소하면 기존 사진을 유지한다. 권한 거부·변환·통신 실패에는 재시도를 안내한다.

앱은 긴 변을 최대 1,024px로 줄이고 실제 PNG로 변환한다. 서버는 PNG 형식·10MiB 상한을 검사하고 메타데이터를 제거한 뒤 저장한다. 확장자만 PNG로 바꾼 파일은 허용하지 않는다.

- R2 버킷: `tripprint-staging-private`, 바인딩 `MEDIA`.
- 객체 키: `User/profile/pfImg_{유저ID}.png`. 같은 회원은 같은 키를 덮어써 현재 객체 하나만 유지한다.
- 현재 객체가 사진 상태의 기준이다. 기존 호환 테이블 `profile_photos`에 새 파일 행을 만들지 않는다.
- 본인 인증 조회로만 사진을 제공하고 `no-store`를 적용한다. 파일 주소의 버전은 현재 객체 ETag다. 교체 후 예전 미리보기를 다시 쓰지 않는다.
- 회원 전환·로그아웃 뒤 늦게 도착한 응답과 사진은 새 회원 화면에 적용하지 않는다. 탈퇴 접수와 겹친 업로드·소유 계정이 없는 파일은 정리한다.

저장 후 바뀐 사진을 표시하고 재진입·새로고침 후에도 다시 조회한다. 미리보기 조회가 실패하면 다시 불러오기를 제공한다. 비공개 버킷 파일을 공개 URL로 노출하지 않는다. 공개 게시물에 회원 사진을 배포하는 기능은 이번 범위에 포함하지 않는다.

## 게스트와 로그인

게스트는 기본 프로필을 사용한다. 변경 기능 대신 Google 로그인 안내를 보여준다. 로그인 전 게스트 자료를 자동 전송하거나 서버 익명 계정을 만들지 않는다. 서버도 Google 회원 여부를 검사하므로 앱 버튼만 숨기는 것으로 권한 검사를 대신하지 않는다.
