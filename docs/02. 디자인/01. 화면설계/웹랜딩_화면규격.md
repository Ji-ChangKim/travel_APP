# 웹 랜딩 화면 규격

## 목적과 적용 범위

랜딩 `/`은 TripPrint가 지향하는 여행 계획과 기록 경험을 소개한다. 홈 `/home`은 로그인한 회원이 여행을 관리하는 서비스 화면이다. 사용자의 최신 지시에 따라 두 역할을 나눈다. 이번 구현은 랜딩과 웹 공통 모듈까지이며, 홈은 [웹 홈페이지 화면 계획](웹홈페이지_화면계획.md)에서 설계한다. 홈·로그인·개인 여행 API를 구현한 것처럼 안내하지 않는다.

기준은 [디자인 시스템](<../00. 공통규격/디자인시스템.md>), [단일 토큰](<../00. 공통규격/design-tokens.json>), [헤더·GNB](<../00. 공통규격/헤더GNB_규격.md>)다. 기존 TripPrint 로고·하루 캐릭터·앱 헤더·GNB는 변경하지 않는다. 랜딩 전용 `SiteHeader`는 소개 구간으로 이동하고 `SiteFooter`는 소개·사진 출처를 제공한다. 서비스 홈의 `HomeHeader`와 GNB를 대체하지 않는다.

## 화면과 실제 행동

| 순서 | 영역              | 읽는 내용·행동                                                                                              |
| ---- | ----------------- | ----------------------------------------------------------------------------------------------------------- |
| 1    | SiteHeader        | 기존 로고, 여행의 흐름·기록 방식으로 구간 이동, 좁은 화면의 메뉴 열기·닫기                                  |
| 2    | 첫 장면           | ‘떠나는 순간부터, 다시 꺼내 볼 이야기까지.’, 여행 사진을 펼친 구성, ‘여행 이야기 살펴보기’로 다음 구간 이동 |
| 3    | 여행의 흐름       | 떠나기 전·여행하는 동안·돌아온 뒤의 세 버튼으로 설명과 시각 예시 전환                                       |
| 4    | 기록 방식         | 사진·장소·영수증 품목을 실제 방문과 연결하는 방향 설명. 인증·본인 방문·원본 진위를 보장한다고 표현하지 않음 |
| 5    | 마무리·SiteFooter | 첫 구간으로 돌아가기, 사진 저작자·원본·라이선스 열람                                                        |

예시는 ‘여행 기록의 예시’로 표시한다. 실제 사용자 게시물·서비스 화면·저장 성공으로 제시하지 않는다. 준비되지 않은 가입·여행 생성·홈·정책 링크는 노출하지 않는다. 웹 게스트 계정·저장 기능은 없다.

## 시각 규격과 모듈

색상·글꼴·본문·버튼·반경은 공통 토큰을 CSS 변수로 변환한다. 웹 어댑터는 `apps/web/src/shared/design-system`에 두며 토큰 원본을 복사하지 않는다. 본문 16/26, 보조 14/22, 제목은 모바일 32/42·넓은 화면 40/52를 따른다. 콘텐츠 최대 폭 1200, 모바일 패딩 20, 넓은 화면 패딩 40, 터치 영역 48 이상이다. 히어로 사진은 4:5와 4:3, 기록 사진은 4:3 비율로 공간을 먼저 확보한다. 장식 사진은 글을 가리지 않는다.

웹 공통 버튼·제목은 `components/ui`, 헤더·푸터는 `components/layout`, 움직임 처리는 `components/motion`에서 공급한다. 소개 문구·사진·세 장면의 데이터는 `features/landing/model`, 화면 조립은 `features/landing/ui`로 분리한다. 페이지는 이 화면을 연결하기만 한다. 공통 수학 함수는 실제 사용하는 스크롤 진행률 계산만 분리한다. 아직 쓰지 않는 업무 함수를 미리 만들지 않는다.

## 움직임과 접근성

첫 장면은 700ms 동안 제목·사진을 차례로 펼친다. 사진은 6초 주기의 작은 이동만 반복한다. 아래 구간은 보일 때 한 번 나타나고, 위쪽 진행선은 전체 읽은 위치를 표시한다. 세 장면 전환은 180ms, 이동 거리는 최대 24px이다. 이 값은 랜딩 전용이며 기존 GNB 애니메이션에 적용하지 않는다.

움직임 일시정지 버튼을 제공한다. 운영체제의 움직임 줄이기를 켰다면 반복·스크롤 연출을 제거하고 내용을 완성된 정적 구도로 표시한다. 다른 탭으로 옮기거나 해당 장면이 화면 밖이면 반복을 멈춘다. 키보드 초점이 들어간 장면도 정지한다. JavaScript를 실행하지 않아도 모든 설명·사진·구간 링크는 읽을 수 있다. 작은 화면에서는 사진 겹침을 줄이고 세 장면 버튼은 줄바꿈한다. 스크롤을 강제로 붙잡지 않는다.

## 검수 기준

360·390·430·1024·1440px, 320 CSS px·큰 글자에서 가로 넘침·제목 잘림·버튼 겹침이 없어야 한다. 메뉴·구간 링크·예시 전환·일시정지를 실제로 조작하고 키보드·Escape·초점 복귀를 확인한다. 움직임 줄이기·JavaScript 미실행·사진 로딩·홈 404·없는 링크 부재를 검사한다. 실제 캡처와 자동 검사 결과는 작업 보고에 따로 기록한다.
