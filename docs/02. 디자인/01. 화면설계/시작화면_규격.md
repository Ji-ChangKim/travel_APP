# 시작 화면 (스플래시·웰컴) 규격

- **적용 경로**: `apps/mobile/src/app/index.tsx` (`/` 시작 연출), `apps/mobile/src/app/welcome.tsx` (`/welcome`)
- **공통 기준**: [디자인 시스템](<../00. 공통규격/디자인시스템.md>), [design-tokens.json](<../00. 공통규격/design-tokens.json>)

---

## 1. 화면 목적 및 진입 조건

- 앱 최초 실행 시 서비스 버전 정책을 확인하고, 비로그인 사용자에게 브랜드 소개와 함께 **게스트 둘러보기** 또는 **로그인하기** 진입점을 제공합니다.
- `/welcome` 경로는 [헤더·GNB 규격](<../00. 공통규격/헤더GNB_규격.md>)에 따라 상단 헤더와 하단 GNB를 모두 생략합니다.

---

## 2. 레이아웃 및 구성요소

1. **브랜드 및 히어로 영역**:
   - 중앙 정렬 컨테이너(최대 폭 `640px`, 좌우 패딩 `20px`).
   - TripPrint 브랜드 로고·하루 일러스트와 서비스 핵심 안내 문구를 표시합니다.
   - 시작 모션은 접근성 동작 줄이기(`reduceMotion`)가 켜져 있거나 화면 읽기 사용 시 즉시 최종 상태로 전환합니다.
2. **하단 행동 버튼 영역**:
   - **주요 CTA (`로그인하고 시작하기`)**: 높이 `52dp`, 배경 `#B84A39`, 전경 `#FFFFFF`, 모서리 반경 `12dp`. 터치 시 `/login`으로 이동합니다.
   - **보조 행동 (`먼저 둘러보기`)**: 최소 높이 `48dp`, 배경 `#FFFFFF`, 테두리 `#8A7B70`, 전경 `#203247`. 터치 시 게스트 모드로 홈(`/`)에 진입합니다.

## 3. 승인한 무음 BI 영상

앱을 새로 열면 위치 핀 주위를 비행기 한 대가 도는 영상을 보여줍니다. 영상이 끝나고 실제 시작 점검을 통과하면 비로그인 사용자는 로그인 선택 화면으로, 로그인한 사용자는 기존 세션의 목적지로 이동합니다. 인증 복귀나 직접 링크에서는 시작 영상을 다시 재생하지 않습니다.

- **영상**: `apps/mobile/assets/brand/tripprint-v1/tripprint_bi.mp4`. 승인 원본과 같은 1920×1080, 30fps, 4초 H.264 파일을 앱에 포함합니다. 원격 다운로드 없이 한 번만 재생합니다.
- **소리**: 파일에 오디오 트랙이 없습니다. 플레이어도 첫 재생 전부터 음소거하고 음량을 0으로 설정합니다. 재생 버튼·전체 화면·화면 속 작은 재생 창은 표시하지 않습니다.
- **배치**: 화면 중앙에서 원본 비율을 유지하는 `contain` 방식으로 보여줍니다. 자르거나 늘리지 않습니다. 작은 화면·가로 화면·태블릿에서도 전체 심볼이 보이게 합니다.
- **배경**: 승인 영상의 흰 바탕에 맞춰 `startup.bi.backgroundTop`과 `startup.bi.backgroundBottom`을 모두 `#FFFFFF`로 사용합니다. 적용 범위는 OS 스플래시, BI, 로그인 선택 화면으로 이어지는 시작 전환 배경입니다. 로그인 선택 화면의 최종 배치, 홈, 헤더·하단 GNB와 설치 아이콘은 바꾸지 않습니다.
- **정지 이미지**: `tripprint_bi_poster.png`는 같은 구도의 승인 정지형입니다. 영상의 첫 프레임을 기다릴 때와 재생 실패 때 같은 비율·위치에 표시합니다. 영상이 끝나도 실제 시작 점검을 기다리는 동안에는 정지 심볼을 유지합니다.
- **움직임 제한**: 동작 줄이기나 화면 읽기가 켜져 있으면 영상을 불러오지 않고 정지 이미지로 이어갑니다. 앱이 뒤로 가면 재생과 표시 시간을 멈추고 돌아왔을 때 남은 구간을 이어갑니다.
- **실패 복구**: 첫 프레임을 전경에서 500ms 안에 표시하지 못하거나 디코딩·길이 검증에 실패하면 정지 이미지를 표시합니다. 정상 길이는 1~4초이며 종료 이벤트가 누락되면 첫 프레임 뒤 전경 4.5초에서 복구합니다. 정지 이미지가 준비된 뒤 1초를 표시하고 다음 화면으로 이어갑니다. 시작 점검 오류는 기존 재시도 안내로 처리합니다.

영상 적용은 사용자가 승인한 모션과 무음 재생에 한정합니다. 기존 공통 디자인 규격은 그대로 따릅니다.
