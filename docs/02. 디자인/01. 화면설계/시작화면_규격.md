# 간단 시작 화면 규격

확정일: 2026-10-27. 사용자가 보낸 심플한 첫 화면 시안과 앱 심볼·영문 로고를 기준으로 한다.

## 화면의 역할

앱을 처음 열면 브랜드를 보고 시작 방법을 고른다. Google로 로그인하거나, 게스트로 둘러보고 계획을 입력한다. 계획 저장에 필요한 회원 로그인 정책은 그대로 유지한다.

이번 요청의 ‘홈’은 로그인 전 첫 화면인 `/welcome`에 적용한다. 이미 로그인한 회원은 기존 홈으로 들어간다. 앱 안의 여행 목록 홈과 저장·초대에서 여는 `/login`은 유지한다.

## 화면 구성

| 순서 | 내용                                                | 배치와 규격                                                                |
| ---- | --------------------------------------------------- | -------------------------------------------------------------------------- |
| 1    | 사용자 제공 앱 심볼                                 | 너비 132, 원본 337:216 비율 유지, 자르지 않음                              |
| 2    | 나만의 여행 기록                                    | 가운데 정렬, LINE Seed Bold, 공통 labelMedium 14/22                        |
| 3    | 사용자 제공 TripPrint 영문 로고                     | 너비 200, 원본 450:106 비율 유지, 자르지 않음                              |
| 4    | 여행의 순간을 간직하고 / 나만의 발자취를 남겨보세요 | 가운데 정렬, 공통 bodySmall 14/22, 언어·글자 크기에 따라 자연스럽게 줄바꿈 |
| 5    | Google로 계속하기                                   | 공통 흰색 버튼, 공식 Google G 아이콘, 실제 이용 가능 여부 확인             |
| 6    | 게스트로 시작하기                                   | 공통 코럴 기본 버튼, 기존 게스트 기록이 있으면 그대로 이어서 시작          |
| 7    | 계획을 저장할 때 로그인할 수 있어요.                | 시작 후 로그인하는 시점을 쉬운 말로 안내                                   |

본문 최대 너비 440, 좌우 여백 20, 상하 여백 48, 브랜드 내부 간격 16, 브랜드와 버튼 묶음 간격 40, 버튼 사이 간격 12다. 화면이 충분히 크면 가운데에 놓고, 작은 화면·큰 글꼴에서는 아래로 스크롤한다. 기기 안전 영역을 보존한다. 버튼은 공통 DesignButton의 최소 48 터치 영역과 글자 확대를 따른다.

배경은 현행 `#F8F9FF`, 글꼴은 한·영·일 LINE Seed를 사용한다. 버튼·본문의 색상과 글자 크기는 공통 토큰을 참조한다. 시안의 작은 안내 글자와 흰색 CTA 글자는 그대로 복제하지 않고, 공통 14/22 안내 문구와 대비를 확보한 네이비 CTA 글자를 유지한다. 로고 색과 모양은 원본 그대로다.

## 시작과 이동

| 상태 또는 행동            | 결과                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------- |
| 첫 실행, 로그인 정보 없음 | 시작 점검 후 `/welcome` 표시. 버튼 선택 전 게스트를 만들지 않음                       |
| 기존 게스트로 앱 재실행   | `/welcome`에서 선택. 게스트 시작을 누르면 기존 계정과 기록을 이어감                   |
| 로그인한 회원으로 재실행  | 기존 홈 또는 보존된 초대·공유 목적지로 이동. 회원가입 미완료는 프로필 설정으로 이동   |
| Google 선택               | 실제 인증 화면을 열고 완료 후 기존 복귀 규칙 적용. 취소·실패를 성공으로 처리하지 않음 |
| 게스트 선택               | 저장된 계정 복원 또는 실제 게스트 발급 후 기존 완료 목적지로 이동                     |
| 초대·장소 공유가 대기 중  | 기존 목적지 복구 규칙 유지. 무조건 홈으로 덮어쓰지 않음                               |
| 계획 저장에서 로그인 필요 | 기존 `/login`에서 이메일·Google 로그인 후 작성하던 곳으로 복귀                        |

## 기다림과 오류

인증 복원 중에는 버튼을 잠근다. Google 이용 여부를 확인하는 동안 Google 버튼은 로딩 표시를 하며, 게스트 버튼은 별도로 사용할 수 있다. 요청 중 연속 누르기는 잠근다.

Google을 쓸 수 없거나 조회에 실패하면 Google 버튼을 비활성화하고 다시 확인할 수 있게 한다. 안내는 ‘Google 로그인을 지금 이용할 수 없어요. 다시 확인하거나 게스트로 시작해 주세요.’다. 서버 설정·API·인증 공급자 같은 개발 설명은 보여주지 않는다.

게스트 발급이나 로그인 시작에 실패하면 오류 안내와 재시도할 버튼을 남긴다. 이때 ‘다른 방법으로 로그인’으로 기존 로그인 화면에 갈 수 있다. 실패를 가짜 계정으로 대체하지 않는다. 일반 상태에는 로고와 두 시작 버튼, 안내만 표시한다.

## 참조와 확인 기준

- [디자인 시스템](<../00. 공통규격/디자인시스템.md>), [공통 토큰](<../00. 공통규격/design-tokens.json>), [헤더·GNB 규격](<../00. 공통규격/헤더GNB_규격.md>)을 따른다. 헤더 생략 예외는 이 첫 화면에만 적용한다.
- [리소스 저장 경로](<../02. 리소스/리소스_저장경로.md>)의 사용자 제공 PNG를 사용한다. 이미지 생성이나 임의 리터칭은 하지 않는다. 설치용 아이콘 교체는 이번 범위에 포함하지 않는다.
- 실제 앱의 웹 실행에서 320·390·430 너비, 글자 200%, 로고 로드, 한·영·일 문구, 정상·조회 실패·요청 실패·재시도·게스트 기록 보존을 확인한다. 테스트 응답과 실제 Google 계정 인증은 구분한다.
- 실제 기기에서는 안전 영역, 시스템 글자 확대, Google 앱 전환과 복귀, 네트워크 끊김 후 재시도를 따로 확인한다. 웹 검사 통과만으로 완료했다고 기록하지 않는다.
