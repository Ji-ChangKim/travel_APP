# 발자국 목록(공개 여행 피드) 화면 규격

- **적용 경로**: `apps/mobile/src/app/(tabs)/footprints.tsx` (`/footprints`, 커뮤니티 탭)
- **스타일 소스**: `apps/mobile/src/features/workspace/community/styles/publicFeedStyles.ts` (`@/constants/theme` 연동)
- **공통 기준**: [디자인 시스템](<../00. 공통규격/디자인시스템.md>), [헤더·GNB 규격](<../00. 공통규격/헤더GNB_규격.md>)

---

## 1. 상단 헤더 및 하단 GNB

- **상단 헤더**: `/footprints`와 `/community` 모두 공통 `ScreenHeader`에 `커뮤니티`를 표시합니다. 루트 화면이므로 뒤로가기와 우측 행동을 두지 않습니다. 공유 진입은 본문에 있습니다.
- **하단 GNB**: 4탭 `GlobalNavigation` 표시 (`커뮤니티` 탭 활성).

두 경로의 기능과 제목 기준은 [페이지별 기능 정의서](<../../01. 서비스기획/01. 기능정의/앱기본구조_페이지별기능정의서.md>)를 따릅니다. 사용자의 구현 지시에 따라 커뮤니티 브랜드 헤더 예외를 해제하고 공통 치수·글꼴·색상은 유지합니다.

앱에서 사용하는 탭 이름은 ‘커뮤니티’다. 본문 첫 부분에는 공개된 계획·기록을 읽는 목적만 표시하고 상단과 같은 대표 제목을 중복 배치하지 않는다. 검색·기간 조건, 빈 결과·오류 재시도, 공개 상세와 목록 복귀는 [앱 기본 구조 화면 규격](앱기본구조_화면규격.md)을 따른다. 공통 GNB의 개수·선택 표시·모션은 변경하지 않는다.

## 2. 검색·필터 및 피드 카드 규격

1. **검색 및 지역·기간 필터**:
   - 두 경로 모두 본문 소개 → 검색 영역 → 조건 칩·시트 → 공유 진입 → 조회 상태·카드 순서로 배치합니다. 검색·유형·기간 조건과 공개 상세 복귀를 같은 방식으로 제공합니다.
   - 검색 입력창(`searchRow`): 최소 높이 `56dp`, 배경 `#FFFFFF`, 외곽선 `#8A7B70`(`colors.borderStrong`), 모서리 반경 `12dp`.
   - 필터 칩(`chip`): 최소 높이 `48dp`, 선택 시 배경 `#A43E31`(`colors.actionPressed`), 글자 `#FFFFFF`.
2. **공개 여행 포스트 카드 (`post`)**:
   - 카드 배경 `#FFFFFF`, 테두리 `#E2E8F0`, 모서리 반경 `16dp`.
   - 표지 영역(`cover`, 최소 높이 `208dp`): 좌상단 지역 배지(`rgba(32, 50, 71, 0.78)` 배경 + `#FFFFFF` 텍스트)를 표시하며, 사진이 없거나 로드 실패 시 대체 안내 영역(`noPhoto`)과 인라인 지역 배지(`locationInline`)로 자동 전환합니다.
   - 본문 영역(`body`, 패딩 `16dp`): 지역·기간 배지(`#E5EEFF`, `#FFF0EB`), 여행 제목(`18px`, 행간 `26px`, 굵기 `700`), 작성자 프로필 및 하단 액션 버튼(`내 여행으로 담기`, `신고/차단`, 최소 높이 `48dp`)을 배치합니다.
