2026-10-21 실제 조건 검수: 서버 기간 계약은1~3일·4일·5일 이상이다. 코드4를3~5일로 안내하지 않는다. 적용된 공개 유형이 없을 때는‘유형 전체’를 표시하며, 시안의 예시 동행값‘친구와’를 선택값으로 표시하지 않는다. 월별 조건은 지원하지 않으므로‘10월’ 대신 실제 검색·기간·공개 유형 시트를 여는‘전체 조건’ 행동을 표시한다. 네 캡슐의 배치·글꼴·색·터치 영역과 공통 헤더·GNB는 유지한다. 이 보완을 아래10월21일 시안의 예시 문구보다 우선한다.

## 2026-10-21 공통 헤더 소유 정리

화면 모양은 유지한다. `PublicFootprintsScreen`은 임의 헤더 JSX 대신 `headerVariant: 'public-brand'`를 선택하며, 공통 `components/HomeHeader`가 기존 브랜드·계정 행동·바탕·하단 구분선을 표시한다. 페이지의 `publicFeedStyles.header`는 제거한다. 아래 과거의 ‘화면에서 헤더 전달·별개 관리’ 설명보다 이 공통 소유 규칙을 우선한다. 카드·필터·공개 데이터 동작은 변경하지 않는다.

## 2026-10-21 HTML 시안 갱신 (헤더·GNB 제외 반영)

사용자가 제공한 최신 발자국 HTML 시안을 기반으로 스크롤 콘텐츠 영역을 갱신했다. 사용자의 명시적 지시에 따라 상단 헤더(타이틀 영역)와 하단 GNB(하단 메뉴)는 기존 공통 규격을 유지하고 이번 반영에서 제외했다.

1. **필터 칩 (4종)**: 완전 캡슐형(`borderRadius: 9999`)으로 갱신. 첫 번째 칩(선택 상태)은 테라코타 레드(`#B3261E`) 배경에 흰색 글자·화살표를 적용하고, 비선택 칩은 흰색 배경과 외곽선(`rgba(198, 198, 205, 0.4)`), 다크 그레이 화살표(`#45464D`)를 적용한다. `여행지 전체`, `3~5일`, `친구와`, `10월` 4종으로 구성하며 탭 시 기존 조건 선택 시트와 연동한다.
2. **다녀온 여정 공유 배너**: 연한 블루(`surface-container-low`, `#EFF4FF`) 배경, 라운드 12px, 테두리 1px, 좌측 `add-location-alt` 아이콘(`#B3261E`, 20px) + "다녀온 여정이 있다면?"(13px medium), 우측 "내 발자국 공유하기"(13px semibold) + `chevron-forward` 링크를 배치한다.
3. **피드 카드 및 표지**: 표지 높이 208px를 유지하며, 표지 이미지 위에 비네팅 오버레이(`rgba(0, 0, 0, 0.15)`)와 좌측 상단 반투명 캡슐 핀 뱃지(`bg-black/50`, 살구빛 핀 `#FFB4A3` 14px + 흰색 지역명 11px)를 적용한다.
4. **메타데이터 뱃지 (4종)**: 라운드 6px, 11px 규격으로 지역(`#DCE9FF`), 기간(`#FFDAD6` 배경 + `#B3261E` 텍스트), 동행/유형(`#E5EEFF`), 시기(`#E5EEFF`) 4개 뱃지를 1:1로 일치시켜 배치한다.
5. **푸터 액션 레이아웃**: 상단 구분선(`border-top`) 아래 좌측에 28px 원형 아바타와 작성자명(13px semibold)을 두고, 우측에 일정 담기(저장, 북마크 아이콘), `동선 보기` 링크(`#B3261E`), 안전 행동(신고/차단) 더보기 아이콘을 통합 배치한다.

## 2026-10-20 일정 담기 추가

공개 카드와 단건 상세에서 ‘일정 담기’를 제공한다. 원본 보기는 유지하고 저장·인기 수치는 새로 만들지 않는다. 공통 하단 시트에서 실제 공개 제목·복사 범위·선택 출발일·자동 도착일·선택 여행 이름을 확인한다. 확정 버튼은 ‘담고 일정 수정하기’다. 회원은 DB의 본인 소유 여행으로, 기기 게스트는 해당 기기 여행 문서로 저장한다. 로그인 전에는 해당 공개 상세로 돌아올 수 있는 인증 경로를 사용한다.

공개된 DAY 소개·장소·시간·주소·공개 설명·구글 장소 연결만 독립 ID로 복사한다. 원본 사진·항공권 상세·실제 지출·영수증·개인 메모·동행자·초대·공개 상태를 복사하지 않는다. 날짜는 원래 DAY 간격을 유지해 선택 출발일로 옮긴다. 저장 중 입력·닫기·중복 확정을 잠그고 응답 유실은 같은 키로 재확인한다. 공개 중단·차단·유효하지 않은 기간은 저장하지 않는다. 이 추가 지시는 이전 ‘저장 기능 미지원’ 설명보다 우선한다.

## 2026-10-20 사용자 추가 지시

발자국 상단의 독립 검색창·검색 실행·조건 아이콘 행은 삭제한다. 기간·유형 등의 가로 조건 칩과 공유 안내는 유지한다. 검색 입력은 조건 칩에서 여는 선택 시트에 둔다. 이 변경은 `/footprints`에만 적용하며 기존 `/community`의 검색창은 유지한다.

GNB는 로그인 여부와 관계없이 홈·내 여행·여행 만들기·발자국·MY 다섯 메뉴를 같은 순서로 표시한다. 로그인 전에도 메뉴를 숨기지 않으며, 개인 화면은 기존 인증·온보딩 규칙으로 보호한다. 상세·작성·인증 화면에서 GNB를 숨기는 기존 규칙과 안전 영역 처리는 유지한다. 이 추가 지시는 아래의 검색창 배치와 계정별 메뉴 설명보다 우선한다.

## 2026-10-20 HTML 시안 적용

사용자가 새로 제공한 `sources/footprints-20261020/footprints_reference.html`을 이 화면의 최신 시각 기준으로 삼는다. 기존 아래의 화면 제목 규칙 대신 공식 TripPrint 브랜드 상단바(최소56)와 계정 이동을 사용하고, ‘발자국 공개 일정’이라는 접근성 이름을 목록에 제공한다. 다른 화면의 헤더는 바꾸지 않는다. `PublicFootprintsScreen`이 헤더를 전달하며 기존 `/community`의 공통 헤더와 별개로 관리한다.

바탕은 #F8F9FF, 카드 흰색·반경16·표지208·본문 안쪽16·요소 간격12, 화면 좌우20·카드 간격16이다. 제목은18/26·굵기700, 본문16/24, 배지·보조 문구14/20을 사용한다. 시안의11~13 글자와36 이하 버튼은 기존 읽기·48 터치 규격에 맞춰 확대한다. 글꼴은 기존 Pretendard와 공식 로고를 유지한다.

검색 입력·검색 실행·조건 버튼을 한 줄에 두고, 실제 서버가 지원하는 검색·기간·공개 유형을 가로 칩과 하단 시트로 연결한다. 시안의 검색 입력 누락은 정상 입력으로 보완한다. ‘3~5일’ 임의 범위 대신 현재 계약인1~3일·4일·5일 이상을 사용한다. 동행 유형은 공개 자료에 없어 표시·필터를 만들지 않는다. 여행 월은 실제 시작일에서 카드 배지로 표시하며 월 필터를 작동하는 것처럼 만들지 않는다.

표지는 실제 공개 사진을 사용한다. 시안의 사진 전체 검정 그라데이션 대신 위치 배지의 불투명 #213145 바탕으로 글자 대비를 확보하고 표지 원색을 유지한다. 나라·도시, 전체 기간으로 계산한 박·일, 공개 종류, 시작 연월을 배지로 표시한다. 계획은 ‘계획’, 기록은 ‘여행’으로 구분한다. 작성자 사진은 현재 공개 계약에 없으므로 인물 아이콘을 사용한다. ‘동선 보기’는 기존 공개 일정 상세로 이동하며 자동 경로 계산을 뜻하지 않는다. 신고·차단은 더보기 시트에서 실행하고 기존 확인·오류 처리를 유지한다.

‘내 발자국 공유하기’는 내 여행 목록으로 이동해 기존 공개 선택을 이어간다. 비회원은 로그인 후 같은 목록으로 돌아온다. 알림 센터·읽지 않은 알림 수·저장 기능·시안의 가상 여행과 인물 사진은 추가하지 않는다. 하단 메뉴는 기존 공통 규격을 재사용한다.

적용일: 2026-10-20. 사용자 지시에 따라 하단 ‘발자국’ 전체를 공개 일정 목록으로 변경한다. 이전 개인 보관함 설명보다 이 문서를 우선한다.

- `/footprints`는 공개된 여행계획·여행기록을 보여준다. 검색, 유형·기간 필터, 다음 페이지, 상세 조회, 신고·차단은 기존 공개 목록 기능을 공유한다.
- 홈의 ‘더보기’와 공개 일정 둘러보기는 `/footprints`로 이동한다. 두 화면은 같은 공개 게시물을 조회하며 별도 샘플 데이터를 만들지 않는다.
- 기존 `/community` 주소도 같은 공개 목록을 제공한다. 게시물 직접 주소 `/community/{postId}`를 유지한다.
- 기존 개인 보관함은 `/my-footprints`에서 제공한다. 내 여행의 ‘나의 여행 기록 보기’와 개인 다이어리의 돌아가기에서 연결한다. 개인 기록·완료 상태·DB 원본은 변경하지 않는다.
- 이전 텍스트 제목 규칙은 이번 HTML의 브랜드 상단바로 대체한다. 개인 보관함과 다른 화면의 제목 규격은 유지한다.
- 작은 화면·큰 글꼴·긴 제목·조회 오류와 재시도를 실제 앱 렌더링으로 확인한다. 로그인 전에도 공개 조회를 허용하고 비공개 원본을 대신 표시하지 않는다.
