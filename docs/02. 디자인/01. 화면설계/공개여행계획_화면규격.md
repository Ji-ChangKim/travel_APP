# 공개 여행계획 상세 화면 규격

- **적용 경로**: `apps/mobile/app/community/[postId].tsx` (`/community/[postId]`)
- **스타일 소스**: `apps/mobile/src/features/workspace/schedule/styles/timelinePlanStyles.ts` (`@/constants/theme` 연동)
- **공통 기준**: [디자인 시스템](<../00. 공통규격/디자인시스템.md>), [헤더·GNB 규격](<../00. 공통규격/헤더GNB_규격.md>)

---

## 1. 상단 헤더 및 노출 정책

- **상단 헤더**: `ScreenHeader` (좌측 뒤로가기 버튼 `/footprints` 복귀, 제목 `공개 여행계획`, 우측 신고·차단 더보기 액션).
- **하단 GNB**: 숨김 처리하며, 대신 하단 실행 바(`publicExecutionBar` / `bottomExecutionBar`)에 `내 여행으로 담기` 주요 CTA 버튼(최소 높이 `48dp`, 배경 `#A43E31`, 전경 `#FFFFFF`)을 고정 배치합니다.

---

## 2. 상세 화면 구성 및 개인정보 보호

1. **상단 요약 배너 (`banner`)**:
   - 배경 `#F1F4FA`(`colors.surfaceMuted`), 패딩 `20dp`.
   - 여행 지역·기간 배지(`#FFF0EB`), 여행 제목(`22px`, 행간 `30px`, 굵기 `700`, `#203247`), 작성자 닉네임과 공개된 통화별 총액 요약을 표시합니다.
2. **일차별 타임라인 열람**:
   - `DAY 1 ~ DAY N` 탭을 전환하며 작성자가 공개 허용한 방문 장소, 시간, 이동 경로, 공개 사진을 읽기 전용으로 표시합니다.
   - 작성자의 비공개 메모, 원본 영수증 이미지, 세부 품목 내역, 동행자 정보는 화면과 응답 데이터 어디에도 노출하지 않습니다.
3. **내 여행으로 담기**:
   - 하단 `내 여행으로 담기` 터치 시 새 여행 시작일을 선택하는 모달을 띄우고, 장소·일정 구조만 복제한 새 여행을 생성합니다.
