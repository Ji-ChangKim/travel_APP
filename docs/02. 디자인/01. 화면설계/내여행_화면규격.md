# 내 여행 화면 규격

- **적용 경로**: `apps/mobile/app/(tabs)/trips.tsx` (`/trips`)
- **스타일 소스**: `apps/mobile/src/features/workspace/my-trips/styles/myTripsStyles.ts` (`@/constants/theme` 연동)
- **공통 기준**: [디자인 시스템](<../00. 공통규격/디자인시스템.md>), [헤더·GNB 규격](<../00. 공통규격/헤더GNB_규격.md>)

---

## 1. 상단 헤더 및 하단 GNB

- **상단 헤더**: `ScreenHeader` (제목 `내 여행`, 우측 `새 여행` 추가 액션).
- **하단 GNB**: 4탭 `GlobalNavigation` 표시 (`내 여행` 탭 활성).

---

## 2. 화면 레이아웃 및 카드 규격

1. **상태 필터 칩 및 검색 바**:
   - 전체 / 여행 중 / 예정 / 완료 필터 칩(`Chip`)과 여행 제목·목적지 검색 입력창(`Input`)을 상단에 배치합니다.
   - 선택된 칩은 배경 `#A43E31`(`colors.actionPressed`), 글자 `#FFFFFF`(`colors.textLight`)를 적용합니다.
2. **여행 카드 (`MyTripCard`)**:
   - 카드 표면 `#FFFFFF`, 모서리 반경 `16dp`, 본문 패딩 `16dp`.
   - 상단 표지 영역(최소 높이 `176dp`, 완료 여행 `144dp`)에 여행 상태 배지와 제목·기간을 표시하며, 사진 유무와 무관하게 텍스트 명도 대비 4.5:1 이상을 보장합니다.
   - 하단 행동 버튼(`일정 보기`, `영수증 등록`, `공유 설정` 등)은 모두 최소 높이 `48dp` 이상을 유지합니다.
3. **빈 상태 (`empty`)**:
   - 아직 생성한 여행이 없을 때 중앙 안내 일러스트와 함께 `새 여행 만들기` 카드를 표시합니다.
