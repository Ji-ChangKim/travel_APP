# 로그인 및 프로필 생성 화면 규격

- **적용 경로**: `apps/mobile/app/login.tsx`, `apps/mobile/app/profile-setup.tsx`, `apps/mobile/app/terms.tsx`, `apps/mobile/app/privacy.tsx`
- **공통 기준**: [디자인 시스템](<../00. 공통규격/디자인시스템.md>), [헤더·GNB 규격](<../00. 공통규격/헤더GNB_규격.md>)

---

## 1. 로그인 화면 (`/login`)

1. **상단 헤더**: `ScreenHeader` (좌측 뒤로가기 버튼 + 제목 `로그인`, 하단 GNB 숨김).
2. **소셜 로그인 버튼**:
   - Google, 카카오, 네이버 로그인 버튼을 세로 간격 `12dp`로 배치합니다.
   - 모든 버튼은 최소 높이 `52dp`, 모서리 반경 `12dp`, 최소 터치 영역 `48×48dp`를 준수합니다.
3. **게스트 진입 및 복귀 보존**:
   - 이전 화면에서 전달된 복귀 경로(`returnTo`)와 작성 중이던 여행 초안(`CreationAuthHandoff`)을 유지하여 로그인 완료 후 원래 흐름으로 연결합니다.

---

## 2. 프로필 생성 및 약관 동의 (`/profile-setup`)

1. **진입 조건**: 소셜 인증을 마쳤으나 필수 약관 동의 또는 프로필 설정(`onboarding_completed_at`)이 완료되지 않은 회원에게 표시합니다.
2. **입력 항목**:
   - **닉네임 (필수)**: 앞뒤 공백 제거와 NFC 정규화 후 한글 완성형·영문·숫자 2~10자를 허용합니다. 글자 수는 유니코드 코드 포인트로 셉니다. 표시 닉네임은 중복을 허용하며 중복 확인 API를 호출하지 않습니다. 입력창 외곽선은 `#8A7B70`, 포커스 시 `#203247`을 적용합니다.
   - **한 줄 소개 및 여행 스타일 (선택)**: 칩(`Chip`) 컴포넌트로 다중 선택을 지원합니다(선택 시 배경 `#FFF0EB`, 테두리 `#B84A39`, 텍스트 `#203247`).
   - **약관 동의**: 서비스 이용약관(`/terms`) 및 개인정보 처리방침(`/privacy`) 상세 보기 링크와 필수 동의 체크박스를 제공합니다.
3. **완료 행동**:
   - 필수 항목 충족 시 하단 `시작하기` 버튼(`52dp`, `#B84A39`)이 활성화되며, 저장 완료 후 복귀 경로(`returnTo`) 또는 홈(`/`)으로 이동합니다.

## 3. 닉네임 입력과 편집

- 입력 중인 자음·모음과 초과 문자열을 강제로 자르거나 삭제하지 않습니다. 한글 조합 중에는 오류를 확정해 표시하지 않습니다. 초점을 옮기거나 저장할 때 길이와 허용 문자를 검사합니다.
- 길이 오류는 `닉네임은 2~10자로 입력해 주세요.`, 문자 오류는 `한글, 영문, 숫자만 사용할 수 있어요.`로 안내합니다. 저장이 거부돼도 입력을 유지하며 다시 입력하면 이전 제출 오류를 지웁니다.
- 기존 닉네임을 정확히 그대로 유지하는 프로필 편집에는 새 제한을 소급하지 않습니다. 이름을 변경하면 현재 제한을 적용합니다. 이 예외는 최초 프로필 설정에 적용하지 않습니다.
- 입력 글꼴은 공통 `DesignInput`의 LINE Seed 계열, 기본 16px·행간 24px을 사용합니다. 글꼴 로딩 실패 시 시스템 글꼴로 입력을 계속할 수 있어야 합니다.
- 웹에서 한글 조합을 취소하는 Escape는 프로필 창을 닫지 않습니다. 조합이 끝난 뒤 별도로 누른 Escape에는 기존 닫기·이탈 확인을 적용합니다.

소개글 상한과 기존 장문 소개의 편집 규칙은 앱·서버가 아직 일치하지 않습니다. 현재 앱 80자·서버 300자이며, 확정 전에는 어느 값을 공통 정책이라고 안내하지 않습니다.
