# 로그인과 최초 프로필 생성

적용일: 2026-11-04 / 상태: 사용자 지시에 따라 구현·검수 중

## 기준과 적용 범위

사용자가 지정한 [BI/CI](https://app.notion.com/p/40ec5197732081488084d9b92f9fa713), [로그인](https://app.notion.com/p/40ec5197732081cea19dd9977db7d252), [프로필 생성](https://app.notion.com/p/40ec51977320816eaf0fcf440835c73e)을 기능 기준으로 적용한다. 문서의 검토대기 표기와 별개로 이번 사용자 지시가 구현 근거다.

사용자가 이미 승인한 BI/CI → 로그인 연출은 유지한다. 따라서 노션의 ‘최소 노출 시간 없음’은 이번 변경에 적용하지 않는다. BI 중앙 배경·심벌과 기존 1초 정적 구간, 640ms 로고 이동, 버튼별 아래에서 위로 등장, 움직임 줄이기·전경 복귀 규칙은 [시작 화면 규격](시작화면_규격.md)을 따른다. Google 버튼도 기존 공식 규격을 유지한다.

공통 canvas·LINE Seed·좌우 여백 20·본문 최대 폭 640·버튼 최소 터치 영역·헤더·GNB는 [디자인 시스템](<../00. 공통규격/디자인시스템.md>)과 [헤더·GNB 규격](<../00. 공통규격/헤더GNB_규격.md>)을 따른다. `/profile-setup`의 제목은 ‘프로필 설정’이며 공통 `ScreenHeader`를 사용한다. 기존 회원의 성별·생일·소개 편집은 별도 프로필 편집에 남긴다.

## 시작과 로그인

시작 확인이 끝나면 세션 없음은 로그인, 미완료 회원은 프로필 설정, 완료 회원은 홈 또는 유효한 원래 목적 화면으로 이동한다. 통신 실패를 로그아웃 성공으로 바꾸지 않는다. 10초 안에 확인하지 못하면 자동 이동을 멈추고 재시도·로그인·게스트 선택을 제공한다. 손상된 기기 기록·확인된 필수 업데이트는 별도 복구 경로를 유지한다. 재시도는 이전 요청을 취소한 뒤 새 요청 결과로 판정한다.

로그인 기본 화면은 원본 브랜드·Google 버튼·게스트 행동·실제 릴리즈 버전으로 구성한다. 공개 버전은 `TripPrint MVP - {version}`으로 번역한다. 프로필에서 돌아오면 `force_auth_entry`로 계정·게스트를 다시 고르게 한다. Google 취소는 기본 로그인으로 돌아오며 오류 완료로 표시하지 않는다.

게스트는 서버 회원 자격과 구분한 기기 UUID를 사용한다. 인터넷 없이 시작할 수 있으며 기기 저장 실패는 안내한다. Google 인증은 외부 인증 화면과 실제 서버 검증을 사용한다. Google 이름·이메일·사진을 최초 공개 프로필로 자동 확정하지 않는다.

## 프로필 설정

최초 화면은 기본 이미지·빈 닉네임·0/10·비활성 시작 버튼이다. 닉네임은 NFC 정규화와 앞뒤 공백 제거 후 한글·영문·숫자 2~10자로 검사한다. 중복 닉네임은 허용한다. 글자 수는 정규화한 Unicode 코드 포인트 수다. 초과 입력을 자르지 않는다. 입력 중 조합을 방해하지 않으며 포커스를 벗어났을 때 정규화와 오류 표시를 적용한다.

이미지 선택은 중앙 팝업에서 기본 이미지·활성 아바타·내 사진으로 나눈다. 기존 하루와 여행자 자산만 사용한다. Android에서는 앨범·촬영을 제공하고 WEB은 파일 선택을 제공한다. 필요한 권한은 선택 시점에 요청한다. 사진은 10MiB 이하이며 표시용 JPEG 사본으로 재인코딩한다. 서버는 JPEG·PNG 구조·크기·소유권을 다시 검사한다. 선택 취소나 업로드 실패는 이전 이미지와 닉네임을 유지한다.

이미지 처리·프로필 저장·결과 확인 중에는 입력과 중복 제출을 막는다. 최초 완료 작업 ID를 계정별로 보관하고 응답이 없으면 결과를 조회한다. 서버에서 저장·완료를 확인한 뒤 이동한다. 이미 완료한 계정을 최초 생성 요청으로 덮어쓰지 않는다. 재인증에 필요한 미저장 입력은 같은 계정의 메모리에서만 복원하며 앱 종료 후 복원은 보장하지 않는다.

상단 뒤로가기와 시스템 뒤로가기는 공통 미저장 입력 보호를 따른다. 입력·선택 창을 먼저 닫고, 변경이 있다면 계속 작성하거나 버리고 이동하도록 확인한다. 작성 취소는 서버 가입 기록·기기 여행을 삭제하지 않는다.

## 기기 여행의 선택 연결

완료 회원에게 연결할 계정과 기기 여행을 표시하고 선택한 여행만 연결한다. 여행마다 작업 ID와 로컬→서버 ID 대응을 보관한다. 사진 수신 전에는 서버 여행 목록에 미완료 여행을 노출하지 않는다. 일부 실패 시 완료·실패를 구분해 다시 시도하며 기기 원본은 지우지 않는다. 연결 성공 후 여행·대상 UUID를 치환하고 선택 날짜를 보존한다. 인증·연결 성공만으로 공개·신고·지출을 자동 제출하지 않는다.

이 계약의 개인 기록은 workspace 안의 일정·개인 메모·영수증 품목이다. 별도 trail 저장소의 독립 기록은 이 가져오기 API의 입력이 아니다. 실제 서버 계약·필드는 [DB·객체 사전](<../../03. 개발/02. 데이터정의/DB_객체사전.txt>)을 따른다.

## 검증과 배포

새 서버 API와 DB 변경은 로컬 구현이다. 기존 staging에는 자동 배포하지 않는다. Android Studio에서는 로컬 API와 Metro를 함께 실행해 새 계약을 확인한다. Google 실제 인증·운영 저장·Play 설치는 로컬 인증과 구분한다. 자세한 결과는 [노션 명세 반영 검수](<../../05. 검수/02. 검수보고/2026-11-04_노션_시작로그인프로필_반영검수.md>)에 기록한다.
