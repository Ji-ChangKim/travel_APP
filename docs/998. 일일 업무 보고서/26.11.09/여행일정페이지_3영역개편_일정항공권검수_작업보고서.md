# 여행 일정 페이지 3영역 개편 · 동선 지도 및 일정·항공권 검수 작업 보고서

## 작업 결과

여행 일정 페이지(`/trips/[id]`)를 손그림 와이어프레임 구조(`1. 상단 바 < Title | ⋮` → `2. 2줄 여행 요약 박스 [여행 타이틀 / (여행일정) | 동반자]` → `3. [일정 | 가계부] 2탭 메뉴` → `4. (DAY 1) · · · · 일차 칩` → `5. 동선 파악용 구글 지도 + 세로 타임라인 | [일정 박스]` → `6. 하단 중앙 원형 ( + ) 버튼`)와 100% 일치하도록 개편했다.

또한 `(여행일정)` 타원 배지에서 **기본 날짜(`11.27~11.30 (3박 4일)`)**, **연도가 바뀔 때(`26.12.30~27.01.02 (3박 4일)`)**, **일정 날짜가 미정일 때(`3박 4일`)**를 모두 대응했으며, `DAY 1 ~ DAY M` 칩에서 불필요한 날짜(`11.27(금)`)를 제거해 일차 번호만 직관적으로 보이도록 개선했다.

코드 변경 후 실행한 `npx eslint --max-warnings=0`, `npm run check:architecture`, `npm run check:navigation`, `npm run check:design`, `npm run check:resources`, `node scripts/checks/check-docs.mjs` 및 단위 테스트 **50개 항목이 모두 통과**했다.

## 2. 핵심 플로우 검수 결과 (API 통신 · DB 등록 · 버튼 작동)

1. **여행 일정 추가 플로우**:
   - **API 통신**: `PlaceSearch.tsx` → `GET /api/v1/places/search` 및 `GooglePlace.tsx` → `GET /api/v1/places/:placeId` 정상 연동 확인.
   - **DB 등록**: `schedule.save` 명령을 통해 서버 D1 DB(`trip_schedules`) 및 게스트 로컬 저장소에 정상 등록 확인.
   - **버튼 작동**: `[+ 장소 검색 / 장소 추가]`, 타임라인 내 `[길찾기]`, `[일정 상세]`, 접기/펼치기(`⌃`/`⌄`), 인라인 `[편집]`(`⊖` 삭제, `↑`/`↓` 순서 변경), 관리 시트(`•••`) 모두 정상 작동 확인.
2. **항공권 조회 및 일정 추가 플로우**:
   - **API 통신**: `FlightLookup.tsx` → `GET /api/v1/flights/lookup` 연동 및 수동 입력 전환 확인.
   - **DB 등록**: `type: 'TRANSPORT'` 및 `flight` 객체 포함 `schedule.save` 저장, 타임라인 세로 점선(`⋮`) 및 항공 요약 렌더링 확인.
   - **버튼 작동**: `DAY` 칩 하단 `[✈️ 항공권 추가]` 및 빈 일정 카드 `[항공편 조회로 채우기]` 클릭 시 즉시 항공권 조회 모달 진입 확인.
3. **영수증 플로우 (14전 버전 준비 상태)**:
   - 하단 고정 액션바 `[🧾 영수증 추가]` 및 일정 추가 모달 내부 `[영수증 촬영으로 추가]` 클릭 → `ReceiptCapture.tsx` 촬영 안내 바텀시트 → `[카메라로 영수증 촬영]` 실행 및 카메라 권한/촬영 화면 진입 확인.
