- 작업일: 2026-11-10 화요일, 한국 시간 기준.
- 대상: TripPoint 앱과 같은 계정·핵심 DB를 사용하는 웹사이트 기획과 독립 웹 실행 기반.
- 기준 버전: `bbb38338a3311efb8315a67bd469dbcbc1019cef`, 작업 브랜치 `codex/prepare-0.0.1`과 미커밋 변경.
- 범위: 기획·색인·일일 보고서, 독립 웹 프로젝트·실행·검사·CI 연결. 앱 화면·API·DB·공통 UI는 변경하지 않았다. 커밋·푸시·운영 배포는 수행하지 않았다.

## 1. 완료 내용과 남은 범위

홈·계정·일정 편집·영수증·커뮤니티·지도와 추가 페이지를 19절의 초기 계획으로 정리했다. 앱·웹 공통 DB와 웹 게스트 금지는 사용자 확정 조건으로, 로그인 전 공개 열람·페이지 배치·출시 단계는 검토안으로 구분했다. 구현과 실제 연동 검증은 후속 작업이다.

후속 요청에 따라 웹 홈페이지를 11절의 화면 계획으로 구체화했다. 로그인 전·후 영역, 회원 빈 상태·초안·열람 권한, 버튼별 목적지·취소·실패·인증 복귀와 홈페이지 수용 기준 16개를 추가했다.

페이지 관리를 위한 개발 폴더와 Git 운영안을 추가했다. 기존 저장소의 `apps/web`, 기능별 브랜치, 공통 UI·타입·CI 보완, 페이지 추적과 환경별 배포를 계획으로 정리했으며 실제 설정은 바꾸지 않았다.

최신 요청에 따라 개발 구조의 장단점을 비교하고 Android·WEB 1.0.0 최종 흐름에서 역산한 8단계 출시 계획을 작성했다. 사용자는 Android·WEB 우선, iOS 후속을 선택했다. 기존 필수인 Android 게스트 서버 저장과 사진·영수증의 회원 가져오기까지 출시 통과 조건으로 보존했다.

## 3. 조사와 검토 기록

### WEB-BASE-01 현재 구조 조사

- 대상 파일·버전: `apps/web`, `apps/mobile`, `apps/api`, `packages/domain`, `packages/validation`와 현행 기획·API·DB 문서. 기준 `bbb3833`.
- 검토 차수: 최초 0회. 읽기 전용 분석 담당이 조사했으며 수정·외부 변경·검사는 실행하지 않았다.
- 발견 사항: 독립 웹 초기 뼈대, Expo 웹, Bearer 인증 연결, Naver URL 미지원, 웹 SVG 지도, 영수증 날짜·금액·통화·중복 제약, 여행당 공개본 1개.
- 조치 결과: 주 담당이 현재 구현과 실제 검증을 구분해 웹 선행 작업·출시 조건에 반영했다.

### WEB-PLAN-01 기획 검토

- 대상 파일·버전: 웹사이트 초기 구성 계획서 초안, 기준 `bbb3833`.
- 검토 차수: 최초 0회. 읽기 전용 검토 담당의 검토 후 주 담당이 수정했다. 재검토는 요청하지 않았다.
- 발견 사항: 전체 지출 공개 범위, 영수증 삭제·원본 정리의 차이, 쿠키 중계 서버의 업무 요청 전달, 가져오기의 출발일 필수 계약.
- 조치 결과: 비용 기본값·전체 합계 안내·100/200 표본 검수, 삭제 행동별 결과표, 인증된 업무 요청 중계, 날짜 미정 가져오기 제외를 반영했다. 주 담당이 수정 문장을 직접 대조했다.
- 남은 문제: 지도 보관·표시 조건, 월 예산, 표시 브랜드, 실제 방문 관계는 개발·출시 전에 확정한다.

한글은 새 기획 문서로 작성하고 지정된 한글 작성 규칙에 따라 표현·용어·설명 순서를 점검했다. 원문 윤문 작업이 아니므로 원문 대비 변경률을 산정하지 않았다. UI 참고 검색을 진행했지만 새 색상·글꼴은 채택하지 않고 현행 디자인 토큰·공통 헤더·GNB를 기준으로 삼았다.

실제 캡처는 production-desktop.jpg·production-full.jpg, desktop-1440.jpg·mobile-390.jpg에 있다. 빌드한 화면에서도 장면 전환·정지·사진 출처 열람을 조작했다. 실제 화면과 규격의 배치·글꼴·색상·버튼·사진 비율을 대조했다. 검토 중 발견한 장식 경로의 가로 넘침, 큰 글자에서 영수증 예시가 넘치는 문제는 수정 후 재확인했다. 남은 차이는 OS 실설정·실기기 검증이며 홈은 아직 설계 단계다.

기존 앱 회귀 실패에는 여행 탭의 기대 일정·가계부와 실제 여행 계획·가계부·공유의 차이, 여행 계획 라벨의 대비 2.8027:1, MY 글자 검의 대비 4.2023:1이 포함된다. 이는 검사에서 관찰한 값이며 큰 글자·이미지·규격별 판정을 같은 것으로 단정하지 않는다. 앱 소스·기존 검사·검수 설정은 이번에 바꾸지 않았다. 검사 기준을 낮추거나 기존 앱을 요청 밖에서 수정하지 않았으며 전체 앱 회귀가 통과했다고 판단하지 않는다. 앞 절의 기존 번역 누락도 별도 문제로 유지한다.

### 다음 작업과 인계

브랜치는 codex/prepare-0.0.1이며 기존 미커밋 기획·개발 준비 변경을 보존했다. 커밋·푸시·운영 배포는 하지 않았다. 홈 구현은 웹 계정·공통 API와 앱/웹 공통 탐색 계약을 준비한 뒤 진행한다. 랜딩의 SiteHeader를 서비스 홈용 헤더로 복제하지 않는다. 기존 앱 회귀 문제는 해당 앱 화면·검사 기준을 대조하는 별도 작업으로 인계한다.

최종 필수 검사 npm run check는 통과했다. 문서 검사 7개·문서 53개·링크 278개 오류 0, 코드 경계 603개 파일·위반 0, 헤더/GNB 경계 496개 소스·23개 화면·위반 0을 확인했다. 기존 앱의 실제 헤더 회귀는 앞서 기록한 15건 실패로 남으며 이 정적 검사 통과와 구분한다. 작업 후 보고서 원본·생성 HTML·문서 연결·서식도 다시 확인한다.
