## 2. 개선 전후

| 개선 전                                                                                   | 개선 후                                                                                                     |
| ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 게스트 기록이 기기에만 머물고 Google 연결 시 전체 여행이 일괄 이전됨 (`COMMON-01`)        | 게스트 기록을 서버에 자동 백업·복구하고 계정 연결 시 체크박스로 선택한 여행만 가져옴                        |
| 생성한 여행을 삭제하거나 참여한 공유 여행에서 나갈 수 없음 (`COMMON-02`)                  | 소유자는 여행 삭제(연결된 커뮤니티 공개 글 동시 내림), 참여자는 공유 여행 나가기 가능                       |
| 지원 통화가 `KRW·JPY·USD` 3개뿐이고 영어 `1 items` 오표기가 노출됨 (`COMMON-05~06`)       | `TWD·VND·THB·CNY·SGD` 5개 통화를 추가해 총 8개 통화를 지원하고 영어 `1 item` 단수형을 자동 보정함           |
| 웹 첫 진입 시 폰트 대기로 흰 화면이 보이고 `/welcome`에 언어 선택이 없음 (`LOGIN-01~04`)  | 폰트 로딩 중에도 BI 화면을 즉시 표시하고 기기 언어 기본 적용 + `/welcome` 우측 상단 언어 선택 버튼을 제공함 |
| 홈에서 영수증 기록 버튼이 묻혀 있고 빈 홈에서 과거 여행 기록 진입이 어려움 (`HOME-01~04`) | 여행 카드 첫 버튼을 ‘영수증으로 기록하기’로 고정하고 빈 홈 ‘다녀온 여행 기록하기’·도시별 후기 수를 연결함   |
| 과거 여행 생성 후 빈 일정만 열리고 달력 오늘 표시·요약 대칭이 부족함 (`NEW-01~05`)        | 과거 여행 생성 시 영수증 사진 일괄 등록 화면으로 바로 연결하고 달력 ‘오늘’ 배지·요약 한 줄·테두리를 정리함  |
| 게스트 장소 검색이 차단되고 일정 추가 화면에 모든 입력이 펼쳐져 복잡함 (`PLAN-01~11`)     | 서버 게스트 세션·일일 한도로 장소 검색을 허용하고 일정 추가 기본 화면을 ‘제목+검색’으로 단순화함            |
| 커뮤니티 초기 피드가 비어 있고 영수증 근거 표시·메뉴 가격 선택 공개가 없음 (`FOOT-01~04`) | 8개 주요 도시 × 3개(24개) 영수증 기반 시드를 제공하고 ‘영수증 기록 있음’ 배지 및 메뉴·가격 선택 공개를 지원 |
| 약관 요약이 한국어뿐이고 게스트 아바타 ‘G’가 Google 로고와 혼동됨 (`MY-01~05`)            | 약관·처리방침 3개 언어 번역과 전문 보기 링크를 연결하고 기본 아바타를 사람 아이콘으로 통일함                |

## 3. 조사와 검토 기록

### COMMON-04-REV01 영수증 인식 50장 실사용 표본 검증

- 대상 파일·버전: `apps/api/src/features/receipts/receiptAnalysis.ts`, `apps/api/src/features/receipts/ocr.ts`, `apps/mobile/src/features/workspace/shared/model/receiptChecks.ts`, `tests/auth/receiptEvaluation50.test.ts`.
- 검토 차수: 1회. 한국(`KRW` 10장), 일본(`JPY` 10장), 미국(`USD` 8장), 아시아 5개국(`TWD·VND·THB·CNY·SGD` 10장), 구겨짐·필드 누락·미지원 통화(`EUR` 포함 7장), 영수증 아닌 일반 사진(5장) 총 50장 표본을 구성해 검증했다.
- 발견 사항: `apps/api`는 Zod 4(`^4.6.5`), `packages/validation`은 Zod 3(`^3.24.2`)을 사용해 `ocr.ts` 내부에서 외부 Zod 3 스키마를 직접 합성하면 런타임 호환 오류가 발생할 수 있음을 확인했다.
- 조치 결과: `ocr.ts`의 `printedCurrencySchema`를 8개 지원 통화 `z.enum`으로 선언해 런타임·타입 호환을 모두 확보했고, 50장 전 표본에서 상호·총액·결제일·품목 행 보존율 100% 및 비영수증·누락·미지원 통화 차단 안내를 검증해 작업지시서 3.1절에 기록했다.

### MY-02-REV01 2인 공유 여행 소유권 이전 및 계정 삭제 검증

- 대상 파일·버전: `apps/api/src/features/accounts/service.ts`, `apps/mobile/src/features/profile/ui/AccountDeleteModal.tsx`, `tests/auth/accountManagement.test.ts`.
- 검토 차수: 1회. 회원 2명(`owner`, `member-2`)이 참여 중인 공유 여행 1개가 있을 때 소유자의 계정 삭제 흐름을 검증했다.
- 발견 사항 및 조치 결과: 소유권 이전 전에는 계정 삭제 요청이 차단되고 영향 목록에 공유 여행이 표시되며, `member-2`에게 소유권을 이전한 직후 삭제 신청이 정상 접수(`deletion_requested`, 7일 유예·30일 파기 안내)되고 세션 폐기 및 재로그인 차단까지 이어짐을 자동화 테스트로 검증했다.
