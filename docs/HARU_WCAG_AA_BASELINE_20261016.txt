TripPrint · WCAG 2.2 AA 제작 기준과 대비 검수
작업일: 2026-10-16

제작 전 기준
- 정보 전달용 본문·보조 문구·버튼·입력값·플레이스홀더는 크기와 관계없이 4.5:1 이상으로 제작한다.
- WCAG에서 예외인 비활성 글자도 프로젝트 기준은 4.5:1이다. 로고·장식은 정보 전달용 글자로 사용하지 않는다.
- 컨트롤 식별 경계·의미 있는 아이콘·직접 만든 초점 표시는 인접 배경 대비 3:1 이상을 확인한다.
- 공통 초점선 2px, 터치 영역 44px는 프로젝트의 제작 규격이다.
- 색 외에도 선택·오류·완료 문구와 체크·접근성 상태를 함께 사용한다.
- 키보드 이동·실행·닫기와 초점 복원, 글자 200%, 작은 화면의 내용·기능 유지도 확인한다.

자동 차단
npm run check:design
npm run check

check:design은 현재 JSON 토큰으로 sRGB 상대 휘도를 다시 계산한다. 기존 contrastChecks의 저장 수치를 통과 근거로 사용하지 않는다. 반올림 전 값이 4.5 또는 3에 못 미치면 실패한다. npm run check는 이 검사를 TypeScript·ESLint·Prettier보다 먼저 실행한다.

실제 토큰 계산
- 본문 네이비 / 아이보리: 12.492822413186602:1
- 보조 글자 / 아이보리: 약 5.68:1
- 주요 버튼 네이비 / 코랄: 4.657779332381318:1
- 눌린 버튼 흰색 / 진한 코랄: 6.340766173339224:1
- 비활성 글자 / 비활성 배경: 4.882464624469171:1
- 현재 46개 의미별 조합 통과. 자세한 원값은 outputs/haru-wcag-aa/contrast-report.json에 기록한다.
- 핵심 팔레트는 이미 기준에 맞으므로 색을 불필요하게 바꾸지 않았다.

브라우저 검사 보완
기존 본문 검사에서 빠져 있던 input·textarea의 입력값과 플레이스홀더를 포함했다. 실제 pseudo-element 색·알파·조상 불투명도와 배경을 읽는다. 검사 결과에 비밀번호나 입력 원문을 남기지 않는다. 숨긴 요소·장식 아이콘·브랜드 로고는 본문 검사와 구분한다.

검사 흐름
320·390·430px에서 이메일 로그인·홈·목록·여행 생성·일정 작성·지도·비용·사진·준비물·동행·발자국·커뮤니티·MY를 검사한다. 주요 버튼의 누름과 보기 전용의 비활성 글자, Tab·Enter·Escape와 시트 초점 복원도 확인한다. 상세의 글자 200%와 문서 가로 넘침을 검사한다.

수정 파일
- scripts/check-design-contrast.mjs: 의미별 토큰의 대비 계산·실패 차단·JSON 보고서.
- package.json: check:design 명령 추가, 전체 check의 첫 검사로 연결.
- docs/design/design-tokens.json: WCAG 버전·목표 등급·대비·입력 안내·비활성 글자·확대·제작 규격 기록.
- docs/design/DESIGN.md: 작업 전 실행 절차·W3C 기준과 프로젝트의 더 엄격한 규칙·수동 검수 범위.
- tests/web/workspace.spec.ts: 입력·플레이스홀더 검사 보완, 세 폭의 접근성 흐름 추가.
- playwright.haru-wcag.config.ts: 최신 앱의 독립 검수 번들·포트·결과 경로.
- tests/auth/tripLifecycle.test.ts: 같은 작업 공간에서 제거된 지난 여행 전용 필터 대신 전체 목록에서 원본을 보존하는 기존 조건을 확인하도록 타입 계약 갱신. 제품의 여행 판별 로직은 수정하지 않았다.

범위와 후속 검수
이 기록은 명시한 토큰과 브라우저 흐름의 검사다. 전체 WCAG AA 인증이나 모든 성공 기준의 적합 판정이 아니다. 사진·배경 이미지 위 글자, 화면 읽기 순서와 실제 iOS·Android 보조기기는 수동 검수를 거쳐야 한다. 새 화면과 새로운 글자·배경 조합은 제작 전에 검사하고 실제 렌더링 후 다시 확인한다. DB·API 계약은 바꾸지 않았다.

최신 앱 브라우저 결과: 320·390·430px의 입력·플레이스홀더·누름·비활성·Tab/Enter/Escape·200% 글자 검사가 모두 통과했다(3개 흐름, browser-complete.log). 별도 여행 단계 계약 검사도 7개 통과했다. 목록 루트의 뒤로가기가 제거되어 키보드 시작점은 새 여행 버튼으로 갱신했으며 상세 뒤로가기는 44px 규격으로 계속 확인한다.


최종 전체 검사: npm run check 통과. 토큰 대비 46/46, TypeScript·ESLint·Prettier 모두 통과했다(check-latest.log). 최신 웹 번들 생성과 세 폭의 브라우저 검사 3개도 완료했다(browser-complete.log). 320px·글자 200% 실제 캡처를 확인했다.
