================================================================================
 TripPrint DB·도메인 객체 사전 (MVP 단일 기준)
 물리 스키마 원본: apps/api/migrations/*.sql (Cloudflare D1 / SQLite)
 도메인·검증 원본: packages/domain/src/*, packages/validation/src/*
================================================================================

A. 저장소 기준
- 물리 데이터베이스: Cloudflare D1(SQLite), Worker 바인딩 `DB`.
- 미디어 저장소: 비공개 Cloudflare R2, Worker 바인딩 `MEDIA`. 바이너리는 R2에, 메타데이터와 권한은 D1에 보관한다.
- 물리 스키마는 `apps/api/migrations/*.sql`을 적용한 업무 테이블 33개(컬럼 199개)로 구성된다.
- 앱 서버의 `*_at` 시각은 UTC epoch 밀리초(`INTEGER`)이며, 여행의 날짜(`YYYY-MM-DD`)·현지 시각(`HH:mm`)은 JSON 내부 문자열로 구분한다.

================================================================================

D. 핵심 데이터 무결성 및 보안 제약
================================================================================
1. 금액 정밀도: 모든 비용과 영수증 금액은 부동소수점 오차를 막기 위해 십진 문자열(`string`)로 저장하고 통화별 소수 자릿수 검증을 거친다.
2. 원자적 갱신과 멱등성: 여행 수정은 `trips.version` 비교(CAS), `trips.snapshot`, `trip_members`, `mutation_requests`를 단일 `D1.batch`로 처리한다.
3. 영수증 확정 및 원본 정리:
   - 동일 미디어(`mediaId`)의 중복 영수증 확정을 거부한다.
   - `keepPhoto: false` 선택 시 미디어 참조와 OCR 캐시를 즉시 제거하고 `receipt_cleanup_jobs`를 통해 R2 원본을 삭제한다.
4. 공개 데이터 격리: `posts.snapshot` 생성 시 원본 영수증 이미지, 세부 품목(`ReceiptItem[]`), 개인 메모, 동행자 식별 정보는 제외한다.

DB명: Cloudflare D1. 실행 원본은 0014·0015 마이그레이션이다. 운영 환경에 적용하지 않았다.
상세 계약: 같은 폴더의 계정_스키마설계.md, 계정_목표스키마.sql.
현재 인증 user/account/session, 상태 account_retirements, 인증 임시 verification/oauth_handoffs는 재사용한다.
새 members 또는 guest_accounts 테이블과 isGoogleUser/isGuest 컬럼은 만들지 않는다.

기존 테이블명: user / 추가 컬럼

기존 id는 여행·권한의 참조를 유지한다. email은 SDK 호환 고유 제약을 유지하되 Google 연결 키·통계 식별자로 사용하지 않는다.
name은 기본 표시값, image는 NULL을 목표로 하며 직접 프로필 입력과 Google 이름·사진의 신규 영속 수집을 제거한다.

토큰·scope·password 호환 컬럼은 유지하더라도 신규 Google 계정의 목표값은 NULL이다. 신규 저장 중단을 SDK 훅으로 검증했다. 미연결 credential 해시만 이행에 유지한다.

Google sub·이메일·이름·성별·생일·위치·금액·본문·임의 JSON payload 컬럼은 두지 않는다.
현행처럼 user 행을 남기는 탈퇴에서는 FK 자동 삭제가 실행되지 않으므로 파기 코드가 member_id 기준으로 원본 이벤트를 별도 정리해야 한다.

제거 순서: 신규 수집 중단 → 앱·API·도메인 의존 제거 → 기존 자료 정리 검증 → 불필요 테이블·컬럼 정리.
