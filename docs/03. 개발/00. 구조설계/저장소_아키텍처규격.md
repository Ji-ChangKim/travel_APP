# 저장소 아키텍처 규격

이 문서는 TripPrint 모노레포의 폴더 역할, 파일 명명 규칙, 계층 간 코드 경계 규칙을 정의합니다.

---

## 1. 워크스페이스 구조

| 경로                   | 역할                                                                                                                          |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `apps/mobile/`         | Expo(React Native·Web) 클라이언트 애플리케이션 (`src/app`, `src/components`, `src/features`, `src/services`, `src/constants`) |
| `apps/api/`            | Cloudflare Workers + Hono 백엔드 서버 (`src/config`, `src/features`, `src/infrastructure`, `src/shared`, `migrations/`)       |
| `packages/domain/`     | 클라이언트·서버 공통 TypeScript 도메인 모델 (`@wherego/domain`)                                                               |
| `packages/validation/` | Zod 기반 입력·응답·명령 검증 스키마 (`@wherego/validation`)                                                                   |
| `packages/api-client/` | 타임아웃·인증·멱등성 키·오류 변환을 담당하는 공통 HTTP 클라이언트 (`@wherego/api-client`)                                     |
| `scripts/`             | 역할별 자동화 도구 (`android`, `build`, `checks`, `design`, `qa`, `release`, `shared`)                                        |
| `tests/`               | 단위·통합·웹 E2E 테스트 및 픽스처 (`auth`, `cloud`, `planning`, `release`, `web`, `config`, `fixtures`)                       |
| `docs/`                | 현행 MVP 기준 문서                                                                                                            |
| `outputs/`             | 로컬 빌드 및 검수 산출물 (Git·EAS 업로드 제외)                                                                                |

---

## 2. 명명 및 의존성 경계 규칙

1. **폴더 및 파일 이름**:
   - 코드 폴더는 소문자 `kebab-case`를 사용합니다.
   - React 컴포넌트 파일은 `PascalCase.tsx`, 일반 모듈·훅·스타일 파일은 `camelCase.ts`, `scripts/` 도구는 `kebab-case.mjs/.cjs`를 사용합니다.
2. **서버(`apps/api/src`) 경계**:
   - 진입점(`index.ts`, `app.ts`) 외 모든 코드는 `config`, `features`, `infrastructure`, `shared` 폴더 안에 배치합니다.
   - `shared/` 계층은 개별 기능(`features/`)을 역참조할 수 없습니다.
3. **모바일(`apps/mobile/src`) 경계**:
   - 순수 모델(`model/*.ts`)은 `react`, `react-native`, UI 컴포넌트를 직접 import하지 않습니다.
   - 화면은 상단 헤더(`AppHeader`)와 하단 탭(`GlobalNavigation`)을 로컬 스타일로 덮어쓰지 않습니다.
4. **자동 검증**:
   - `npm run check:architecture` 및 `npm run check:navigation`으로 폴더 구조와 의존성 경계를 검사합니다.
