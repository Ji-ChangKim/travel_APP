# 리소스 아키텍처

이 문서는 앱 번들에 포함되는 정적 리소스와 런타임 사용자 미디어의 분리 원칙 및 검증 체계를 정의합니다.

---

## 1. 정적 번들 리소스 (`apps/mobile/assets/`)

- **브랜드 자산 (`brand/`)**: 앱 아이콘, 스플래시, TripPrint 로고, 하루(Haru) 캐릭터 이미지 및 무결성 해시(`manifest.json`).
- **글꼴 (`fonts/`)**: `LINESeedKR` 및 `Pretendard` 글꼴 파일과 오픈소스 라이선스 문서.
- **아이콘 (`icons/`)**: SVG 원본과 매니페스트(`icon-manifest.json`).
- **목적지 사진 (`destinations/`)**: 추천 도시 이미지와 저작자·라이선스 출처 명세(`credits.json`).
- **일러스트 (`illustrations/`)**: 화면 고정 일러스트 자산.

---

## 2. 런타임 미디어 및 검증 규칙

1. **사용자 미디어 분리**: 사용자가 등록하는 여행 사진과 영수증 이미지는 `assets/`에 저장하지 않으며, 게스트는 기기 문서 폴더에, 회원은 비공개 Cloudflare R2 버킷에 저장합니다.
2. **정적 참조 검사 (`npm run check:resources`)**:
   - 코드와 `app.config.ts`에서 참조하는 모든 정적 이미지·글꼴 경로가 실제로 존재하는지 검사합니다.
   - `apps/mobile` 외부의 파일(예: `docs/` 내부 이미지)을 앱 런타임 코드에서 직접 `require`/`import`하는 행위를 차단합니다.
