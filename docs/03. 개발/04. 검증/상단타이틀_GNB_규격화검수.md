# 상단 타이틀·GNB 규격화 검수

## 결과와 범위

사용자의 작업 시작 지시에 따라 [페이지별 기능 정의서](<../../01. 서비스기획/01. 기능정의/앱기본구조_페이지별기능정의서.md>)의 제목 통일을 구현했다. 홈은 기존 브랜드를 유지하고 내 여행·커뮤니티·MY는 공통 제목 헤더를 사용한다. 하위 화면의 제목·뒤로가기와 기존 4탭 GNB 구성은 유지한다. 기본 구조의 선행 실제 서버 검사 7개에 이어, 현재 여행 상세에 맞춘 전체 헤더·GNB 회귀 22개와 필수 코드 검사를 통과했다. 큰 글꼴에서 실제로 발생한 제목 넘침은 공통 헤더의 제목 전용 행으로 해결했다.

여행 제작·계획 편집·게스트 서버 저장·장소·영수증 내부는 이번 변경 범위에 포함하지 않는다. DB 스키마·저장 데이터·API 계약·인증 방식은 변경하지 않는다. 기존 사용자 흐름 문서와 이미지, 앞선 기본 구조 구현은 보존한다. 커밋·운영 배포는 수행하지 않는다.

## 규격 대조

공통 `ScreenHeader`·`ScreenTitle`·`HeaderAction`을 재사용한다. 글꼴·치수·색상·토큰·GNB 코드와 모션은 유지한다. 큰 글꼴에서 뒤로가기·우측 행동이 함께 있으면 공통 헤더의 제목 전용 행으로 높이를 확장한다. 기준은 제목 26/36·굵기 700, 헤더 최소 높이 56·좌우 여백 20·최대 폭 640·수직 여백 6, 터치 영역 48, GNB 최소 높이 64·아이콘 22·라벨 13/20이다. 안전 영역과 글자 확대는 기존 확장 규칙을 따른다.

실제 서버의 새 검사에서는 제목 26/36과 글자 확대 시 52/72, 왼쪽 정렬, 헤더 최소 높이 56, GNB 버튼 4개와 최소 터치 영역 48을 대조했다. 공통 토큰을 낮추거나 페이지별로 재정의하지 않았다. 영어의 긴 단어와 일본어 제목은 규격대로 줄바꿈하며 높이를 확장했다.

실제 캡처는 `outputs/navigation-standard/index.html`에서 함께 볼 수 있다. 주요 파일은 `community-standard-390.png`, `community-alias-390.png`, `plans-standard-390.png`, `community-320-font200.png`, `plans-430-font200.png`, `footprints-en-320-font200.png`, `plans-ja-320-font200.png`다. 스케치가 아닌 실행 화면이며, `source-manifest.json`은 최종 작업 사본의 해시를 기록한다. 별도 여행 화면 변경까지 동일 빌드로 검수했다는 의미는 아니다.

### 전체 회귀 실패 정리

현행 고정 탭은 일정·지출이다. 지도 등 보조 영역은 더보기에서 연다. 공통 검사 도구도 이 경로를 사용하며, 기존 호출의 비용 이름은 현재 지출 탭으로 연결한다. 항공편은 사라진 상단 카드 대신 장소 추가 → 이동 → 항공편으로 등록에서 검사한다. 빈 입력을 저장했을 때 안내 표시와 서버 변경 없음도 유지했다.

커뮤니티 제목은 GNB와 같은 문구이므로 제목 역할로 선택한다. 오류 상세에서 복귀한 주소·제목·커뮤니티 탭 선택을 함께 확인한다. 커뮤니티에 남아 있던 과거 브랜드 헤더 검사 예외도 제거했다.

320px·글자 200%의 긴 여행 제목은 실제로 상자 폭을 넘었다. 기존 제목 26/36·확대 52/72와 버튼 터치 영역을 유지하며 제목을 공통 헤더의 아래 전용 행에 배치해 해결했다. 기준을 낮추거나 실패 항목을 제외하지 않았다. 원래 22개·선택 범위·시간 제한을 그대로 사용해 전체 통과했다.

지정한 일일 보고서 경로는 해당 루트와 유효한 YY.MM.DD 날짜만 허용한다. 다른 이름·위치·잘못된 날짜와 깨진 링크를 차단하는 검사를 추가했다. 최종 보고서는 [일일 작업 보고서](<../../998. 일일 업무 보고서/26.11.09/상단타이틀_GNB_전체회귀검사_작업보고서.md>)에 있다.

수정 전 실패 증거는 `outputs/header-regression/first-run/`, `title-overflow/`에 보존한다. 수정 후 실제 캡처는 `outputs/header-standard/flights-320-200.png`, `detail-지도-390-200.png`, `flights-430-200.png` 등이다. 화면 모음은 `outputs/header-regression/index.html`에서 볼 수 있다. 큰 글꼴·긴 제목의 잘림은 남아 있지 않다.

## 검토와 남은 항목

- 쟁점 ID / 대상: SHELL-NAV-01 / 제목 정책·두 공개 목록·관련 검사·위 연결 문서.
- 검토 차수: SHELL-NAV-01 변경 후 재검토 1회. 주 에이전트의 구현·문서·전체 22개 검수 대조. 서브에이전트 재검토 없음.
- 발견 사항: 두 커뮤니티 경로가 다른 제목·검색 구성을 사용. 내 여행 제목과 GNB 라벨 불일치.
- 조치: 같은 화면과 공통 헤더로 통일. 로딩·오류에서도 같은 제목을 사용하고 GNB 주소 판정은 기존 공통 정책 유지.
- 추가 검토: SHELL-HEADER-REFLOW-01·SHELL-REPORT-PATH-01 최초 0회. 실제 제목 넘침 수정과 보고서 경로 예외의 범위를 확인.
- 남은 항목: 실제 외부 인증·실기기 인수, 기본 구조 정의서의 전체 언어·계정 전환·오류 조합 검수, 약관·개인정보 페이지, 게스트 서버 저장, 여행 제작·장소·영수증 후속 작업.

이번 검수 통과를 정의서의 모든 기능과 여행 작성 사이클의 완료로 확대하지 않는다. 변경 후 저장 기능이 추가된 작업도 아니므로 서버 저장 계약 검사를 새로 완료했다고 보고하지 않는다.
