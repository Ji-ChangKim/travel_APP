# 계정 데이터 관리 검수

## 1. 요청과 완료 범위

현재 우선 작업은 계정 DB·API 반영, 기존 자료 이행, 계정 삭제 서버 정책이다. 사용자는 Google 정보만 입력받고 불필요한 정보는 제거하되 Google 회원·기기 게스트와 서비스 이용을 구분하라고 지시했다. 이전 전체 페이지 기능 To-do의 완료 판정을 이 보고서의 계정 작업으로 대신하지 않는다.

[계정 역할과 데이터 기준](<../../01. 서비스기획/01. 기능정의/계정_역할과데이터기준.md>), [계정 스키마](<../02. 데이터정의/계정_스키마설계.md>), [이행·삭제 서버 정책](<../02. 데이터정의/계정_이행삭제_서버정책.md>)을 기준으로 서버를 구현했다. 화면 배치·폰트·입력창·헤더·GNB는 수정 범위에서 제외했다. 기존 화면이 호출하던 추가 프로필 입력·탈퇴 경로는 서버에서 닫았으므로 새 앱 연결은 별도 확인해야 한다.

대상은 `main`의 `db0dc16`과 현재 공유 작업 트리다. 다른 작업의 변경은 보존했다. 운영 DB·R2의 실제 사용자 값은 조회하지 않았고 운영 이행·개인정보 삭제·배포를 실행하지 않았다.

## 3. 반영한 서버 동작

신규 가입은 Google만 허용한다. 기존 이메일 계정은 Google을 연결하기 전까지 기존 비밀번호 로그인을 유지한다. Kakao·Naver는 기존 연결 계정만 로그인한다. 같은 이메일로 자동 합치지 않는다. 최근 10분 이내 본인 세션에서 같은 이메일의 Google을 명시 연결하면 ID를 유지하며 이전 비밀번호 해시는 제거한다.

`GET /api/v1/account`는 본인 계정 종류와 비공개 이메일을 안내한다. 기본 프로필 조회는 추가 입력 완료를 요구하지 않으며 Google sub·생일·성별·소개를 반환하지 않는다. 추가 입력 경로는 410이다. 기기 게스트를 서버 회원으로 새로 만들지 않는다.

신규 삭제는 `DELETE /api/v1/account`, 명시 확인·정책 버전·최근 인증을 요구한다. 공유 소유 여행은 409로 거부하고 기존 참여자에게 명시 이전하도록 한다. 접수 응답은 202이며 완료 응답으로 표현하지 않는다. 서버는 세션·초대를 즉시 차단하고 파일·사본 정리가 끝난 뒤 실제 회원 행을 삭제한다. 이미 접수된 90일 요청은 기한과 복원·파기 계약을 보존하되 신규 옛 POST 요청은 410으로 닫는다.

개인 여행은 삭제한다. 다른 소유자의 공유 여행에서는 본인 권한·업로드·영수증·품목·연결 비용·OCR 사본을 제거한다. 다른 참여자의 공동 일정과 무관한 공개본은 유지한다. 사진 미보관 영수증도 삭제한다. R2 실패·늦은 파일·동시 삭제는 작업과 DB 저장 제약으로 재시도한다.

기존 추가 프로필과 사본 정리는 서버 작업으로 분리했다. 기본 표시명은 여행·공개본·미완료/완료 가져오기에도 적용한다. 입력 해시·ID 매핑·저장 요청 키는 유지해 재시도로 새 여행이 생기지 않게 한다. 원본 자료가 복원될 수 있는 백업이 남아 있는 동안 비공개 UUID 삭제 표식을 보관한다.

## 6. 검토와 남은 작업

쟁점 `ACCOUNT-DELETE-02`의 최초 0회는 FK·공유 JSON·초대/업로드 경합 경계를 조사했다. 재검토 1회에서 무관한 공개본 철회·사진 미보관 영수증·OCR 사본·서명 handoff 대조·가져오기 옛 이름 재저장·서로 다른 삭제 작업의 교착을 확인해 수정했다. 관련 실행 검사를 주 담당이 수행했다. 최종 재검토 2회에서 고아 파일의 진행 위치가 없어 뒤쪽 자료를 정리하지 못하는 문제를 추가 확인했다. 주 담당이 영속 커서·페이지 단위 D1 대조·처리량 제한·실패 종류 순환을 구현했다. 정상 파일 205개 뒤의 고아 파일, 한 호출 3쿼리, 공유 여행 5개 재개, 보수적인 50쿼리 예산을 직접 검증했다. 복원 차단도 10개씩 진행 위치를 저장한다. 수정 후 추가 독립 재검토는 요청하지 않았다. 같은 쟁점의 자동 재검토는 2회를 넘기지 않는다.

정적 검사와 DB·Worker 회귀는 통과했지만 전체 인증 회귀는 기존 다른 화면의 번역 키 누락으로 미완료다. 이 문제를 숨기거나 검사를 제외하지 않았다. 화면 문구·번역을 바꾸는 작업은 요청 범위에서 제외했다. 기존 변경 파일 5개는 필수 서식 검사에 맞춰 공백·줄바꿈만 정리했으며 화면 배치와 동작은 바꾸지 않았다.

미실행 범위는 실제 Google 테스트 계정 로그인, 앱 삭제 버튼·소유권 이전 연결, 운영 자료 이행·정리·배포다. 실제 운영 백업 수명·검수 대상 계정을 확인한 뒤 승인 범위에서 재개한다. 기존 이메일 계정이 비밀번호를 잊었을 때의 복구 수단과 서버 익명 자료의 기기/회원 연결 지원도 남아 있다.
