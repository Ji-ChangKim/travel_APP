2026-10-06. 이번 배포 식별자는 `test-1`이다. 실제 이메일 인증·D1 여행 데이터·비공개 R2 사진을 사용하는 MVP 스테이징이다. 웹 테스트는 배포 URL에서 진행하고, Android 설치 테스트는 실제 EAS APK 생성 뒤 진행한다.

테스터별 이메일로 직접 가입한다. 비밀번호는 8자 이상이며 공용 계정은 사용하지 않는다. 현재 이메일 소유 확인·비밀번호 재설정 메일은 연결하지 않았다. 동행 공유 검사는 서로 다른 두 계정과 브라우저 프로필을 사용한다.

자동 검사는 아래 검증 기록에 표시한다. 이 표의 수동 테스트와 Android 실기기 테스트가 모두 실행되었다는 뜻은 아니다. 테스트 데이터 제목은 `TEST1_닉네임_항목`으로 구분하고, 게시글 철회와 사진 정리는 작성 계정의 앱 기능으로 진행한다.

## 현재 제공 범위

이메일 인증, 여행/항공/기간, 수동 일정, 사진, 비용, 영수증 확인 입력, 체크리스트, 동행 초대·역할, 종료 다이어리, 선택 커뮤니티 게시를 테스트한다. Google Maps 앱/웹 열기는 제공한다.

자동 Google Places 검색·단축 공유 링크 장소 조회·Vision OCR은 실제 공급자 키 미연결 상태다. 해당 실패 안내 후 수동 입력으로 테스트한다. Google/Kakao/Apple 소셜 로그인, 이메일 확인/재설정 메일, 저장 목록 전체 동기화는 이번 준비본에 연결하지 않았다.
