# 에이전트·스킬 운영 기준

이 문서는 프로젝트 개발·기획·검수 시 주 에이전트와 서브에이전트의 역할 분담 및 검증 기록 양식을 정의합니다.

---

## 1. 역할 구성과 실행 한도

| 역할                   | 권한                | 책임                                                                     |
| ---------------------- | ------------------- | ------------------------------------------------------------------------ |
| 주 에이전트            | 읽기·쓰기·검증 실행 | 요구사항 파악, 설계·코드 수정, 서브에이전트 조율, 실제 검증 및 최종 보고 |
| 분석 담당 (`analyst`)  | 읽기 전용           | 코드·문서·경쟁 기능 조사, 근거 위치 및 영향 범위 정리                    |
| 검토 담당 (`reviewer`) | 읽기 전용           | 정책 충돌, 예외 누락, 보안·권한·접근성·UI 규격 위반 점검                 |

- 동시 실행 에이전트는 주 에이전트를 포함해 최대 **3명**입니다.
- 동일 쟁점에 대한 재검토는 최초 검토(0회) 이후 **최대 2회**(1회, 2회)까지만 수행합니다.
