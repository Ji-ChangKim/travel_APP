## 이번 정리와 구분할 사항

1. 전체 검사에서 `CommunityScreenView.tsx`의 GNB 스크롤 스토어 직접 참조가 표현 계층 규칙에 걸렸습니다. 별도 전체 린트에서는 `GlobalNavigation.tsx`의 렌더 중 ref 접근 오류 7개와 미사용 변수 경고 1개가 나왔습니다. 이 화면 동작을 폴더 정리 작업에서 수정하거나 검사 기준을 낮추지 않았습니다. 별도 수정 중이던 `GlobalNavigation.tsx`·`navigationPolicy.ts`에는 전체 서식 검사 과정에서 서식만 정리했습니다.
2. 정리 시작 시점과 비교해 공통 토큰의 바탕색·경계색 4개 값이 별도로 변경된 것을 확인했습니다. 이번 경로 치환에서 색상을 변경하지 않았으며 확인한 값을 덮어쓰지 않고 보존했습니다. Ledger 토큰은 시작 시점과 바이트가 같습니다. 최신 토큰 대비 검사는 75/75 통과했습니다.
3. 정리 이전부터 정적 시안의 자산 참조 643건, 고유 대상 112개가 파일로 존재하지 않았습니다. 주로 페이지 축소 캡처와 로컬 전용 시안 자산입니다. 이번 이동으로 정상 참조가 끊어진 경우와 구분해 목록을 보존했습니다. 미존재 자산을 더미 이미지로 채우거나 정적 시안 전체가 완전히 실행된다고 판정하지 않았습니다. 전용 검토 서버에서 실제 자산을 제공하는 경로는 별도로 확인했습니다.

문서 정리 결과와 전체 앱의 검사 통과 여부는 별개입니다. 이 보고서는 전체 코드의 출시 준비 완료 판정이 아닙니다.
