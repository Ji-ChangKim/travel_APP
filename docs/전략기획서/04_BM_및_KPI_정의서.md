## 1. 4-Pillar 다각화 비즈니스 모델 (Monetization Architecture)

TripPrint는 사용자 경험을 해치는 저단가 디스플레이 광고(배너)에 의존하지 않고, 여행자의 자연스러운 여정 맥락(Context) 속에서 발생하는 4대 고부가가치 수익 파이프라인을 구축합니다.

```
[ TripPrint 4-Pillar 다각화 수익 모델 구조 ]
┌─────────────────────────────────┬─────────────────────────────────┐
│ [Pillar 1] Travel Affiliate     │ [Pillar 2] Travel Fintech & FX  │
│ • 맞춤형 투어/패스/숙소 커머스   │ • 해외결제 체크카드/환전 제휴   │
│ • 수수료: 거래액의 3.0 ~ 8.0%   │ • 수수료: 결제액의 0.5 ~ 1.2%   │
├─────────────────────────────────┼─────────────────────────────────┤
│ [Pillar 3] TripPrint D2C Book   │ [Pillar 4] Tourism Big Data     │
│ • 1클릭 하드커버 포토북 출판    │ • 익명화된 여행 동선/소비 리포트│
│ • 객단가: 35,000원 (마진율 45%) │ • 건당 계약: 1,500 ~ 5,000만 원 │
└─────────────────────────────────┴─────────────────────────────────┘
```

### 1.1 Pillar 1. Travel Commerce Affiliate (맥락 기반 제휴 커머스)

- **메커니즘**: 여행자가 짠 일정표 상의 장소(예: 도쿄 디즈니씨, 신칸센 이동 등)에 맞춰 최적의 현지 입장권, 교통패스, 숙소 예약 링크를 맞춤형으로 넛지(Nudge).
- **수익 모델**: 거래 중개 수수료(Take Rate) 3.0% ~ 8.0% 수취 (클룩, 마이리얼트립, 아고다 등 글로벌 OTA API 제휴).
- **예상 연간 기여도**: 전체 매출의 약 35%.

### 1.2 Pillar 2. Travel Fintech & FX (트래블 핀테크 파트너십)

- **메커니즘**: 실시간 다중 통화 가계부와 연동하여, 목표 예산에 맞춘 환전 우대 혜택 및 트래블 특화 외화 체크카드 발급 연계.
- **수익 모델**: 신규 카드 발급 건당 수수료(CPA 20,000~30,000원) 및 해외 결제액의 0.5% 인터체인지 수수료 쉐어.
- **예상 연간 기여도**: 전체 매출의 약 18%.

### 1.3 Pillar 3. TripPrint D2C On-Demand Publishing (실물 포토북 출판)

- **메커니즘**: 여행 종료 즉시 자동 생성된 발자국 다이어리를 전문 제휴 인쇄소와 연동하여 단 1클릭으로 프리미엄 하드커버 여행책으로 인쇄 배송.
- **수익 모델**: 권당 28,000원 ~ 45,000원 (표준 권당 평균 35,000원 / 제조원가 19,000원 / 공헌이익률 약 45.7%).
- **예상 연간 기여도**: 전체 매출의 약 43% (핵심 캐시카우).

### 1.4 Pillar 4. Smart Tourism Big Data (B2B 지자체·관광청 리포트)

- **메커니즘**: 사용자 동의 기반의 비식별화된 국가별/도시별 실제 이동 동선, 장소 체류 시간, 카테고리별 소비 패턴 데이터를 정제하여 B2B 대시보드로 제공.
- **수익 모델**: 국내외 지자체 및 관광청, 관광 유통 기업 대상 연간 구독 또는 프로젝트성 리포트 공급 (건당 1,500만~5,000만 원).
- **예상 연간 기여도**: 전체 매출의 약 4% (고마진 순수익).

## 2. 단위 경제학 (Unit Economics) 및 고객 생애 가치 (LTV)

### 2.1 활성 여행자 1인당 연간 경제성 분석 (연 1.8회 여행 기준)

- **연간 고객 매출 (Revenue per User)**:
  - 제휴 커머스 예약 수수료 (연 2회 발생): 약 6,500원
  - 핀테크 카드/환전 제휴 (연 1회 발급/결제): 약 4,000원
  - D2C 포토북 출판 (연 0.5회 구매, 전환율 28%): 약 18,000원
  - **연간 1인당 평균 LTV (생애가치)**: **약 28,500원**
- **고객 획득 비용 (CAC)**:
  - 유료 마케팅 인당 획득 비용: 약 7,000원
  - 그러나 바이럴 K-Factor 1.25 적용 시 유기적(Organic) 유입 희석
  - **실질 블렌디드 획득 비용 (Blended CAC)**: **약 2,800원**
- **LTV / CAC 배수**: **10.18x** (초기 스타트업의 통상적 건전성 기준인 3.0x를 3배 이상 상회하는 압도적 수익 구조).

## 3. 북극성 지표 (North Star Metric, NSM) 수립

```
┌────────────────────────────────────────────────────────────────────────┐
│                   TripPrint의 북극성 지표 (NSM)                         │
│                                                                        │
│        ★ "주간 완료된 완전한 여행 라이프사이클 수"                    │
│   (Weekly Completed Full-Lifecycle Trips, 이하 WCFT)                  │
└────────────────────────────────────────────────────────────────────────┘
```

### 3.1 왜 WCFT가 TripPrint의 북극성 지표인가?

단순 가입자 수(MAU)나 일정 생성 수는 껍데기 지표(Vanity Metric)에 불과합니다.  
TripPrint의 비즈니스 본질은 **"계획(Plan) → 협업(Share) → 현장 방문/지출(In-Trip) → 기록/출판(Record)"**의 4단계를 여행자가 이탈 없이 완주했는가에 있습니다.

- **고객 가치 증명**: 4단계를 모두 완료한 여행자는 일정 파편화, 정산 갈등, 사진 방치라는 3대 페인포인트를 100% 해결받았음을 의미합니다.
- **비즈니스 수익 직결**: 여정을 완주한 사용자만이 커머스 제휴 예약, 환전/카드 결제, 포토북 실물 주문, SNS 자발적 바이럴 공유를 발생시킵니다.

### 3.2 북극성 지표를 견인하는 4대 인풋 지표 (Input Metric Drivers)

```
                       [ 북극성 지표: WCFT ]
                                ▲
        ┌───────────────────────┼───────────────────────┐
        │                       │                       │
 [Driver 1. 계획 완결]   [Driver 2. 동행 초대]   [Driver 3. 현장 유틸리티] [Driver 4. 기록 전환]
 1분 일정 생성 완료율    여행당 초대 수락자 수   방문인증 & 영수증 등록수  발자국 다이어리 생성율
 (목표: > 85%)           (목표: > 2.0명)         (목표: 일평균 > 4건)      (목표: > 70%)
```

## 4. 계층별 핵심 성과 지표 체계 (AARRR Funnel Metrics)

TripPrint의 성장 단계를 5대 퍼널로 분해하여 측정 및 관리합니다.

| 퍼널 단계                  | 핵심 관리 지표 (KPI)                                                                         | MVP 목표치                                      | 측정 주기 및 데이터 소스                |
| :------------------------- | :------------------------------------------------------------------------------------------- | :---------------------------------------------- | :-------------------------------------- |
| **1. 획득 (Acquisition)**  | • 신규 여행 생성 수<br>• 게스트 초대 링크 유입률<br>• **바이럴 계수 (K-Factor)**             | • 주당 5,000건<br>• 65% 이상<br>• **1.25 이상** | 매일 / Supabase `trips`, `trip_invites` |
| **2. 활성화 (Activation)** | • 3단계 온보딩 완료율<br>• 첫 일정 등록 완료 시간<br>• 게스트의 회원 전환율                  | • 85% 이상<br>• 3분 이내<br>• 40% 이상          | 매주 / 클라이언트 이벤트 로그           |
| **3. 유지 (Retention)**    | • 여행 기간 중 일간 활성도(DAU)<br>• **D+7 재방문율**<br>• 동시성 충돌 데이터 유실률         | • 75% 이상<br>• **35% 이상**<br>• **0.00%**     | 매월 / TanStack Query 캐시 & 서버 로그  |
| **4. 수익 (Revenue)**      | • 커머스 제휴 링크 클릭률(CTR)<br>• **D2C 포토북 주문 전환율**<br>• 사용자당 평균 매출(ARPU) | • 12% 이상<br>• **25% 이상**<br>• 15,000원 이상 | 매월 / 결제 및 제휴 API 정산 내역       |
| **5. 추천 (Referral)**     | • 발자국 다이어리 SNS 공유율<br>• 동행자의 차기 여행 방장 전환율                             | • 45% 이상<br>• 30% 이상                        | 분기별 / 공유 링크 `share_links` 트래킹 |

## 5. 지표 모니터링 거버넌스 및 대시보드 운영 원칙

1. **단일 진실 공급원 (Single Source of Truth, SSOT)**:
   - 프로덕션 DB(Supabase)와 클라이언트 이벤트 로그를 Redash/Metabase 중앙 BI 대시보드에 실시간 집계.
2. **주간 북극성 리뷰 (Weekly North Star Review)**:
   - 매주 월요일 전사 스프린트 미팅에서 WCFT 지표와 4대 드라이버 지표의 변동 원인을 점검하고, 저조한 단계에 즉각 그로스 실험(A/B Test) 배정.
3. **가드레일 지표 (Guardrail Metric) 준수**:
   - 수익화(BM)를 추진하되, 사용자 만족도(NPS > 60점) 및 동시성 데이터 유실률(0.00%)이 훼손될 경우 즉시 해당 기능 롤백.
