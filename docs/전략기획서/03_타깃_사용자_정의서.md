## 1. 타깃 고객 세분화 (Customer Segmentation)

TripPrint의 핵심 고객군은 자유 여행(FIT)을 즐기는 2030 밀레니얼·Z세대로, 행동 패턴과 주요 결핍(Needs)에 따라 3대 핵심 세그먼트로 구분됩니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                      TripPrint 3대 핵심 사용자 세그먼트                │
├─────────────────────┬──────────────────────────┬───────────────────────┤
│ [Segment 1]         │ [Segment 2]              │ [Segment 3]           │
│ 효율 추구 계획파     │ 감성 아카이빙 기록파     │ 소규모 동행 정산파    │
│ (The Efficient      │ (The Aesthetic           │ (The Social           │
│  Trip Architect)    │  Life Chronicler)        │  Split-Settler)       │
├─────────────────────┼──────────────────────────┼───────────────────────┤
│ • 꼼꼼한 사전 계획   │ • 사진/후기 소셜 기록   │ • 친구/연인과의 동행   │
│ • 동선 최적화 추구  │ • 실물 굿즈/소장 욕구    │ • 정산 스트레스 해소   │
│ • 일정 방장(Owner)  │ • 비주얼 다이어리 중시   │ • 가입 없는 참여 희망  │
└─────────────────────┴──────────────────────────┴───────────────────────┘
```

1. **Segment 1. 효율 추구 계획파 (The Efficient Trip Architect)**:
   - 비중: 전체의 약 35%
   - 특성: 모임의 '총무' 또는 '일정 설계자' 역할을 자처함. 엑셀이나 노션으로 일정을 짜던 꼼꼼한 성향으로, 동선 낭비와 시간 지연을 극도로 싫어함.
2. **Segment 2. 감성 아카이빙 기록파 (The Aesthetic Life Chronicler)**:
   - 비중: 전체의 약 40%
   - 특성: 여행지에서의 사진, 영수증, 티켓 스크랩을 즐기며, 다녀온 여행을 인스타그램이나 블로그에 정리하는 것을 좋아함. 디지털 화면을 넘어 실물 포토북으로 간직하고 싶어 함.
3. **Segment 3. 소규모 동행 정산파 (The Social Split-Settler)**:
   - 비중: 전체의 약 25% (그러나 바이럴 전파의 핵심 매개체)
   - 특성: 친구가 짠 일정에 숟가락만 얹고 싶어 하는 수동적 참여자이나, 여행 중 지출 분담(1/N)과 환율 계산 갈등에는 매우 민감함. 복잡한 가입을 질색함.

## 2. 핵심 페르소나 정의 (Core Personas)

### 2.1 Persona A. '일정 마스터 방장' 김민지 (28세, IT 스타트업 마케터)

```
[ Persona A: 김민지 ]
"내가 고생해서 짠 완벽한 일정표, 친구들이 한눈에 보고 감탄했으면 좋겠어요.
 엑셀이랑 구글맵 왔다 갔다 하느라 출발 전부터 지치는 건 이제 그만하고 싶어요."
```

- **인구통계**: 여성, 28세, 서울 거주, 미혼. 연 2~3회 해외 자유여행.
- **디지털 숙련도**: 최상 (노션, 슬랙, 인스타그램 헤비 유저).
- **Pain Points**:
  - 노션으로 3박 4일 일정을 짰는데, 모바일로 보니 표가 다 깨지고 친구들이 잘 보지도 않음.
  - 비행기 도착 시간과 호텔 체크인 시간, 공항철도 배차 시간을 일일이 계산하느라 반나절 소요.
  - 여행 중 일정이 바뀌면 모든 일정을 수동으로 다시 시간 밀기를 해야 하는 번거로움.
- **Jobs to be Done (JTBD)**:
  - "도시와 날짜, 비행기 편명만 넣으면 1분 만에 동선과 시차가 정리된 예쁜 모바일 일정표를 만들고 싶다."
  - "친구들에게 가입하라고 강요하지 않고 링크 하나로 쉽게 일정을 공유하고 싶다."

---

### 2.2 Persona B. '감성 기록 콜렉터' 이준혁 (24세, 시각디자인 전공 대학생)

```
[ Persona B: 이준혁 ]
"여행 다녀오면 폰에 사진만 3,000장 쌓여있고 끝나요.
 내가 어느 날 몇 시에 그 골목 카페에서 어떤 커피를 마셨는지, 영수증과 함께 예쁜 책으로 남기고 싶어요."
```

- **인구통계**: 남성, 24세, 대학생, 휴학 중 배낭여행 준비.
- **디지털 숙련도**: 상 (핀터레스트, 라이트룸, 숏폼 콘텐츠 크리에이터).
- **Pain Points**:
  - 여행지에서 찍은 사진이 날짜별·장소별로 매핑되지 않아 나중에 추억을 정리하기가 너무 힘듦.
  - 감성적인 여행 일기장을 만들고 싶지만 포토샵이나 인디자인으로 책을 만들자니 시간이 너무 많이 듦.
  - 기존 여행 앱들은 온통 광고 배너뿐이라 감성적인 소장 가치가 전혀 없음.
- **Jobs to be Done (JTBD)**:
  - "여행하면서 찍은 사진과 방문 인증(체크인)이 자동으로 타임라인에 차곡차곡 쌓였으면 좋겠다."
  - "여행이 끝났을 때 1초 만에 나만의 감성 발자국 다이어리가 완성되고, 터치 한 번으로 실물 포토북으로 배송받고 싶다."

---

### 2.3 Persona C. '귀차니즘 동행자' 박서연 (27세, 외국계 기업 어카운트 매니저)

```
[ Persona C: 박서연 ]
"친구들이 가자고 해서 따라가는데, 앱 깔고 가입하라고 하면 솔직히 귀찮아요.
 그냥 링크 눌러서 지금 어디 가는지 보고, 내가 낸 영수증만 딱 올려서 칼같이 정산하고 싶어요."
```

- **인구통계**: 여성, 27세, 직장인, 주말 활용 단기 해외여행(도쿄, 방콕 등) 선호.
- **디지털 숙련도**: 중상 (카카오톡, 토스, 인스타그램 중심 사용).
- **Pain Points**:
  - 친구가 보낸 여행 계획을 보려는데 앱 설치하고 소셜 로그인까지 해야 해서 이탈하고 싶음.
  - 엔화, 달러 섞여서 누가 밥값을 냈고 누가 택시비를 냈는지 여행 마지막 날에 계산하다가 의 상할 뻔함.
  - 종이 영수증 잃어버려서 얼마 썼는지 기억이 안 나 정산이 흐지부지됨.
- **Jobs to be Done (JTBD)**:
  - "회원가입 없이 링크 하나 누르면 바로 일정과 지도 동선을 보고 싶다."
  - "영수증 사진만 찍으면 알아서 엔화가 원화로 계산되어 내 분담금이 얼마인지 투명하게 나왔으면 좋겠다."

## 3. 엔드투엔드 고객 여정 지도 (Customer Journey Map)

TripPrint는 여행 전(Pre-Trip)부터 여행 중(In-Trip), 여행 후(Post-Trip)에 이르기까지 끊김 없는 가치를 제공합니다.

| 여정 단계                    | 사용자 행동 (Actions)             | 감정 상태 (Emotion)                  | 사용 기능 및 솔루션                   | 기회 요소 및 와우 포인트 (Wow Moments)                                            |
| :--------------------------- | :-------------------------------- | :----------------------------------- | :------------------------------------ | :-------------------------------------------------------------------------------- |
| **1. 계획 착수 (Pre-Trip)**  | 도시 선택, 날짜 지정, 항공편 입력 | 설렘, 그러나 세팅 부담감 (😕)        | **1분 여행 생성기 & 하루(Haru) 코치** | 비행기 편명 넣자마자 DAY 1 공항철도와 체크인 일정이 자동 배치되는 순간 (😍)       |
| **2. 동행 초대 (Pre-Trip)**  | 카톡으로 초대 링크 공유           | 혹시 귀찮아할까 불안 (😐)            | **무가입 게스트 모드 & 초대 링크**    | 친구가 가입 없이 링크 누르자마자 1초 만에 같은 일정표에 들어와 있는 경험 (🚀)     |
| **3. 현장 이동 (In-Trip)**   | 도쿄 시내 이동, 카페 방문         | 바쁨, 길 잃을까 걱정 (😰)            | **WGS84 GPS 지오펜싱 & 라이브 동선**  | 다음 장소까지의 도보 5분 거리 안내와 200m 반경 자동 체크인 스탬프 획득 (📍)       |
| **4. 지출 정산 (In-Trip)**   | 식당에서 식사 후 결제             | 정산 번거로움, 영수증 분실 우려 (😫) | **비전 AI 영수증 OCR & 정밀 가계부**  | 영수증 찍자마자 엔화와 상호가 인식되고 1초 만에 1/N 정산 리포트 완성 (⚡)         |
| **5. 추억 기록 (Post-Trip)** | 귀국 후 사진 정리                 | 여행 끝난 아쉬움, 귀차니즘 (😢)      | **발자국 다이어리 자동 전환**         | 귀국 즉시 계획표가 아름다운 사진 다이어리로 변해있고, 1클릭 포토북 인쇄 연동 (✨) |

## 4. 바이럴 유입 루프 (Viral Growth Loop) 메커니즘

TripPrint는 막대한 유료 광고비 없이도 유저가 유저를 데려오는 **자연 발생적 오가닉 성장 루프(K-Factor > 1.2)**를 제품 내에 내재화했습니다.

```
[ TripPrint 바이럴 오가닉 성장 루프 ]
┌────────────────────────────────────────────────────────────────────────┐
│  ① 여행 생성자(Persona A)가 TripPrint에서 '3박 4일 도쿄 여행' 생성    │
│                               ▼                                        │
│  ② 카카오톡으로 동행자(Persona B, C) 2.5명에게 무가입 초대 링크 발송   │
│                               ▼                                        │
│  ③ 동행자들은 로그인 허들 없이 즉시 접속하여 일정 조회 및 가계부 사용  │
│                               ▼                                        │
│  ④ 여행 중 영수증 등록, 사진 업로드, 발자국 다이어리 생성 경험 매료     │
│                               ▼                                        │
│  ⑤ 귀국 후 다음 여행에서 이번엔 동행자(B, C)가 새로운 방장이 되어    │
│     새로운 다른 친구 그룹을 TripPrint로 초대 (루프의 무한 반복)         │
└────────────────────────────────────────────────────────────────────────┘
```

- **Zero-Friction 유입**: 초대 링크 진입 시 앱 설치나 로그인을 강제하지 않는 '게스트 모드'를 통해 온보딩 이탈률을 15% 미만으로 극소화.
- **소셜 프루프(Social Proof)**: 인스타그램 스토리 공유에 최적화된 감성 발자국 타임라인 이미지 1클릭 내보내기 지원으로 자연스러운 SNS 바이럴 전파.
