# 서버·웹 배포 절차

이 문서는 백엔드 API(`apps/api`)와 웹 클라이언트(`apps/mobile` 웹 빌드)의 배포 및 사전 검증 절차를 정의합니다.

---

## 1. 배포 전 필수 검증

배포 실행 전 아래 명령이 모두 오류 없이 통과해야 합니다.

1. `npm run check`: 디자인 토큰 대비, 문서 링크, 리소스, 아키텍처·네비게이션 경계, 타입, 린트, 포맷 검사
2. `npm run test:foundation` 및 `npm run test:auth`: API 계약 및 인증·저장 회귀 테스트
3. `npm run release:check`: 배포 환경 설정 및 소스 매니페스트 무결성 검사

---

## 2. 배포 순서

1. **D1 마이그레이션 반영**:
   - 신규 SQL 마이그레이션(`apps/api/migrations/*.sql`)이 있는 경우 먼저 로컬 SQLite에서 검증한 뒤 대상 환경 D1에 적용합니다.
2. **백엔드 Worker 배포 (`apps/api`)**:
   - `wrangler.jsonc` 설정을 기준으로 Cloudflare Workers를 배포하고 `/api/startup` 응답 상태를 확인합니다.
3. **웹 정적 빌드 및 배포 (`apps/mobile`)**:
   - `npm run mobile:build:web`으로 웹 정적 산출물을 생성하고 Cloudflare Pages에 배포한 뒤 `/release.json` 버전 정보를 확인합니다.
