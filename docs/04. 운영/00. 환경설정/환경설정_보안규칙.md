# 환경 설정 및 보안 규칙

이 문서는 로컬 개발 환경과 운영(Cloudflare Workers·Pages·GitHub Actions) 환경의 설정 분리 및 비밀정보 보호 규칙을 정의합니다.

---

## 1. 비밀정보 및 환경 변수 원칙

1. **저장소 커밋 금지**:
   - API 키, OAuth 클라이언트 시크릿, 세션 서명 시크릿, Android 키스토어(`.jks`/`.keystore`), 로컬 비밀 폴더(`docs/98. keys/`)는 Git 및 EAS 빌드 아카이브에 절대 포함하지 않습니다.
2. **클라이언트·서버 변수 분리**:
   - 모바일·웹 클라이언트에 노출 가능한 공개 설정만 `EXPO_PUBLIC_*` 접두사를 사용합니다.
   - Google Places, 항공편 조회, OCR 분석, 소셜 OAuth 시크릿은 모두 백엔드(`apps/api`) Worker Secret에만 등록하고 클라이언트는 서버 프록시 API를 호출합니다.
3. **로그 및 오류 메시지 보호**:
   - 서버 로그와 클라이언트 화면 오류 메시지에 세션 토큰, 비밀번호 해시, SQL 원문, 개인 식별 정보를 출력하지 않습니다.
