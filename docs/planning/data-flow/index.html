01. 회원 여행의 저장·재조회·공유

파란 화살표는 입력·저장 요청, 초록은 저장 결과·재조회, 보라는 명시적 공개 요청입니다. 작은 화면에서는 흐름도를 가로로 이동해 볼 수 있습니다.

02. 게스트·저장소·외부 서비스 경계

게스트 여행

사용자 → 앱 검증 → 기기 저장 → 기기 재조회

Android: 앱 문서 폴더의 tripprint-guest-<UUID>.json
웹: 계정별 localStorage 키

서버 여행 DB에 저장됐다고 표시하지 않습니다. 회원 로그인만으로 자동 이전되지 않습니다. 장소 검색 등 별도 기능에는 서버 요청이 있을 수 있습니다.

회원 여행 원본

trips.snapshot JSON에 여행·DAY·일정·항공편을 묶어 저장합니다. trip_members가 접근 권한, mutation_requests가 중복 요청을 관리합니다.

앱 폼은 입력 초안이고 조회 캐시는 화면용 사본입니다. 저장 성공은 서버 응답으로 확인합니다.

지도·장소·항공편

장소 검색·사진: 앱 → 서버 → Google Places → 서버 → 앱. 서버 키는 앱에 보내지 않습니다. Android 지도 SDK 키는 별도 클라이언트 설정입니다.

항공편 조회는 입력을 돕습니다. 조회에 실패해도 직접 입력할 수 있습니다.

사진·영수증

원본 파일은 R2, 연결 정보는 서버 데이터로 관리합니다. 여행계획 원본 저장·커뮤니티 공개와 파일 원본 공개는 같은 작업이 아닙니다.

파일 업로드·OCR는 이번 V11 여행 생성·DAY 편집 검증 범위에 포함하지 않았습니다.

03. 실패했을 때의 데이터 흐름

상황 클라이언트 서버·저장소
저장 응답 유실 입력·요청 키를 유지하고 같은 요청 재시도 같은 입력·키면 기존 결과 반환. 중복 저장 방지
버전 충돌 · 409 작성 내용 보존 → 최신본 조회 → 확인 후 다시 저장 현재 버전과 다르면 갱신 거절
입력 오류 · 422 입력 보존 → 오류 수정 → 새 요청 잘못된 입력을 저장하지 않음
저장 성공 후 조회 실패 조회만 재시도 이미 확정된 저장을 반복하지 않음
세션 만료 / 계정 변경 재인증·목적 화면 복귀 / 이전 계정의 늦은 결과 무시 실제 로그인 계정으로 권한 재검사

04. 확인한 범위

기존 V11 검수: 실제 브라우저 → 로컬 Worker → D1 저장·재조회·재로그인 통과. 로컬 DB 원문 대조 완료. staging 회원 API 저장·재로그인·재조회 34개 요청 성공.

원격 DB SQL 직접 대조는 접근 권한 오류 7403으로 미확인입니다. Google 실제 로그인·Android 기기 인수는 내부 테스트 대상입니다. 이번 문서 작성 중 신규 등록·공유·배포·Android 빌드는 실행하지 않았습니다.
