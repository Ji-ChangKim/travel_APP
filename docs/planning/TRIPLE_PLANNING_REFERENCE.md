# 여행 생성·편집·공유의 트리플 참조 기준

작성일: 2026-10-21

사용자 지시에 따라 여행 생성·편집·공유의 기능과 동선은 트리플을 우선 참조한다. TripPrint의 공통 헤더·GNB·로고·토큰은 기존 문서를 유지한다. 참조 서비스의 구매·결제·쿠폰을 여행계획 등록 기능에 넣거나, 지원하지 않는 기능을 화면에 표시하지 않는다.

## 조사 근거

- [트리플 공식 일정 사용법](https://triple.guide/articles/48574b88-6705-458e-a288-a864ab1e0641): 장소·예약과 지도 동선을 중심으로 계획을 구성하고, 다른 사람의 코스를 담는 흐름을 확인했다. 게시 표기는 2017.01이며 현재 설치본의 모든 화면을 검수한 자료는 아니다.
- [트리플 공식 활용 안내](https://triple.guide/articles/8e26647d-9e7b-4346-8517-4945ced97bb8): 공동 편집 초대와 일정 열람 링크의 목적을 구분한다. 게시 표기는 2023.01이다.
- [Google Play 공식 등록 정보](https://play.google.com/store/apps/details?hl=ko&id=com.titicacacorp.triple): 현재 소개된 일정·지도·여행 정보 기능을 교차 확인했다. 설명과 실제 설치본의 세부 배치가 같다고 가정하지 않는다.

위 자료는 기능과 동선의 근거다. 공식 이미지 일부는 조회되지 않았으므로 최신 Android 화면을 전수 대조했다고 보고하지 않는다. 일정 복사·DAY 일괄 선택은 TripPrint에서 확인한 사용 불편을 해결하는 보완이며, 트리플의 현재 버튼명이나 위치와 같다고 주장하지 않는다.

## 이번에 실제 변경한 기능

일정 관리에 복사를 추가했다. 기존 저장 명령을 재사용하며, 원본 일정과 새 일정의 ID가 달라 기존 사진·실제 지출·영수증 관계가 새 일정으로 이동하지 않는다. 일반 일정의 방문 시간은 비워 다시 정하도록 하고 항공편은 연결된 출발 시각을 유지한다. 장소 설명·위치·체류시간·예상 비용은 확인 가능한 초안에 이어받는다. 복사 초안 취소에는 기존 이탈 보호를 적용한다.

수정 화면의 공통 제목은 ‘일정 수정’, 복사 화면은 ‘일정 복사’로 구분한다. 공통 제목 크기·폰트·정렬·뒤로가기 규격을 페이지에서 덮어쓰지 않는다.

공개 항목 선택에 DAY별 전체 선택·해제를 추가했다. 다른 날짜의 선택, 사진 공개, 비용 공개는 바꾸지 않는다. 삭제된 선택을 조용히 제거하지 않아 기존 검증에서 다시 확인하도록 한다.

공개본에 외부 링크 전달 행동을 추가했다. 초대 토큰·세션·인증 콜백의 쿼리와 fragment를 전달하지 않는다. 기기 공유를 취소하거나 실패해도 이미 저장한 공개본은 바꾸지 않는다. 웹 공유 기능이 없는 브라우저에서는 클립보드에 쓰기가 성공한 경우에만 복사 안내를 표시한다.

## 참조 서비스와 남은 차이

새 타임라인과 미리보기는 같은 표시 컴포넌트와 첨부 영역을 사용한다. 장소 설명·팁은 기존 상세 보기로, 사진은 공개 전 회원 권한·공개 후 공개 사진 경로로 읽는다. 선택한 통화별 합계도 양쪽에 같은 데이터로 표시하며, 공개 상세의 여행 제목은 공통 헤더에 한 번만 둔다.

일정 수로 만들어 내던 거리·소요시간, 저장하지 않은 체크인 완료·여행자 검증·권장 시각·추천 팁을 제거했다. 지도처럼 보이던 빈 박스는 저장 순서 안내로 바꿨다. 연결되지 않은 빠른 추가·인쇄 버튼은 표시하지 않으며, 공개 화면의 담기는 기존 입력·저장 시트로 연결했다.

2026-10-21 후속 구현에서는 대표 여행지와 함께 최대20개 도시·시간대를 관리한다. 생성에서 도시를 추가하거나 여행 더보기에서 DAY별 도시를 배정한다. 기존 단일 도시 여행은 자동 변환 없이 읽으며 DAY·항공권·일정 ID를 보존한다. 공개 선택 도시와 담은 여행의 새 ID 연결도 같은 계약으로 처리한다.

AI 장소 추천은 저장된 DAY의 도시와 사용자의 관심사·여행 속도로 검색 방향을 정한 뒤 실제 Google Places 결과를 제시한다. Google 공급자 콘텐츠를 AI에 보내지 않고, 모델이 지어낸 장소를 일정으로 저장하지 않는다. 사용자가 고른 뒤 기존 일정 작성에서 확인·저장한다. 영업시간·가격·체류·이동시간을 AI가 보장하는 기능은 아니다.

이동수단 WALK/DRIVE/TRANSIT는 연속한 일정 구간에 저장한다. 실제 시간·거리는 고정 Google Routes API에서 조회하고 공급자 정책에 따라 DB·공개 사본에 영구 저장하지 않는다. 공개 전 미리보기와 공개 상세는 같은 조회 컴포넌트를 사용한다. 공개 경로는 양쪽이 Google 장소로 연결된 구간만 지원하며, 사용자가 고른 개인 좌표를 새 공개 필드로 추가하지 않는다. 순서가 바뀐 이전 구간은 제거한다. 드래그 정렬은 추가하지 않았으며 기존 접근성 버튼을 유지한다.

참고한 공급자 문서: [Google Routes 정책](https://developers.google.com/maps/documentation/routes/policies), [Places 정책](https://developers.google.com/maps/documentation/places/web-service/policies), [Text Search 유형 필터](https://developers.google.com/maps/documentation/places/web-service/text-search), [Workers AI JSON 모드](https://developers.cloudflare.com/workers-ai/features/json-mode/). 고정 월 상한은 비용 제한이며 무료 사용을 보장하지 않는다.
