## 공통 행동

주요 버튼은 높이 52px, 일반 버튼·입력은 48px, 최소 터치 영역은 44px이다. 버튼·입력 모서리는 12px, 카드 16px, 여행 표지 20px을 기준으로 한다. 모바일 화면 좌우 여백은 20px이다.

DesignButton은 실제 눌림 상태를 배경·글자·아이콘에 함께 전달한다. 로딩은 기존 버튼의 읽기 대비를 유지하고, 중복 실행은 disabled와 busy 속성으로 막는다. 초점은 네이비 선으로 표시한다.

## 행동과 탐색 위계 · 2026-10-16

코랄 주요 버튼은 한 화면에 하나 이하로 둔다. 홈에 이어갈 여행이 있으면 여행 보기가 주요 행동이며 새 여행 만들기는 보조 행동이다. 내 여행 목록에서는 새 여행 만들기가 주요 행동이고 카드 열기는 작은 보조 링크다. 목적지가 있는 화면의 보조 탐색을 주요 버튼과 같은 크기·색으로 반복하지 않는다.

여행 상세는 일정·지도·비용·더보기 네 항목을 한 줄에 고정한다. 가로로 밀어야 보이는 작업 탭을 사용하지 않는다. 사진·영수증, 준비물, 동행, 발자국 공유는 더보기 메뉴에서 연다. 동행 바로가기와 인원 소개를 중복해서 배치하지 않는다. 역할·공개 관리의 기존 권한은 유지한다.

일정 추가는 일정 콘텐츠 안에 있는 주요 행동 하나다. 별도 고정 도구 바를 글로벌 내비게이션 위에 겹치지 않는다. 지도는 상단 영역 선택으로, 영수증 촬영·앨범은 사진·영수증 영역으로 접근한다. 화면이 실제 일정에 제공하는 높이를 브라우저에서 측정한다.

ScreenHeader는 최소 56px, 뒤로가기 터치 영역 44px, 같은 24px 화살표, 제목 18/26px을 사용한다. 이동 목적은 접근성 이름으로 전달하고 보이는 뒤로가기 문구는 반복하지 않는다. 목록·상세·여행 생성·항공권 입력에 같은 규격을 적용하며 큰 글꼴은 제목을 별도 줄에 표시한다.

여행 기간은 travelDateRange 함수와 format.dateRangeSeparator 토큰을 사용해 YYYY-MM-DD – YYYY-MM-DD로 통일한다. 저장한 날짜와 시간대는 바꾸지 않는다. 홈·목록·발자국·다이어리·커뮤니티·공개 미리보기도 같은 구분 기호를 사용한다.

필터와 여행 스타일은 최소 높이 44px의 chip 변형을 사용한다. 선택은 옅은 코랄·네이비 테두리·체크와 selected 속성으로 전달한다. 아이콘 버튼과 달력 날짜도 같은 초점·눌림·비활성 규칙을 따른다. 달력의 양 끝은 테두리와 selected 속성으로 표시하고 기간 안쪽은 연한 배경으로 이어준다.

기존 화면의 colors.primary·accent는 네이비와 흰 글자 조합을 보존하는 호환 이름이다. 새 주요 행동은 colors.actionPrimary·actionForeground를 사용한다. 일정 테마는 같은 JSON의 action 전경을 읽는다. 작은 링크에 actionPrimary를 쓰지 않는다.

## 세 화면 적용

홈은 실제 여행 사진이나 노트 표지, 여행명·기간·계속하기 행동으로 구성한다. 첫 여행은 원본 하루와 코랄 버튼으로 시작한다. 긴 제목을 작은 글자로 축소하지 않는다.

공동 일정은 실제 멤버 수, DAY 체크, 네이비 시간, 장소 카드, 진한 링크로 구성한다. 큰 글꼴에서는 시간과 카드가 위아래로 배치되어 좁은 열에 글자가 끼지 않는다. 동행 관리는 더보기에서 연다.

발자국은 완료 여행만 표시한다. 일반 사진을 표지로 사용하고 영수증은 제외한다. 원본 기록은 나와 동행자가 읽는다는 기존 권한을 안내한다. 커뮤니티에는 사용자가 직접 고른 내용만 공개하는 기존 흐름을 유지한다.

하단 메뉴는 홈·내 여행·발자국·커뮤니티·MY다. 새 여행은 홈과 내 여행의 생성 버튼에서 시작한다. 일정 작성 중 메뉴를 옮길 때 기존 이탈 확인을 유지한다.

## 추가 네 화면 적용

여행 만들기는 두 단계의 현재 위치를 안내하고 첫 단계에 원본 하루를 작게 배치한다. 제목·여행지·달력은 흰 카드로 묶는다. 항공편 선택과 입력의 뒤로가기·완료·조회도 공통 버튼을 사용한다. 웹 날짜 입력은 Pretendard와 사용자 글자 배율을 적용하며 모바일 시스템 날짜 선택기는 운영체제의 표시 설정을 따른다.

내 여행 목록은 실제 상태별 건수와 검색 결과를 구분한다. 새 여행 만들기를 주요 행동으로 두고 카드 열기는 보조 링크로 표시한다. 목록의 검색 입력은 공통 글꼴·초점 테두리를 사용한다. 목록 응답에 없는 사진·동행 인원을 만들지 않는다.

커뮤니티는 공개된 사진·작성자·날짜·여행 정보·본문·일정 순서로 구성한다. 사진 위에 작은 글자를 겹치지 않는다. 사진 조회·다운로드 실패에는 다시 불러오기를 제공하고 공개 권한 검사에 실패한 주소를 계속 표시하지 않는다. 신고·차단·추가 읽기도 공통 상태를 사용한다.

MY는 프로필 카드·실제 여행 통계·앱 정보로 구성한다. 닉네임과 설명은 줄바꿈하고, 여행 스타일은 체크가 있는 선택 칩으로 표시한다. 프로필 수정·닫기·저장·로그아웃은 같은 버튼 체계를 따른다. 저장 중 입력 잠금과 작성 내용 이탈 확인은 기존 흐름을 유지한다.

## 여행 상세 네 영역 적용

지도는 22px 영역 제목·18px 장소명·14px 주소와 안내로 구성한다. 긴 장소명을 줄바꿈하고 방문 번호·선택 상태·위치 수정 행동을 구분한다. 웹의 상대 위치 도식은 번호의 축소 비율과 사용자 글자 배율을 함께 반영한다. 모바일 지도 핀은 일반 코랄/네이비, 선택 네이비/흰색을 사용한다. 연결선은 실제 도로 경로를 뜻하지 않는다는 안내와 기존 외부 지도 열기를 유지한다.

비용은 실제 지출과 예상 비용을 각각 흰 카드에 표시하고 KRW·JPY·USD를 따로 합산한다. 소수 금액은 정수 센트로 계산하고 1센트와 0도 소수 두 자리로 표시한다. 항목은 비용 구분·출처·제목·통화와 금액·연결한 일정으로 나눈다. 입력의 통화·실제/예상·일정 연결은 공통 선택 상태를 사용한다.

체크리스트는 준비한 개수와 전체 개수, 완료 막대를 표시한다. 각 준비물은 공통 버튼의 checkbox 변형으로 checked 속성과 체크를 함께 제공한다. 저장이 확정되기 전에 임의로 완료 처리하지 않는다. 동행자는 닉네임 첫 글자·실제 역할·나 표시를 사용하고 역할 변경과 참여 해제는 기존 권한에 따라 제공한다. 초대 내역의 역할·만료일·상태는 14px 이상으로 표시한다.

빈 지도·비용·준비물에는 원본 하루와 다음 행동을 안내한다. 보기 전용 여행에는 입력할 수 있다고 안내하지 않는다. 고정 네 메뉴·날짜 선택·상세 설정·더보기는 같은 선택·초점·눌림 토큰을 따른다. 저장 중에는 실제 입력과 관리 행동을 잠그고 처리 안내를 표시한다.

## 검증과 범위

토큰의 contrastChecks는 지정 전경·배경의 sRGB 계산이다. 일반 글자 4.5:1, 식별 경계 3:1을 기준으로 반올림 전 값을 비교한다. 브라우저 검수는 표시된 단색 배경 글자의 실제 색·크기·불투명도를 읽고 360·390·430px 및 큰 글꼴을 확인한다.

사진·그래디언트와 기기별 렌더링까지 포함한 전체 앱 접근성 인증을 뜻하지 않는다. 인증·저장·공개 선택의 API·DB 계약은 바꾸지 않는다.
