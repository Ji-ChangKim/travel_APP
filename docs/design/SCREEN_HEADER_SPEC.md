# TripPrint 화면 헤더 규격

적용일: 2026-10-16. 이 문서는 이전 시안과 헤더 설명보다 우선한다. 수치는 앱의 논리 단위이며 상태 표시줄과 기기 안전 영역을 포함하지 않는다.

## 기본 규격

| 요소             | 규격                                                 |
| ---------------- | ---------------------------------------------------- |
| 화면 제목        | Pretendard Bold, 26/36, 굵기 700, 네이비, 왼쪽 정렬  |
| 이동 상단바      | 기본 최소 높이 56, 위아래 여백 6                     |
| 화면 좌우 여백   | 20, 본문과 동일한 기준선                             |
| 넓은 화면        | 헤더와 본문 최대 너비 640, 묶음만 가운데 배치        |
| 뒤로가기         | 왼쪽 `arrow-back` 24, 터치 영역 최소 44 × 44         |
| 우측 아이콘      | 24, 터치 영역 최소 44 × 44                           |
| 우측 텍스트 행동 | `size="header"`, 16/24, 최소 높이 44, 안쪽 여백 8    |
| 제목과 이동 바   | 별도 역할, 제목을 상단바의 작은 글자로 대체하지 않음 |

버튼은 기본·눌림·비활성·키보드 초점 상태를 공통 `DesignButton`으로 표시한다. 뒤로가기와 헤더 행동은 네이비를 사용하며 초점 테두리는 2다. 작은 글자와 비활성 글자도 배경과 4.5:1 이상의 대비를 유지한다.

## 화면별 배치

최상위 화면인 내 여행·발자국·커뮤니티·MY는 뒤로가기 없이 제목을 왼쪽에 둔다. 필요한 우측 행동만 같은 행에 둔다. 내 여행의 새 여행 만들기는 우측 `+` 아이콘이다. 홈은 기존 TripPrint 심볼과 워드마크를 유지하며 같은 56 높이와 좌우 20 기준선을 따른다. 브랜드 로고는 화면 제목의 글꼴 규격과 구분한다.

여행 만들기·항공권 입력·일정 작성·나라/도시 선택·여행지 가이드·다이어리·초대·장소 가져오기·이전 기록·인증 입력은 이동 바 아래에 26/36 제목을 둔다. 기본 간격은 이동 바 아래 8, 제목 아래 4다. 제목 아래 본문 여백은 20이다. 여행 상세는 이동 바에 뒤로가기와 더보기만 두고 실제 여행명을 본문 첫 제목으로 표시한다. `여행 상세`를 작은 제목으로 중복하지 않는다.

프로필 편집과 바텀시트의 제목도 `ScreenTitle`을 사용한다. 시트 안쪽에 이미 20 여백이 있으면 `ScreenHeader inset={false}`로 중복 여백을 막는다. 시트의 제목과 내용은 사용자가 끝까지 스크롤할 수 있어야 한다. 본문 섹션·카드·달력의 제목은 화면 제목과 별도 위계이므로 26으로 일괄 확대하지 않는다.

## 큰 글자와 긴 제목

기본 이동 바 높이는 56이지만 확대된 텍스트 행동이 더 많은 높이를 요구하면 자연스럽게 늘어난다. 고정 높이로 글자를 자르지 않는다. 아이콘만 있는 이동 바는 확대 설정에서도 56을 유지한다.

제목은 사용자의 글자 배율을 그대로 따른다. 200%에서는 52/72다. `numberOfLines`, 말줄임, `adjustsFontSizeToFit`, 최대 배율 제한, 고정 제목 높이를 사용하지 않는다. 실제 가용 너비에서만 줄바꿈하고 전체 제목을 왼쪽 정렬로 읽게 한다. 글자 확대 여부만 보고 제목을 다른 행으로 이동하거나 빈 컨트롤 행을 만들지 않는다. 우측 액션과 제목이 겹치지 않도록 제목은 줄바꿈하고 액션은 최소 터치 영역을 유지한다.

상태 표시줄 안전 영역은 최상위 `SafeAreaView`에서 한 번 처리한다. 헤더에 기기 상단 높이를 다시 더하지 않는다. 헤더 뒤 본문은 `ScrollView`로 이동할 수 있어야 한다.

## 구현과 변경 절차

- 화면 제목은 `apps/mobile/src/components/ScreenTitle.tsx`를 사용한다.
- 이동 바와 최상위 헤더는 `apps/mobile/src/components/ScreenHeader.tsx`를 사용한다.
- 수치는 `docs/design/design-tokens.json`의 `navigation`·`layout`·`typography`를 따른다.
- 새 화면에서 뒤로가기용 일반 본문 버튼이나 별도 제목 스타일을 만들지 않는다.
- 헤더 수정 시 320·390·430 너비와 글자 100%·200%를 모두 확인한다. 짧은 제목과 긴 여행명을 포함한다.
- `npm run check`와 `npm run test:headers:web`를 통과시킨다. 제목 크기·행간·굵기·정렬, 빈 행, 실제 텍스트 잘림, 버튼 터치 영역, 대비를 함께 검사한다.
- 자동 검사 후 실제 캡처를 열어 제목 기준선과 본문 간격을 육안으로 확인한다. 검수 캡처와 실행 결과는 `docs/1.uiux/SCREENSHOT_INDEX.txt`에서 안내한다.

웹 검수는 브라우저에서 실제 앱 컴포넌트를 렌더링한 결과다. Android/iOS의 운영체제 글자 설정·노치·스크린리더 검증을 대신하지 않는다.
