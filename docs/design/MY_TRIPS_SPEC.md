## 동작·접근성

검색 아이콘은 실제 입력을 열고, 필터·정렬은 현재 계정의 목록만 선택한다. 일정 행동은 기존 일정/다이어리 경로, 비용은 `section=expenses`, 공개 관리는 확인 과정이 있는 기존 `section=share`로 이동한다. 새 여행은 기존 `/new-trip`, 개인 보관함은 `/my-footprints`다. 미지원 알림 점·가상 아바타·복제·삭제 기능은 만들지 않는다.

가로 필터의 보이는 높이는28을 유지하고 상하10씩 터치 영역을 넓힌다. 다른 행동은 최소48이며, 큰 글자와 긴 제목은 잘라내거나 축소하지 않는다. 빈 검색 결과는 등록 없음과 구분해 필터 초기화를 제공한다. 목록 오류에는 재시도·인증 복귀를 제공하고 이전 비공개 원본을 오류 뒤에 표시하지 않는다.

GNB는 기존 다섯 메뉴를 한 번만 표시하며 안전 영역과 상세 화면 숨김 규칙을 유지한다. 원본 대비 누락·변경 사항과 실제 캡처는 검수 보고서에 남긴다. 자동 검사 통과만으로 원본 시각 일치를 승인하지 않는다.
