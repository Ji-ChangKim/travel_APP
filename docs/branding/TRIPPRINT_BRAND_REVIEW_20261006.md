# TripPrint 브랜딩 검토 및 제작 기준안

2026-10-06. 사용자가 첨부한 컨셉 보드, 현재 앱 소스, 실제 배포 로그인 화면을 비교했다. 이번 작업은 브랜딩 검토이며 앱 이름·아이콘·배포 버전 변경과 광고 이미지 제작은 실행하지 않았다. 아래 규격은 향후 앱과 마케팅 작업에 함께 사용할 제안이다.

## 검토 결론

TripPrint(트립프린트)는 여행 계획이 사진·비용·기록을 거쳐 하나의 발자국으로 남는 서비스 흐름에 어울린다. 코랄·네이비·아이보리, 위치 핀과 여행 경로, 따뜻한 여행 사진을 함께 사용하는 방향을 유지할 만하다.

현재 상태는 **컨셉 방향 적합 / 실제 앱 브랜드 미통일 / 상업용 원본 자산 미완성**이다. 제공된 보드 자체를 모든 광고에 반복 사용하기보다, 로고·타이포·색상·사진·실제 앱 화면을 분리한 마스터 자산과 매체별 템플릿을 준비하는 편이 일관성을 유지하기 쉽다.

## 이름과 메시지

| 항목           | 권장 기준                              | 이유                                                     |
| -------------- | -------------------------------------- | -------------------------------------------------------- |
| 영문 표기      | `TripPrint`                            | T/P 대문자, 띄어쓰기 없이 고유명 표기 통일               |
| 한글 표기      | `트립프린트`                           | 앱·광고·스토어 검색에서 같은 이름 사용                   |
| 제품 설명      | `여행 계획·공유·기록 앱`               | Print가 사진 인화/출력 서비스로만 해석되는 것을 줄임     |
| 메인 슬로건    | `여행의 발자취를 남기다.`              | 기존 발자국 다이어리와 연결                              |
| 영문 슬로건    | `Leave your TripPrint.`                | 제공된 보드의 표현 유지                                  |
| 기능 설명 문장 | `함께 계획한 여행, 나만의 발자국으로.` | 여행 전 계획과 여행 후 기록을 함께 전달                  |
| 완료 기록 명칭 | `발자국`                               | TripPrint는 서비스명, 발자국은 완료 기록의 이름으로 구분 |

`Trip Print`, `TRIPPRINT`, `Tripprint`, `트립 프린트`를 화면마다 혼용하지 않는다. 검색/상표 검토에는 띄어쓰기·유사 발음도 함께 사용한다. 회사의 법적 명칭과 서비스 브랜드는 별도로 관리하며 확인되지 않은 `TripPrint Corp.` 같은 회사명을 만들지 않는다.

영문 Print는 출력/인화로 읽힐 수 있다. 따라서 광고 첫 화면에 풍경과 로고만 두는 경우에도 `여행 계획·공유·기록`이라는 설명이나 실제 다이어리 화면 중 하나는 함께 보여주는 것을 권한다.

### 이름 검색 상태

2026-10-06에 `TripPrint`, `트립프린트`, 여행 앱 관련 일반 웹 검색과 Google Play/Apple App Store 도메인 제한 검색을 진행했다. 반환된 검색 결과에서 동일 이름의 여행 앱을 명확하게 확인하지 못했다. 이는 검색 엔진에 노출된 결과만의 사전 조사이며 앱스토어 전체 목록, 국가별 상표 권리, 도메인 가용성 확인을 완료한 결과가 아니다.

상표 등록·사용 가능 여부는 이번 검토에서 확정하지 않았다. 이름을 대규모 광고에 고정하기 전 [KIPRIS](https://www.kipris.or.kr/)의 한글·영문·유사 표기 및 관련 상품/서비스 검색 결과를 남겨야 한다. 해외 범위는 [WIPO 검색 안내](https://www.wipo.int/en/web/madrid-system/check-availability)를 기준으로 별도 확인한다. WIPO는 동일 이름뿐 아니라 유사한 표장도 확인해야 한다고 안내한다.

도메인과 SNS 핸들의 실제 가용성/확보도 미확인이다. 이번 작업에서 등록이나 구매는 하지 않았다.

## 색상과 가독성

아래 값은 첨부 보드에 표기된 HEX를 기준으로 정리했다. 보드의 그라데이션이나 픽셀 샘플을 새로운 색상 기준으로 사용하지 않는다. 화면과 인쇄에서 동일한 HEX가 동일한 외관을 보장하지 않으므로 인쇄용 CMYK는 별도 교정한다.

| 역할                     | 색상      | 사용 기준안                                     |
| ------------------------ | --------- | ----------------------------------------------- |
| Trip Coral               | `#FF6B57` | 로고, 큰 장식, 여행 경로와 브랜드 포인트        |
| Journey Navy             | `#203247` | 본문·제목·숫자·핵심 아이콘                      |
| Warm Ivory               | `#FFF9F3` | 기본 앱 배경, 광고의 여백                       |
| Sky                      | `#8FD3E8` | 지도/이동 배경, 보조 태그. 글자는 네이비        |
| Sun Yellow               | `#FFC857` | 발견/강조 배경. 글자는 네이비                   |
| Action Coral — 보완 제안 | `#C84432` | 흰 글자의 실행 버튼, 아이보리 위 작은 강조 글자 |

기본 비중은 아이보리·흰 표면을 넓게, 네이비를 정보에, 코랄을 주요 포인트에 사용한다. 스카이와 옐로는 작은 보조 요소에 사용하며 오류·완료 같은 상태를 브랜드 장식 색 하나로만 전달하지 않는다.

### 직접 계산한 색 대비

HEX를 sRGB 상대 휘도로 변환하고 `(밝은 휘도 + 0.05) / (어두운 휘도 + 0.05)`로 계산했다. 아래 값은 표시용으로 소수 둘째 자리까지 반올림했고 판정은 반올림 전 값을 사용했다. 고정된 단색 조합의 결과이며 사진·그라데이션 위 텍스트 전체의 통과를 뜻하지 않는다.

| 글자 / 배경                         | 대비    | 일반 텍스트 AA |
| ----------------------------------- | ------- | -------------- |
| 흰색 / Trip Coral                   | 2.80:1  | 미달           |
| Trip Coral / Warm Ivory             | 2.68:1  | 미달           |
| Journey Navy / Warm Ivory           | 12.49:1 | 통과           |
| Journey Navy / Trip Coral           | 4.66:1  | 통과           |
| Journey Navy / Sky                  | 7.86:1  | 통과           |
| Journey Navy / Sun Yellow           | 8.49:1  | 통과           |
| 흰색 / Action Coral `#C84432`       | 4.85:1  | 통과           |
| Action Coral `#C84432` / Warm Ivory | 4.64:1  | 통과           |

[W3C WCAG 2.2 텍스트 대비](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)는 일반 텍스트 4.5:1, 큰 텍스트 3:1 기준을 설명한다. 로고는 해당 텍스트 기준에서 예외가 있지만 버튼·설명 문구까지 예외인 것은 아니다. 따라서 코랄 로고는 유지할 수 있고 작은 본문·CTA 글자는 별도로 보완한다.

식별에 필요한 활성 UI 아이콘·컴포넌트 경계도 [비텍스트 대비 기준](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)을 확인한다. 장식용 경로와 실제 탐색/상태 표시를 구분하고, 필요하면 네이비 외곽선·라벨을 함께 사용한다.

## 로고·아이콘 규격안

위치 핀·경로·비행기라는 핵심 조합은 유지한다. 동일 마스터에서 세로형·가로형·심볼·단색형을 파생시키고, 보드마다 다시 그려 모양이 달라지는 것을 막는다.

| 변형        | 권장 용도                       | 필요한 보완                                                 |
| ----------- | ------------------------------- | ----------------------------------------------------------- |
| 가로 로고   | 앱 헤더·웹·광고 서명            | 핀과 TripPrint 간격 및 두 단어 색상 고정                    |
| 세로 로고   | 시작 화면·소개·브랜드 보드      | 작은 한글 부제는 충분한 공간에서만 사용                     |
| 심볼        | 앱 아이콘·favicon·작은 워터마크 | 가는 경로와 작은 비행기를 축소용으로 단순화                 |
| 단색형      | 어두운 사진·인쇄·각인           | 흰색/네이비에서 형태와 내부 여백이 유지되게 제작            |
| TP 모노그램 | 보조 장식                       | 공식 앱 아이콘과 경쟁하는 두 번째 대표 로고로 사용하지 않음 |

제공된 핀과 비행기는 여행 서비스에서 흔한 모티프다. 경로의 형태·핀 내부 공간·비행기 각도·워드마크 간격 중 고유한 규칙을 정해 식별력을 높이는 것을 권한다. 현재는 벡터 원본이 없으므로 구체적인 최소 크기와 획 두께를 확정하지 않았다.

원본을 만든 뒤 16/24/32/48px 축소와 Android 마스크를 실제 렌더링해 핀·경로가 남는지 검증한다. 작은 아이콘에는 슬로건과 작은 한글 글자를 넣지 않는다. 보호 여백은 우선 핀 중심 원 지름 1개를 기준안으로 잡고, 최종 벡터로 조정한다.

사진을 배경으로 사용한 아이콘은 여행지에 따라 인상이 달라지고 작은 크기에서 복잡하다. 코랄 단색 계열을 대표 앱 아이콘으로, 사진형은 캠페인용 변형으로 구분하는 것을 권한다.

Google Play 스토어 아이콘은 512×512px 규격으로 별도 내보내고 앱 adaptive icon과 분리한다. Google Play는 스토어 아이콘의 둥근 마스크와 그림자를 적용하므로 원본에 바깥 둥근 모서리·외부 그림자를 중복 적용하지 않는다. [Google Play 아이콘 규격](https://developer.android.com/distribute/google-play/resources/icon-design-specifications)

## 글꼴과 이미지 원본

영문은 Poppins Bold/Semibold, 한글은 Pretendard를 기준안으로 권한다. 보드의 `Rounded`는 형태 설명으로 읽히지만 실제 폰트 파일명이 명확하지 않으므로 Poppins의 실제 굵기와 글자 간격으로 규격화한다. Poppins를 사용하는 것만으로 보드의 로고 글자 모양이 완전히 재현되는 것은 아니다.

로고 워드마크는 검증한 글꼴/커스텀 글자 형태로 만든 뒤 벡터 외곽선 버전을 보관한다. 앱 본문·광고 카피는 편집 가능한 텍스트로 유지한다. 필기체 슬로건은 장식용 보조이며 주요 기능 설명·시간·금액에 사용하지 않는다.

[Poppins 라이선스](https://github.com/google/fonts/blob/main/ofl/poppins/OFL.txt)와 [Pretendard 라이선스](https://github.com/orioncactus/pretendard/blob/main/LICENSE)는 SIL OFL 1.1이다. 앱에 폰트를 포함할 때 해당 저작권/라이선스 문서를 함께 보관한다. 필기체의 정확한 폰트와 첨부 여행 사진의 원본/사용권은 이미지 한 장으로 확인할 수 없으며 아직 검증하지 않았다.

편집 원본, 벡터 로고, 폰트 파일, 사진 출처 및 사용 범위를 자산별로 보관한다. 첨부 보드를 잘라 광고용 완성 로고로 쓰면 작은 크기·인쇄에서 품질과 일관성이 떨어질 수 있다.

## 마케팅 이미지 제작 기준안

따뜻한 실제 여행 사진, 충분한 아이보리 여백, 네이비 헤드라인, 코랄 경로/핀, 실제 앱 화면을 함께 사용한다. 산토리니 이미지는 분위기를 전달하는 한 가지 테마로 유지하고 도시 여행·음식 기록·동행 일정 같은 기능별 소재도 같은 규칙으로 확장한다.

각 소재는 하나의 메시지를 중심으로 만들고 로고·헤드라인·앱 화면·CTA의 위치 규칙을 재사용한다. 풍경 위 글자는 복잡한 부분을 피하거나 일정한 단색 패널/오버레이 위에 배치한다. 하단 서명 로고는 배경에 따라 단색형으로 바꾼다.

| 소재        | 헤드라인 예시                          | 실제 보여줄 내용                               |
| ----------- | -------------------------------------- | ---------------------------------------------- |
| 브랜드 소개 | `여행의 발자취를 남기다.`              | 여행 사진 + 브랜드 + 계획·공유·기록 설명       |
| 계획/동행   | `함께 정한 일정, 한곳에서.`            | 현재 여행 일정·동행 기능의 실제 화면           |
| 여행 기록   | `다녀온 순간을 하나의 발자국으로.`     | 완료 다이어리·등록 사진·실제 비용 표시         |
| 커뮤니티    | `내 여행이 누군가의 첫 계획이 되도록.` | 사용자가 선택한 내용만 공유되는 실제 게시 화면 |

현재 자동 Places·Vision OCR·소셜 로그인은 미연결이다. 1차 테스트 광고에서는 `영수증 사진과 비용을 함께 기록`처럼 제공하는 수동 확인 기능을 표현하고, `촬영만 하면 전부 자동 정리`나 미연결 로그인이 가능한 것처럼 표현하지 않는다. 보드의 지도 목업과 실제 제공 중인 Maps 열기/공유 링크 기능도 같은 기능으로 오해되지 않게 구분한다. 순위·이용자 수·평점·절감 금액을 확인 없이 광고 문구에 넣지 않는다.

### 마스터 자산 목록

| 파일 기준안                                           | 내용                                                 |
| ----------------------------------------------------- | ---------------------------------------------------- |
| `tripprint-logo-horizontal.svg`                       | 가로 컬러 로고                                       |
| `tripprint-logo-stacked.svg`                          | 세로 컬러 로고                                       |
| `tripprint-symbol.svg`                                | 핀·경로·비행기 심볼                                  |
| `tripprint-logo-white.svg`, `tripprint-logo-navy.svg` | 단색형                                               |
| `tripprint-app-icon-1024.png`                         | 앱 아이콘 작업 원본. 실제 플랫폼별 출력은 별도       |
| Android foreground/background/monochrome              | 마스크·단색 테마용 분리 레이어                       |
| `tripprint-favicon-*`                                 | 작은 크기 전용 심볼                                  |
| brand tokens 및 폰트 라이선스                         | 앱과 광고가 공유할 색상·글꼴·간격 기준               |
| editable campaign templates                           | 헤드라인·사진·앱 화면·CTA를 교체할 수 있는 편집 원본 |

위 자산 파일은 이번 점검에서 제작하지 않았다. 이미지 생성으로 배경/사진을 만들더라도 브랜드명과 로고는 같은 마스터를 별도 합성하여 표기 흔들림을 막는 것을 권한다.

캠페인 작업판은 정사각 1080×1080, 세로 피드 1080×1350, 세로 전체 1080×1920을 제안한다. 이는 제작 템플릿 기준안이며 모든 광고 채널의 제출 규격을 확정한 것이 아니다. 실제 게재 채널별 잘림·UI 겹침·안전 영역을 다시 확인한다. Google Play feature graphic은 1024×500px로 별도 제작한다. [Google Play 미리보기 자산 안내](https://support.google.com/googleplay/android-developer/answer/9866151)

## 적용 순서

1. 브랜드 표기와 설명 문장을 정하고 이름의 권리·도메인·핸들 확인 상태를 기록한다.
2. 하나의 벡터 로고와 축소용 심볼, 색 대비를 보완한 액션 토큰, 정확한 폰트 자산을 마련한다.
3. 설치 이름·아이콘·로그인·초기 진입·일정·다이어리·초대 공유 등 사용자 접점을 같은 기준으로 수정한다.
4. 기존 세션/여행 데이터가 유지되는지 검증하고 브랜드 반영 버전을 새로 배포한다. 현재 `test-1` 기록과 구분한다.
5. 브랜드가 반영된 실제 화면을 캡처해 스토어/광고 템플릿에 적용한다.

현재 웹 1차 테스트본은 여전히 WHEREGO 표기를 사용한다. 이번 검토 문서가 TripPrint 적용 완료나 새로운 광고/앱 배포 완료를 뜻하지 않는다.
