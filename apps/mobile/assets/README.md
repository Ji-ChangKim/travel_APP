# 앱 리소스 안내

- `brand/`: 로고·하루·앱 설치 아이콘과 출처 원본입니다.
- `fonts/line-seed/`: 현재 앱이 사용하는 한·영·일 글꼴입니다.
- `fonts/pretendard/`: 이전 디자인 시안을 열 때 필요한 글꼴입니다.
- `icons/`: 보유 SVG 아이콘입니다. 모든 화면에 적용됐다는 뜻은 아닙니다.
- `destinations/`: 앱에 포함하는 도시 사진과 출처 기록입니다.
- `illustrations/`: 용도를 정해 등록한 일러스트입니다.

사용자 영수증·사진, 빌드 결과, 검수 캡처를 여기에 넣지 않습니다. 파일을 옮기면 앱·문서·시안의 경로를 함께 바꾸고 `npm run check:resources`로 확인합니다. 같은 파일 내용이라도 앱 설치·스플래시처럼 역할이 다르면 임의 삭제하지 않습니다.
